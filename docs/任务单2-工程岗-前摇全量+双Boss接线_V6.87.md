## §3 双 Boss 贴图接线（**5 处，缺一处就静默失效**）

### §3.1 现状（实测）

`shared/dive/tables.ts:966` 只有一条：

```ts
boss: 'f_dash',        // ← 两个 Boss 共用冲刺体的贴图
```

叠加 `cocos/assets/scripts/view/Codex.ts:91`：

```ts
const BOSS_KEY: Record<string, string> = { 'boss:abyss': 'f_drift', 'boss:angler': 'f_orbit' }
```

⇒ 两个 Boss 在**场景里**共用 `dash` 的图，在**图鉴里**分别借 `drift` / `orbit` 的图。
（`Codex.ts:87` 的注释自己写了"真图走插画岗"—— 这是挂账。）

### §3.3 落地顺序（避免闸门中途变红）

`verify_cocos` 要求 **`artPaths()` 的每个 key 在磁盘上有文件**。所以：

- **路线 A（推荐）**：先等任务单 1 的两张 Boss 图落盘 → 一次接完 5 处 → 跑闸门。
- **路线 B（并行）**：先接 1-3-5 三处，但 `BOSS_TEX` 的两个值**先都指 `f_dash`**（占位，
  行为与现在完全一致、闸门不红）；等图到了只改这**一行常量**。

⛔ 别接一半就停（例如只改 `Codex.ts` 不改 `artKeys.ts`）—— 那种"一半接上了"最难查。
