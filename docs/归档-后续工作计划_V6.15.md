## 三、对比《土豆兄弟》（Brotato）

| 维度 | Brotato（300 万份 / $18.2M） | 深海回响（现状） | 判定 |
|---|---|---|---|
| 核心循环 | 波次 + 自动开火 + 纯走位 | 同 | ✅ 一致 |
| 武器槽 | 6 | 6（4 基础 + 2 扩容解锁） | ✅ 一致 |
| 波次时长 | 20–90 秒 | 40–60 秒 | ✅ 一致 |
| 波间商店 | 三选一 + 刷新 + 锁定 | 三选一 + 刷新 + 锁定 | ✅ 一致 |
| 武器数量 | 数十把 + 每把多级 | **4 把** + 5 级 | 🔴 差距大 |
| 武器进化 | 无（靠数量堆） | **无** | ⚠️ 我们要靠进化补数量 |
| 角色 | 数十，机制各异 | **1 台** | 🔴 差距大 |
| 道具 | 数百 | ≈23 | 🔴 差距大 |
| 单局时长 | < 30 分钟 | 20–25 分钟 | ✅ |
| 定价 | $4.99 | 计划 $4.99–7.99 | ✅ |
| **差异化（我们的牌）** | — | **氧气四合一**（Brotato 血量只在挨打时掉，我们的氧气**持续在掉**） | ✅ 独有 |
| | — | **每层末下潜/上浮风险决策**（Brotato 只能打到死） | ✅ 独有 |
| | — | **深海矢量霓虹**第一眼识别度 | ✅ 独有 |
| 长尾机制 | 低价 + 高频更新（三年后在线反涨） | 未开始 | ⏳ |

**结论**：**骨架与 Brotato 同构且已立住**，三张差异化的牌（氧气 / 下潜决策 / 美术）都有实物。
**真正对不上的是"量"**：Brotato 用"数百道具 + 数十角色"填满 build 空间，计划书的对策是**"质变密度"（少数但改机制的升级）**——而实现这一点的**进化系统目前是 0**，这是最该补的一块。

### P1 · 武器进化系统（0 → 24 形态）—— ✅ **已完成第一批（v6.17，8 形态）**

每把武器 2 条进化分支，**改机制而不是加数值**（§5.2）。首批 4 把基础武器 × 2 = **8 个形态**：

| 基础 | 进化 A | 进化 B |
|---|---|---|
| 脉冲机关枪 | **加特林**（射速翻倍 · 射程腰斩） | **霰弹散射**（一次 5 弹扇形） |
| 追踪鱼雷 | **集束鱼雷**（一次 3 枚 · 覆盖面） | **重型鱼雷**（单发重击 · 爆炸半径 ×1.5） |
| 链式电弧 | **过载电弧**（跳跃 +4 · 串得更远） | **定点雷暴**（一次电击射程内全部目标） |
| 声呐共振 | **共振炮**（命中后向邻近弹射 40%） | **定向聚焦**（短距强波 · 伤害 ×2.5） |

**入口**：武器升到 **Lv5** 后，它的两条进化分支才会出现在商店卡池里（`dead` 门控）。
**实测**：未满级时 8 张进化卡全部被挡住；满级后机枪两条分支出现；购买后武器 id 变为 `gun_sg`，战场一次打出 5 颗弹。
