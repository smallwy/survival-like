## §1 HUD：雷达放大

```
RCX = W − 86     RCY = 174     RR = 64     RPLOT = 54     RANGE = 780
```

**尺寸的上下界不是拍脑袋，是被两条边夹出来的：**

| 约束 | 校验 |
|---|---|
| 上：不撞波次倒计时环 | `RCY − RR = 110 > 97`（波次环最下缘 `by+bh+36+15`） |
| 右：不越屏幕 | `RCX + RR = W − 22`（右边留 22px） |

⇒ `RR = 64` 是"刚好放下"的值。再加就会同时踩这两条。

配套：点位半径 `drift 3.0→3.6` / 其他 `2.2→2.6` / BOSS `3.4→4.2`、呼吸环 `6→7`、
外环线宽 `1.4→1.6`、标题字号 `11→12`。**圈放大了点位不放大，读起来会更"空"。**

## §2 HUD：暂停键移到右下角

### §2.1 位置与连锁

| 元素 | 旧 | 新 |
|---|---|---|
| 暂停键 | `(W−32, 30)`，38×38，热区 64 | `(W−46, H−27)`，**46×46**，热区 **76** |
| 鱼骨 | `(W−150, …)` | **`(W−106, …)`**（回贴边） |
| 生物质 | 右对齐 `W−64` | 右对齐 **`W−24`** |
| 遗物槽 | 右端 `W−24` | 右端 **`W−92`**（给暂停键让 23px） |

**为什么去右下角**：右上角现在挤了鱼骨 / 生物质 / 雷达三组，暂停键插在中间会互相抢注意力；
而右下角天然是"出口"的位置 —— 拇指最容易够到、与其他信息块距离最远。

`W−92` 的依据：暂停键视觉左缘 `W−69`，留 **23px** 间隔（= 装备槽 46px 的一半，视觉上算"同一行"）。

**底部这一行现在是从右往左排的**：暂停键 → 遗物槽 →（空）→ 技能冷却 → 装备槽。

### §2.2 icon 五层

```
① 投影        右下偏移 (2,3) 的暗圆角块
② 键体        UI.panel 圆角 12
③ 键帽面      内缩 3.5px、**比框亮**（UI.panelHi）⇒ 读作凸起的键，不是一块平贴
④ 顶边受光 + 四角铆钉   深海仪器的语汇（手轮/舱门都是四角固定的）
⑤ 双竖杠      用 fillRoundRect（**圆头**）而不是 fillRect（方头）；
              两柱之间压一条暗槽 ⇒ 竖杠本身也有厚度
```

判据：**方头是"两条色块"，圆头才是"两根实体按键柱"。**

## §3 炮塔：从"贴上去的圆点"到"装上去的基座"

### §3.1 挂点 = 底座 + 内凹槽

```
base = pad × 1.28                    // pad = TURRET_R × 0.55 = 8.8
① 投影      circle(cx + pad×0.14, cy + pad×0.30, base)  UI.abyss 0.40
② 底座侧壁  circle(cx, cy + 1.6, base)  shade(BODY_METAL, 0.34)
③ 底座顶面  circle(cx, cy, base)        shade(BODY_METAL, 0.52)
④ 顶面受光弧  arc(base×0.84, 1.05π→1.45π)  UI.cyanHi 0.42   ← 光源固定世界左上
⑤ 底座外沿  strokeCircle(base)          cyanDim / 扩容座 amber
⑥ 内凹槽    circle(cx, cy, pad)         UI.abyss 0.58
```

> **⚠️ 尺寸的教训**：底座先做过 `pad × 1.55`，预览放大图否掉了 ——
> 6 个直径 27px 的盘挂在 88×56 的机体上，读作"**机体外面套了六个黑盘**"，比不改更"贴图"。
> **底座的作用是给挂点一圈厚度，不是自己成为主体。**

### §3.2 发射器外壳

沿炮管方向一个短壳体（`L0..L1 = −0.55pad .. 1.45pad`，半宽 `1.05pad`），
上缘亮棱 / 下缘暗棱 / **壳口环**（`arc`，把"炮管从这里出来"写死）。

缺壳口环时，壳体与炮管是两个不相干的块 —— 这是"像贴图"的最后一环。

## §4 机体：关于「质感」与「养成线」

### §4.1 先回答那个问题

> 「机体本身没有质感（还是说有养成线补充）」

**不是靠养成线补。** 现有养成线**全部是数值**：

| 来源 | 加什么 |
|---|---|
| `unlocks.ts` 永久强化（`hull` 结构强化等） | `o2Bonus` / `rate` / `pickup` |
| 局内商店属性卡（`pool.ts`） | `regen` / `armor` / `dodge` / `luck` … |
| 潜航器固有（`subs.ts`） | `o2Max` / `hp` 等 |

⇒ **机体外观从头到尾长一样**，养成只改数字。所以"没有质感"只能靠渲染层解决。

### §4.2 矢量做到了哪一步

`Graphics` 的硬天花板是**无渐变 / 无模糊 / 无笔触**。本轮加了四样（见 `preview_hull_side.py --tex`）：

| 线索 | 值 |
|---|---|
| ②d 镜面高光带 | 沿上背 `edge(1,5)`，`0xdcfeff α0.50 w2.6` + `0xffffff α0.34 w1.2` 两级 |
| 背脊铆钉排 | 5 颗（暗底 + `cyanHi α0.5`），沿背脊带下方 |
| 舷窗光晕 | `cyanHi α0.11`，半径 `2.0r` |
| 塔观察窗 / 艉散热格栅 | 结构开口 |

### §4.3 三个被预览图否掉的方案（别再走回头路）

| 方案 | 为什么不行 |
|---|---|
| 三条贯穿全艇的**竖板缝**（近黑 2.4px） | 读作**铁笼**。收细、改艇身暗调、跨度收到 62% 之后**仍然是栅栏**。根因：`HULL_H` 只有 56px，任何贯穿艇高的竖线都只可能读作"这条船被切开了" |
| 舷窗套**暗色窗框** / 凹槽阴影 | 0.9px 暗环挂在 2.2px 半径上 = 半径的 41%，五个窗一排就是**五个黑洞**。⇒ 窗只做加法：**只加光，不加暗** |
| 几块**低频明暗斑** | 读作"锈斑 / 污渍"，不是"反光不均匀" |

> **结论**：56px 量级上，"金属质感"不来自结构线、也不来自斑块 ——
> 人眼认金属靠的是**一条会随角度走的集中亮痕**。所以最终只留高光带 + 铆钉。

### §4.4 真正的解：位图化（下一步）

按项目既定的 **B 混合形态**，静态装饰层应当走 png 切图。机体位图化的**前置条件已经具备**：

- V6.54 已把朝向改成**离散镜像**（`faceX`），不再随 `aim` 旋转 ⇒ 位图 `scale.x = -1` 可复用；
- ⚠️ **但受光方向不能烘焙进图** —— 镜像会把"左上受光"翻成右上，违背"光源固定世界坐标"的铁律。

⇒ **正确分工**：位图只出**中性层**（装甲板分块 / 表面材质 / 铆钉 / 舷窗开口），
**明暗层（受光弧 / 暗弧 / 高光带）继续用矢量叠在上面**（世界固定光源）。

这一步需要出图（插画岗），本轮先给结构与规格。

## §5 弹射感

### §5.1 后坐曲线

```ts
const kf = Math.min(1, wp.fireFlash / 0.15)
const e  = 1 - kf                                  // 经过的时间比例 0→1
const kick = 5.5 * Math.exp(-e * 3.4) * Math.cos(e * 6.2)
                 * (e > 0.9 ? (1 - e) / 0.1 : 1)   // 末尾 10% 线性收口，防跳变
```

- 行程 `3 → **5.5px**`。
- ⚠️ **线性归位读作"贴图滑回原位"** —— 匀速退回没有任何冲击感。
  真实后坐是**阻尼振荡的第一段**：猛退到底 → 快速回位 → **轻微过冲** → 归中。
- 末尾 10% 收口：`fireFlash` 结束时残值必须归零，否则炮管会"啪"地跳一下。

### §5.2 枪口焰三层

| 层 | 寿命 | 说明 |
|---|---|---|
| 焰芯 | `0.11 → 0.15s`，`size 7→9` | 静止大闪 |
| **前向长焰** | 新增 `0.09s`，`3.4px`，白，速度 `130S` | **关键**：有速度 + 寿命更短 = 有方向、有初速 |
| 火花 | `0.16→0.18s`，数量 `3/6 → 5/8`，速度 `70/90 → 95/120` | 更快更多 |

> 旧版只有一颗 0.11s 的**静止**短闪 —— 60fps 下只存在 6~7 帧，且没有任何"往前喷"的元素，
> 读起来是"枪口亮了一下"，不是"一发打出去了"。

### §5.3 炮口照明（新增）

开火瞬间，**炮口的光打回机体**：取全场最大 `fireFlash`，整机叠一层 `cyanHi α0.11`。

> "发射装置像贴图"的第三半：没有这一层，开火只是"船**外面**亮了一下"，
> 机身上收不到任何来自自己武器的光 ⇒ 炮塔与船读作两件不相干的东西。

颜色用青白而非枪口焰的暖色：深海整体冷光环境下，船壳反射用冷色更成立。

## §6 待实机确认（Creator 3.8.8）

1. **雷达放大后**与波次环、屏幕右缘不打架；点位不显稀。
2. **暂停键在右下角**：与遗物槽留出 23px；点击热区（76×76）够得着、不与遗物槽抢点击。
3. 暂停键 icon 在实机尺寸（46px）下**读得出是暂停**（圆头双柱 + 铆钉）。
4. 鱼骨 / 生物质回贴边后，数字位数变化不会左右抖。
5. **机体高光带**在实战画面（有背景、有敌人）里是"亮痕"还是"白线"。
6. **炮塔**：底座不盖住机体轮廓；壳体不遮住发射器本色（"机枪必须清晰可见"是硬要求）。
7. **开火**：后坐看得出"退→回→过冲"吗；机身上的炮口照明会不会太亮。
8. ⚠️ **后坐过冲若导致炮管"倒吸"太明显**，只调 `e` 的系数（`3.4` / `6.2`），公式结构不动。
