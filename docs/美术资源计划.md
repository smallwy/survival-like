## 一、版本变更：V3 → V4

| # | V3 | **V4** | 原因 |
|---|---|---|---|
| **①** | 视觉基石：黑暗中一束光，视野=电量 | **分层可见度模型**：环境可见度按层递减，但**敌人发光核心永远可见** | 波次制要求满屏可读（§2） |
| **②** | 未处理同屏多单位 | **新增第 3 章：满屏可读性规范**（150 敌人红线） | Bullet Heaven 的核心技术门槛 |
| **③** | 5 层签名面向"纵向探索世界" | 改为面向**层内竞技场**：地面纹理 / 边界 / 背景 | 玩法从纵向探索改为波次竞技场 |
| **④** | 击杀三类交互（驱离/击杀/收容） | 简化为**击杀 + 氧气泡**；收容改为武器进化 | V6 §8 |
| **⑤** | 闪电 = 视野 = 生命 = 货币 | **氧气**取代电量；氧气泡是新的关键视觉对象 | V6 §3.2 |
| **⑥** | 暴露度条 | **删除** | V6 §8 已删该机制 |

**继承不变**：运行时几何绘制（`render/neon.ts`，零 png）、三层发光公式、色相隔离硬规则、5 层签名表、双渲染器降级规则、剪影验收法。

## 二、视觉体系重构：分层可见度模型

### 2.1 矛盾与解法

| 冲突 | V3 的做法 | V6 的要求 |
|---|---|---|
| 视觉 | 视野外全黑，只见发光轮廓 | 同屏 150 敌人必须全部可辨识 |
| 玩法 | 探索，慢慢看 | 波次，30 秒内做多次走位决策 |

**解法：把"可见度"从"玩家灯半径"改为"环境可见度 × 敌人自发光"两条独立通道。**

> **铁律：敌人的「发光核心」（2-3px 亮点）在任何层、任何距离都必须可见。**
> 黑暗只影响氛围与细节，**绝不阻断 gameplay 信息**。

### 2.2 五层可见度参数

| 层 | 环境可见度 | 玩家灯半径 | 敌人可辨识内容 | 氛围目标 |
|---|---|---|---|---|
| **L1 阳光带** | **100%**（有阳光） | 600（≈全屏） | 完整轮廓 + 颜色 | 明亮、安全、教学层 |
| **L2 暮光带** | 80%，边缘渐暗 | 500 | 完整轮廓 + 颜色 | 开始变暗 |
| **L3 无光带** | 40% | 400 | **轮廓 + 发光核心** | 真正的黑暗初体验 |
| **L4 热泉带** | 25%（热泉岛内 100%） | 320 | **主要靠发光核心** | 压迫感 |
| **L5 深渊带** | 10% | 220 | **几乎只靠发光核心** | 极端压迫 |

**实现要点**：环境可见度用一层**半透明黑幕**控制（α = 1 - 可见度），黑幕**只压暗地形与背景**；敌人、氧气泡、玩家、UI **绘制在黑幕之上**，不受压暗影响。

> 这一条是 V4 最重要的工程约定。它让"深海黑暗"从**遮挡机制**变成**氛围滤镜**，从而在保留美术调性的同时满足 gameplay 需求。

### 2.3 三层发光公式（继承 V3）

```
单位 = 近黑填充 + core 描边 + halo 柔光 + bloom 外扩
```

| 层 | 线宽 / 半径 | 颜色 | 透明度 | 作用 |
|---|---|---|---|---|
| **fill** | — | `#040810` | 1.0 | 遮挡背景 |
| **core** | 1-2px 描边 | 单位专属发光色 | 1.0 | **清晰度锚点** |
| **halo** | +8px | 同色 | 0.35 | 第一次柔化 |
| **bloom** | +24px | 同色 | 0.12 | 远距离色晕 |

> **同屏压力下的降级**：敌人数量 > 80 时自动**去掉 halo 与 bloom**，只保留 fill + core（见 §3.2）。

### 2.4 全局色板（继承 V3）

| 用途 | 色值 | 说明 |
|---|---|---|
| 底色 | `#04070d` | 近黑蓝 |
| **主色 · 青蓝** | `#4fe8ff` | UI / 潜航器 / **玩家专属** |
| 主色高光 | `#c8f8ff` | 文字与高亮 |
| 主色暗部 | `#1f6a7d` | 未激活描边 |
| 生物 · 青绿 | `#7fffd4` | 常见生物 |
| 生物 · 品红 | `#ff4fd8` | 稀有 / 危险 |
| 生物 · 琥珀 | `#ffd166` | 资源 / 热泉 |
| 生物 · 紫 | `#a06bff` | 深渊 / Boss |
| 危险 · 纯红 | `#ff2e63` | 全场唯一纯红，致命预警 |
| **氧气 · 纯白** | `#ffffff` | **氧气泡专属**（见 §3.3） |

**硬规则：青蓝只给玩家和 UI。** 生物发光色必须避开青蓝色相。

## 三、满屏可读性规范（V4 核心）

> **这是 Bullet Heaven 品类真正的技术门槛，也是 62% 换皮作品崩掉的地方。**
> 判定标准：**同屏 150 个敌人 + 50 个氧气泡时，玩家仍能在一帧内找到自己、找到最近的气泡、识别冲刺中的敌人。**

### 3.1 五条硬规则

| # | 规则 | 理由 |
|---|---|---|
| **①** | **敌人只画轮廓 + 发光核心，不填实体色** | 实体色在重叠时会糊成一片；轮廓 + 核心在重叠时仍可数清个体 |
| **②** | **氧气泡用唯一纯白 + 上升动画** | 混乱中"最亮 + 在动"的对象会被最先看见；这是玩家最需要的信息 |
| **③** | **玩家永远是最亮的青蓝，且有独特轮廓** | 任何时刻都能找到自己 |
| **④** | **不显示伤害数字** | 150 个敌人时数字会淹没画面。用"击中闪白"替代反馈 |
| **⑤** | **敌人在屏幕外生成，游入屏幕** | 避免在玩家视野内凭空出现 |

### 3.2 同屏密度分级降级（性能 + 可读性双保险）

| 同屏敌人 | 绘制档位 | 内容 |
|---|---|---|
| 0-40 | **完整** | fill + core + halo + bloom |
| 40-80 | **标准** | fill + core + halo |
| **80-150** | **简化** | **fill + core**（去掉所有柔光） |
| >150 | **极简** | **只有 core 亮点**（2px）+ 轮廓省略 |

> 降级是**全局的**（一帧内所有敌人同档位），避免画面档位混杂产生视觉噪音。

### 3.3 氧气泡（新关键视觉对象）

| 项 | 规格 |
|---|---|
| 形状 | 圆形，半径 4-6px，带 1px 白色高光弧 |
| 颜色 | **纯白 `#ffffff`**（全场唯一纯白） |
| 动画 | 生成后**缓慢上升**（12px/s），带轻微左右摆动 |
| 存活 | 6 秒；**最后 2 秒闪烁**（α 1.0 ↔ 0.4，4Hz） |
| 层级 | 绘制在**所有敌人之上** |
| 拾取 | 玩家接触半径内自动吸入，吸入时有 0.15s 拖尾 |

> **为什么必须是白色**：画面里其余颜色都是有语义的（青蓝=自己、青绿/品红/琥珀/紫=生物）。氧气泡是玩家"最需要立刻看到"的东西，必须独占一个未被使用的通道。

### 3.4 冲刺敌人的预警（可读性中最难的一条）

| 项 | 规格 |
|---|---|
| 蓄力期 | 敌人 core 描边**由生物色转为纯红 `#ff2e63`**，持续 0.5s |
| 蓄力期 | 地面出现**红色方向指示线**（长 60px，宽 2px） |
| 冲刺中 | 拖尾残影（3 段，α 递减） |

> 冲刺类敌人是 survivors 品类**唯一会造成"莫名其妙被秒"**的类型。红色预警线是必须项，不是可选项。

### 3.5 Boss 视觉（三重区分，继承 V3）

| 维度 | 做法 |
|---|---|
| 几何签名 | 完全不同的轮廓（巨大环 / 分裂触须） |
| 颜色 | 紫色 `#a06bff` + **红呼吸脉冲** |
| 行为 | 周围"扭曲光环"（正弦扰动） |

## 四、深度分层美术签名

> V3 §4 的五要素签名继续有效，此处按**层内竞技场**重新落地。

### 4.1 五层签名总表（竞技场版）

| 层 | 深度 | ① 主色板 | ② 地面/边界形态 | ③ 地标签名物 | ④ 生物签名族 | ⑤ 粒子 | 环境可见度 |
|---|---|---|---|---|---|---|---|
| **L1 阳光带** | 0-200m | `#4fe8ff` → `#2a9fc4` → `#1f6a7d` → 雾 `#0d3a4a` | 开阔沙地 + 珊瑚簇，**场地最大** | **发光珊瑚塔** | 纺锤族 | 上升气泡、浮游絮 | **100%** |
| **L2 暮光带** | 200-1000m | `#2a4a8c` → `#1a2f60` → `#0e1b33` → 雾 `#081228` | 岩壁环绕，边界不规则 | **沉船残骸** | 卷族 | 稀疏 marine snow，缓慢下沉 | 80% |
| **L3 无光带** | 1000-4000m | `#060a14` → `#04070f` → `#02040a` → 雾 `#010206` | 破碎岩柱散布，可作掩体 | **鲸落** | 伞族 | 密集 marine snow，横向漂移 | 40% |
| **L4 热泉带** | 4000-6000m | `#1a0f08` → `#0f0805` → `#060302`；琥珀 `#ffd166` | 烟囱群，**场地最窄** | **热泉烟囱** | 塔族 | 上升热流、黑烟柱 | 25%（热泉岛内 100%） |
| **L5 深渊带** | 6000m+ | `#120824` → `#0a0414` → `#010205` → 雾 `#000103` | 平坦沉积，**场地空旷** | **深渊遗构** | 环族 | 几乎静止的悬浮微粒 | 10% |

### 4.2 地标签名物规格（继承 V3 §4.3）

| 通用规则 | 要求 |
|---|---|
| **唯一性** | 每种地标**只**出现在对应层 |
| **尺度** | 高度 ≥ 屏幕高度 60% |
| **远距可见** | 必须有**自发光**部分 |
| **密度** | 每层 1-2 处（竞技场比探索世界小，减少到 1-2 处） |
| **放置** | 放在场地**边缘或角落**，**不得占据战斗区中心**（会挡视线、挡走位） |

| 层 | 地标 | 自发光 | 附加作用 |
|---|---|---|---|
| L1 | 发光珊瑚塔 | 柱顶青绿荧光簇 | 导航锚点 |
| L2 | 沉船残骸 | 断裂舷窗残余琥珀灯 | 视觉锚点 |
| L3 | 鲸落 | 脊椎节点青绿微光 | 可作为掩体 |
| L4 | 热泉烟囱 | 顶部琥珀强光柱 | **热泉岛：站立区内氧气消耗减半** |
| L5 | 深渊遗构 | 紫色脉冲 | Boss 战场地 |

> **V4 新增约束**：地标从"探索地标"变成"竞技场装饰"，必须**退到边缘**，否则会干扰战斗可读性。

### 4.3 层间过渡（下潜时）

| 阶段 | 表现 | 时长 |
|---|---|---|
| 决策后 | 画面缓慢下沉，当前层元素向上移出 | 1.2s |
| 穿越 | **全屏致盲**（白 → 新层主色） | 0.6s |
| 落地 | 新层主色向内淡入 + 新地标从远处浮现 | 1.2s |
| HUD | 层指示跳格 + 氧气上限条**可见地缩短**（强化"容错变小"） | 同步 |

## 六、波次节奏视觉

| 事件 | 表现 | 时长 |
|---|---|---|
| **波次开始** | 屏幕边缘一圈**品红扩散环**向内收缩 + 低频音效 | 0.5s |
| **波次进行** | 敌人从屏幕外游入 | — |
| **波次结束** | 剩余敌人加速逃离画面；场地中央出现三选一升级面板 | 1.0s |
| **层末补给站** | 画面上浮半格，出现补给站面板（买氧气/武器/道具） | — |
| **下潜决策** | 两个大按钮：**继续下潜**（琥珀，显示门票数值）/ **上浮兑现**（青蓝，显示当前收益） | — |
| **Boss 现身** | 紫色扭曲光环 + 全屏震动 + 环境可见度**短暂归零再恢复** | 2.0s |
| **阵亡（溺水）** | 氧气条归零 → 全屏气泡上升 → 画面转深黑 → 结算 | 2.5s |

> **下潜决策面板是本作唯一的"非 survivors"画面**，必须做得足够有仪式感——它是我们差异化的门面。

## 八、UI 规划

## 12. V6.2 表现层落地记录（2026-10-11 实测截图验收）

用户判定"我方单位是一个圆点，整体 UI 不达标"。本次重做表现层，核心玩法不动：

### 12.1 击杀方式：声呐共振脉冲

**答案：深海里用声波杀鱼。** 潜航器发出一圈向外扩散的声波波前，扫过鱼时软组织被共振震散（肉屑粒子），只剩发光骨架。设定自洽（声波剥离软组织、高密度骨骼保留），视觉独特（扩散环），且机制上**波从玩家身上往外扩 → 贴得越近越早命中**，强制"扎进鱼群"的赌性与氧气系统咬合。

- 波前绘制三层：主环 + 内侧余波（-13px）+ 外侧预兆（+11px），随扩散衰减
- 机制变更：投射物 → 环形波前 AOE；`pierce` 升级改名「声呐功率」（每级 +55 射程）

### 12.2 击杀 → 鱼骨 → 氧气（新掉落闭环）

取代原"白色氧气泡"：鱼死亡 → 肉屑飞散 → **发光鱼骨**留下（脊椎 + 4 对肋骨 + 头骨 + 尾鳍骨），自转下沉，玩家游过去拾取换氧气。

- 颜色 `#dcfffb`（近白微青），继承 V4 §3.3"全场唯一最亮"的可读性席位
- **骨架大小 = 鱼体大小 = 回氧量**：小鱼 14px/3 氧 → 大鱼 30px/7 氧 → Boss 44px/24 氧。"挑大鱼打"视觉直接可读
- 下沉（有重量感）+ 6 秒消失 + 最后 2 秒闪烁；拾取半径内才吸收，**不做远程磁吸**（硬约束①）
- dropCap 硬约束②不变；Boss 骨不受上限（它是里程碑）

### 12.3 玩家：圆点 → 潜航器

流线型七边形艇身（朝移动方向）+ 驾驶舱穹顶 + 双稳定翼 + 推进器尾焰（移动时变长）+ **艇首探照灯锥**。

- 探照灯锥取代原"朝向指示线"——灯往哪照，艇就朝哪开，天然指示方向
- **灯锥亮度 = 0.05 + (1 − 层可见度) × 0.11**：L1 阳光带几乎看不见灯，L5 深渊带灯是唯一照明。V4 §2.2「分层可见度」落到了玩家自己身上
- 受击时整艇转白（保留"氧气被撞"的唯一反馈）

### 12.4 验收

无头 CDP 全链路：鱼骨掉落/拾取正常（L1 第 3 波 bones=10）、5 层推进、Boss 波、零 JS 异常。截图确认：L3 午夜带潜航器剪影 + 灯锥清晰；L5 深渊带环境全黑但鱼/鱼骨/灯锥全部可读。

## 13. V6.3：分层体感 + 多器械系统

> 立项背景：V6.2 把表现层做出来了，但试玩反馈是「感受不到深浅不同层的区别，UI 还是太简易」。
> 根因不是缺素材，是**世界结构和武器系统都还停在占位状态**。这一版同时补这两条。

### 13.1 分层体感：三处联动

问题诊断：V6.2 的 `drawEnv`只有 `alpha 0.05~0.16` 的几何剪影，还被暗幕压掉，玩家实际只感觉到"屏幕变暗"。改法不是继续调暗度，而是**给每层一个真实存在的世界**。

**① 五张混元环境背景（1536×1024 → WebP q82，合计 862 KB）**

| 层 | 场景 | 主色 |
|---|---|---|
| L1 阳光带 | 珊瑚礁+ god ray光柱 | 青绿 /暖金 |
| L2 弱光带 | 陆架边缘，光线明显衰减 | 青蓝 |
| L3 午夜带 | 深水悬浮颗粒+ 冷光团| 靛蓝 |
| L4 热泉带 | 黑色烟囱 + 熔岩裂缝喷发 | 橙红 / 近黑 |
| L5 深渊带 | 几乎全黑，只有生物冷光 | 近黑 / 紫 |

- 风格统一：Painterly sci-fi semi-realistic commercial game art（大众商业游戏审美，不是硬核写实概念图）
- **中央留空**给战斗区，矢量实体压在上层才不糊
- 裁底 34px 去模型水印后转 WebP，单张 2 MB → 130–270 KB

**② 实时深度米数**：HUD 左侧大号数字随波次连续滚动（203m→1,612m→4,008m→…→9,816m）。
米数比"L3 午夜带"这个词更有压迫联想——玩家对"3,400 m"有生理反应。

**③ 下潜过渡演出（2.1 s）**：压力舱排气（70 个空心气泡上涌）+ 深度数字 easeInOutQuad 滚动到下一层 35% 处 + 暗角收缩 + 下一层名预告 + 相机闷响震动。

### 13.2 暗角（vignette）的实现约束

用 18 圈同心环带由外向内叠加，**每像素只画一次**。
不能用渐变矩形直接填充：Canvas 无径向渐变（`fillGradientStyle` 是 WebGL-only），且矩形叠加会让中心被反复压成死黑。

- `strength = 0.16 + (1 − vis) × 0.72`，下潜过渡时额外 +0.38
- 基础压暗从V6.2 的 `(1−vis)×0.88` 降到 `×0.42`——背景图自带明暗关系，再套旧公式会把 L3/L4 实景压成一片死黑

### 13.3 多器械武器系统（用户诉求 3）

参照 Brotato：**火力来自多个来源，操作只有一个（走位）**。最多同时挂 3 台，各���独立冷却、各自索敌、同时自动开火。

| 器械 | 定位 | 间隔 | 伤害 | 射程 | 弹幕形态 |
|---|---|---|---|---|---|
| 声呐共振 | 群体 AOE、贴脸才快 | 0.42s | 12 | 420 | 环形波前（×1.15/级） |
| 脉冲机关枪 | 高频单体、通用 dps | 0.11s | 7 | 520 | 18px曳光弹 |
| 追踪鱼雷 | 低频追踪、清成堆 | 1.50s | 30 | 620 | 4 段尾迹 + 范围爆炸 |
| 链式电弧 | 瞬发连锁、收割分散敌 | 0.90s | 16 | 460 | 锯齿折线（跳 3→7） |

- 四台定位**互不重叠**，拿到哪张都明显改变手感
- 等级 1–5，每级`伤害 ×1.35 / 频率 ×1.12 / 射程 +26`
- 弹幕三条表现铁律：曳光弹必须有**尾迹**（不依赖瞄准辅助就能读弹道）、鱼雷必须有尾迹 + 前部亮点（否则像随机飞行的点）、电弧必须**瞬亮瞬灭 0.18s**（常驻会变成"看不懂的网"）

### 13.4 HUD 武器槽

三槽，每槽回答三个问题：**装了什么**（形状签名图标）· **多强**（5 格等级点）· **什么时候好**（底部冷却条）。

图标靠**形状差异**而非颜色区分（11px 尺寸下颜色不可靠）：环 = 声呐 / 三道平行线 = 机关枪 / 鱼形 = 鱼雷 / 折线闪电 = 电弧。
商店卡显示真实图标，并标注「已持有 · Lv1→Lv2」，否则玩家不知道买到的是新武器还是强化。

### 13.5 生存压迫感官层（用户诉求 1）

压迫必须**有常驻显式指示**，玩家才能把"我为什么喘不上气"归因到正确的原因：

- **低氧心跳边框**：O₂ < 32% 时红色边框按心跳节奏收缩，频率随缺氧程度上升（2.2→5.6 Hz），直接映射生理联想
- **L4 热泉上升流（`ventPush` = 190 px/s²）**：用**加速度**而非速度偏移——加速度会自然地和玩家输入对抗，静止时明显被顶走。
  这是深海热泉区的生存体感：**没有稳定的地方可以停**。
  推力带空间梯度（越靠下越强，×1.0→1.8），且上升条纹 + 泉口热源的视觉解释与推力**同源**，否则玩家看到水在动却被看不见的力顶走会认为是 bug

### 13.6 顺手修掉的真 bug
