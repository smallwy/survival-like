# 数值框架（solo 调平衡基线）

> 所有可调参数集中在 `web/src/config/gameData.ts` 的 `BALANCE / WEAPONS / ENEMIES / UPGRADES`。
> 改这里即可调平衡，不必动逻辑代码。

## 玩家基线
| 项 | 值 |
|---|---|
| 最大生命 | 100 |
| 移速 | 220 px/s |
| 起始武器 | 手枪（伤害12 / 间隔450ms / 单发） |
| 经验拾取范围 | 60 px |

## 敌人成长公式（随等级）
- 生命：`hp = base + level * 4`（base 见武器被动表：小怪20 / 快怪14 / 胖怪70）
- 速度：固定（小怪70 / 快怪130 / 胖怪45）
- 伤害：固定（小怪8 / 快怪6 / 胖怪14）
- 刷怪间隔：`max(250, 900 - level*30)` ms（等级越高越密）

## 经验曲线
- 1 级需求：`expToLevel = 10`
- 之后：`expNeed = floor(prev * 1.25 + 4)`
- 每杀经验：`expPerKill = 3`

## 武器节奏参考
| 武器 | 伤害 | 间隔(ms) | 发数 | DPS(单发) |
|---|---|---|---|---|
| 手枪 | 12 | 450 | 1 | ~26.7 |
| 霰弹 | 7×5 | 850 | 5 | ~41.2（近距全中） |
| 环绕球 | 9 | 600 | 2 | ~30 |

## 升级池（6 选 3）
伤害+20% / 移速+15% / 攻速+15%（冷却×0.85）/ 血量+25 / 拾取+40 / 新武器。

## 平衡建议（给 solo 开发者）
1. **先保证能通，再调有趣**：把 `runMinutes` 调到 5 分钟快速验证整局闭环。
2. **用脚本批量模拟**：写个本地脚本按当前数值跑 N 局，统计平均存活时间/分数，找崩盘点。
3. **难度旋钮优先级**：刷怪间隔 > 敌人血量 > 玩家伤害 > 移速。先动刷怪间隔最安全。
4. **避免指数爆炸**：升级增益用乘法但设上限（如攻速最低 150ms），防止后期数值崩。
