## 六、关卡深度专项复核（2026-10-12 追加）

> 起因：用户提问「目前的关卡设计没有吧 只有几层设计 这种深度不够吧」

### 6.1 先纠正前提：这个品类**没有关卡地形**

核代码：`obstacle / collide / blocker / 岩壁` —— **全文件 0 处引用**，竞技场就是一块空地。
这不是缺陷：**Brotato / DRG:S 都没有地形遮挡**。在这类"波次 + 自动开火 + 纯走位"里，
"关卡设计"指的是另外三样东西：

1. **波次编排**（encounter design）—— 一局 20 波各自刷什么、怎么刷
2. **层差异**（modifier）—— 每层改一条规则
3. **敌人组合**（archetype mix）—— 不同敌人逼出不同走位

### 6.2 逐条核对现状

| 维度 | 代码现状 | 判定 |
|---|---|---|
| **波次编排** | `WAVE_SHAPE` 是**全局一张 4 项表**（`count / dashRatio / hpMul / dur`），按 `waveInLayer` 索引 → **5 层共用同一套波次节奏**，只被层的 `cntMul/hpMul` 放大 | 🔴 **这是"深度不够"的首要原因** |
| **层差异** | 5 层共 13 个字段，但其中 **11 个是纯数值缩放**（氧气上限 / 消耗 / 掉落上限 / 血量 / 数量 / 冲刺占比 / 水母占比 / 视野 / 色调 / 粒子 / 深度区间）；真正算"机制"的只有 **L4 的 `ventPush`（热泉推流）一处**，其余 4 层 `ventPush = 0` | 🟡 **层 ≈ 同一关加数值 + 换色** |
| **敌人组合** | 3 类（梭形 swarm / 水母 drift / 翼型 dash）+ Boss；计划书 §3.5 要 4 类 | 🟡 差 1 类 |
| **关卡地形** | 无 | ✅ 品类惯例，不是问题 |

> **结论：判断正确，但根因是「层缺机制 + 波次表不分层」，不是"缺关卡设计"。**

### 6.3 推进方案（按性价比）

| # | 做法 | 成本 | 说明 |
|---|---|---|---|
| **1** | **`WAVE_SHAPE` 从 1×4 拆成 5×4**（每层一套波次表） | 低（**纯数据表**） | 最直接解决"每层节奏一样"。例：L1 教学少量慢；L2 加入成群梭形横推；L3 水母为主；L4 冲刺鱼群；L5 混合高压 + Boss |
| **2** | **每层加一条"层规则"**（现在只有 L4 有） | 中（要新系统） | L2 **暗流**（随机横向水流推玩家）· L3 **涌流**（敌人从单一方向集体冲锋）· L5 **压力**（氧气上限随时间继续压缩，不能拖）。L1 保持无规则 = 教学层 |
| 3 | **补第 4 类敌人**（重甲 / 护盾型） | 中 | 计划书 §3.5；逼你绕后或换武器 |
| 4 | 层内随机事件（沉船 / 热泉 / 鱼群，路过触发一次性效果） | 高 | 可选，锦上添花 |

### 6.4 重要提醒：这一块**不影响 §10 止损线判定**

止损线只看两件事：**单波爽不爽** + **氧气有没有产生"要不要去捡"的犹豫**。
层深度不够**不阻碍**这两条判定。
它影响的是**单局 20–25 分钟的耐受度** —— 前 5 分钟和第 20 分钟是同一套波次，玩到十几分钟会开始腻。

**所以顺序上：P0 止损线判定仍然排在最前，层深度归入 P2。**
