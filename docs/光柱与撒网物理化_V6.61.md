# V6.61 光柱与撒网物理化

> 起因：用户批评「你设计的东西**太机械化了** 要结合物理世界 光照下来 视觉上能看到**平行的柱子**吗
> 光在水里不能**消化**吗 要具备物理知识思维 之前那个**撒网的技能**也是 撒出去是个**圆形**
> 物理世界会是这样吗」。
>
> 这条批评是对的。V6.60 的光柱是「等距平行直条 + 多项式衰减」，撒网张开的判定与画法都是
> 「完美圆 + 同心圆环」——**两处都是"按几何画"，不是"按物理想"**。
> 本版把两处都改成物理模型。**模拟层的网判定半径 `NET_R` 未改**（这是手感参数，不是物理参数）。

## §1 光柱：几何 → 物理

### 1.1 五个物理事实 → 五处改动

| # | 物理 | V6.60（几何） | V6.61（物理） |
|---|---|---|---|
| ① | 太阳在无穷远 ⇒ 入射光**平行**；但**透视投影**让平行线在画面上必**汇聚到消失点**（云隙光 / 铁轨 / 走廊同一几何） | 等距**平行**直条 | **放射**到消失点 `(0.62W, −0.55H)` |
| ② | 水对光是 **Beer–Lambert 指数衰减** `I(d)=I₀·e^(−c·d)` | `(1−t)^1.6` 多项式 | `e^(−1.75t)`：顶 100% / 中 42% / 底 17% |
| ③ | 光被悬浮粒子**反复散射** ⇒ 越深越宽越糊 | 固定倍率梯形 | `w(t)=w₀·(1+0.8t)`：底 1.8× 顶宽 |
| ④ | 水**分波长吸收**（红先死）⇒ 清澈海水衰减长度 红 5m/橙 20m/黄 50m/绿 100m/蓝 200m | 整条一个色 `0xdff2ff` | 暖白 `0xfff2dc` → 蓝青 `0x93cdf0` **变色** |
| ⑤ | 丁达尔效应 = 光被**粒子散射进眼**。水若绝对纯净，光束**侧面看不见** | 与颗粒无关 | 光束里的颗粒**被照亮**（`BEAM_LIT_GAIN 1.9`） |

### 1.2 「光在水里不能消化吗」的正解

**能，而且正是它让我们看见了光柱。** 这是同一条因果的两面：

- 光在水里被**吸收**（→ 变暗、变色）**和**被**散射**（→ 使光束侧面可见）都是"消化"；
- 光束可见，**正因为**光正在被粒子散射掉 —— 真空中看不见激光的径迹，就是这个道理；
- 所以「看得见光柱」与「光被水消化」不是矛盾，是**同一件事**。V6.60 把它们做成互不相干的两层
  （光柱是贴上去的，颗粒是另一套）才是错的。

### 1.3 关于「视觉上能看到平行的柱子吗」

**看不到。** 真平行的入射光经透视投影**必然**汇聚 —— 这是投影几何，不是风格选择。
观察者（以及照片里的云隙光）看到的是**放射状**。V6.60 画成等距平行：**既不物理
（无衰减无扩散）**，**也不符合透视**（真平行线在画面上必汇聚）⇒ 两头不靠。

附带一条：水下抬头看，整个天空被压缩进 **97.2° 的斯涅尔窗**内
（水 n=1.333 ⇒ 临界角 arcsin(1/1.333)=48.6°，全角 97.2°），窗外的水面是全反射的镜面。
⇒ **消失点只会在上方**，不会跑到侧面去。

### 1.4 参数

| 常量 | 值 | 依据 |
|---|---|---|
| `BEAM_N` | 4 | §4.2「4–6 条」，取下限（5–6 条铺满读作"光幕"） |
| `BEAM_VP_X/Y` | `0.62 / −0.55`（归一化） | 消失点（太阳虚像）。`y<0` = 屏幕上方之外 |
| `BEAM_COL_TOP/BOT` | `0xfff2dc` / `0x93cdf0` | 分波长吸收：暖白 → 蓝青 |
| `BEAM_ABSORB` | 1.75 | `e^-1.75` ⇒ 顶 100 / 中 42 / 底 17% |
| `BEAM_DIFFUSE` | 0.8 | 底部 1.8× 顶宽 |
| `BEAM_W0/W1` | 24 / 44 | 顶宽区间（宽度是"几道"与"一片"的分界） |
| `BEAM_SWAY_T/PH/A` | 11 / 各条不同 / 14 | 水面波让消失点缓慢漂移；**每条独立相位**（同步 = 贴图） |
| `BEAM_LIT_GAIN` | 1.9 | 光束内颗粒的亮度倍率 |
| `BEAM_D0/D1` | 900 / 1200 | `depthM` 淡出（再深照不进太阳） |

## §2 撒网：圆形 → 水滴形

### 2.1 四个物理事实 → 四处改动

| # | 物理 | V6.60（几何） | V6.61（物理） |
|---|---|---|---|
| ① | 网是**柔性体**：被抛出时沿速度方向拉长（迎水面前缘被水拖） | 各向同性完美**圆** | 沿抛出方向拉长的**水滴形**（`NET_STRETCH 0.45`） |
| ② | 网缘挂着**离散铅坠**，坠之间网衣被水顶起 ⇒ **扇贝波** | 光滑圆 | 12 段，`NET_SCALLOP_N 6` 的**扇贝缘** |
| ③ | 网有**网目**（径向索 + 环向索），不是空心圈 | 两条同心圆 | 12 径向索 + 2 圈环向索 + 12 铅坠 |
| ④ | 张开后受**水阻**塌回去，不是一直张着 | 单向扩张 | 两段：**展开**(0→0.42) → **塌陷**(0.42→1)，收回到 0.82 |

### 2.2 `burst` 事件靠 `ang` 分流

同一个 `burst` 事件承载**两种物理**：

| 事件 | `ang` | 物理 | 画法 |
|---|---|---|---|
| 撒网张开（`openNet`） | **有**（= 子弹速度方向） | 有方向的**抛投** | 水滴形网（`drawNets`） |
| 氧气雷 / 水雷 / 诱饵引爆 | **无** | 各向同性**爆炸** | 冲击波环（`pushShock`） |

⚠️ `ang` 是**可选**字段，别为"字段统一"给爆炸编一个方向 —— 那会把"炸开"画成"抛出"。
（`shared/dive/types.ts` 的注释里写明了。）

### 2.3 参数

| 常量 | 值 | 依据 |
|---|---|---|
| `NET_DUR` | 0.52s | 整段时长 |
| `NET_OPEN_END` | 0.42 | 展开期占前 42%，其后塌陷 |
| `NET_STRETCH` | 0.45 | 沿抛出方向最多拉长 45% |
| `NET_TAPER` | 0.22 | 前尖后宽（水滴）的锥度 |
| `NET_SCALLOP/N` | 0.035 / 6 | 扇贝波幅度 / 波数（12 段里 6 个波） |
| `NET_SEGS` | 12 | 网缘顶点数（配 6 个扇贝波、12 个铅坠） |
| `NET_JITTER` | 0.05 | 各段随机 ±5%（打破完美对称） |
| `NET_COLLAPSE` | 0.82 | 塌陷段收拢到的比例 |
| `NET_CAP` | 6 | 同屏网数上限 |

## §4 图元预算

| | 基线 | V6.61 | 变化 |
|---|---|---|---|
| 光柱 | 4×3×3 = 36 | 4×3×3 = 36 | 0 |
| 撒网（每张） | 1 环 ≈ 2 | 网衣1 + 网缘1 + 索12 + 环24 + 坠12 ≈ **50** | +48 |

（一张读不出是网的东西，画得再省也没用）。

## §6 待实机确认（Creator 3.8.8 跑 `Dive.scene`）

1. **光柱**：是"透过水面的太阳光"还是"几条斜光带"？消失点在屏幕上方之外，光柱顶部是否"从画面外射进来"？
2. **光柱变色**：顶部暖白 → 底部蓝青，在 L1 / L2 是否都读得出？会不会太含蓄（看不出变）？
3. **光柱与颗粒**：光束路径上的颗粒是否**比旁边亮**？（`BEAM_LIT_GAIN 1.9`）—— 这是"光被水消化"的可见证据。
4. **光柱淡出**：`depthM 900→1200` 之间是否**平滑**淡出、没有"啪"地消失？
5. **撒网形状**：是"一张被甩出去的网"还是"一个形状怪的圈"？水滴尖是否朝向抛出方向？
6. **撒网扇贝缘**：12 个铅坠之间的扇贝波是否读得出"网衣被水顶起"？会不会太细看不见？
7. **展开→塌陷**：能看出"先张开、后塌回去"吗？还是全程大小不变？
8. **触发方向**（`DiveGame` 的分流）：撒网有 `ang` ⇒ 水滴形；氧气雷/水雷/诱饵引爆无 `ang` ⇒ 冲击波环。
   两者是否各自正确？（**若撒网也画成了圆环，说明 `openNet` 的 `ang` 没传出去**。）
