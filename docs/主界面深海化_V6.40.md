## 1. 主界面背景整图

### 1.1 为什么是整图，不是"再加点矢量装饰"

主界面原先的"深海元素"是矢量画的：探照灯锥 + 峡谷轮廓线 + 5 只水母 + 扫描线。
问题不是数量不够，是**媒介不对** —— 概念图里的深海靠的是：

- 岩壁的**实体感**（受光面 / 暗面 / 缝隙），不是一根轮廓线；
- 珊瑚、海葵的**有机笔触**；
- 沉船金属件的**锈蚀与铆钉细节**；
- 水母群的**半透明叠加与辉光衰减**。

这四样 `Graphics` 都做不了（无渐变边、无噪声纹理、无半透明叠加）。
矢量这条路的天花板就是"霓虹线稿"。所以背景走**整图**。

### 1.2 规格

| 项 | 值 | 依据 |
|---|---|---|
| 源图尺寸 | **1536 × 1024**（3:2） | 出图模型的宽幅档；≥ 设计分辨率 1304×749 保证不放大 |
| 落盘路径 | `cocos/assets/resources/ui/title_bg.png` | 与图标同目录（都是"主界面框架素材"） |
| 资源 key | `title_bg` | `shared/uiArt.ts` 的 `UI_BG_PATH` |
| 铺满方式 | **cover**（保比例、裁溢出） | contain 会在宽屏两侧露清屏色条带 —— "上线才被发现"那类问题 |
| 锚点 | 中心 `(W/2, H/2)` | ⚠️ `Title.root` 锚点是 (0,0) 且在**左下角**，写成 (0,0) 整图会贴到角上 |
| 中央留白 | 上偏中约 40% 区域**不放物体** | 顶部放标题、中央放大立绘，不能被背景细节干扰 |
| 内容要素 | 峡谷岩壁 / 发光珊瑚 / 沉船残骸 / 水母群 / 光柱 / 浮游微粒 | "深海元素"的清单，缺一项都读不出"深海" |

### 1.3 与战斗背景的关系（**两套东西，不可互借**）

| | 主界面背景 | 战斗背景（`env/L1..L5.png`） |
|---|---|---|
| 数量 | 单张 | 五层，随深度切换 |
| 信息量 | 高（要有东西看） | 极低（HUD 与弹药要在上面读得清） |
| 用途 | 撑住"这是深海"，可被 UI 压住 | 不能抢戏，是"幕后" |

⚠️ 把主界面这张铺进战斗，敌人会在珊瑚丛里消失。两套**不通用**。

### 1.4 缺图兜底（**必须保留**）

`Title.ts` 的 `syncBgArt()` 逻辑：

```
背景图到位 → 显示整图，关闭矢量装饰层（gBack / gCanyon / coneNode / gMotes / gDeco / 水母）
背景图缺失 → 整图节点 active=false，矢量层照常绘制
```

理由：本项目的铁律是「**没有美术也能跑**」——"打开工程点运行"不应依赖任何美术导入步骤。
所以矢量背景**不删**，退居兜底。

## 2. 深青玻璃槽（图标底）

### 2.1 规格：`GLASS`（`shared/theme.ts`）

| 键 | 值 | 用途 |
|---|---|---|
| `base` / `baseAlpha` | `#0c202a` / **0.82** | 常态底：深青、**半透明**（背景能透一点 → 槽位"贴"在场景上） |
| `hi` | `#56bad0` | 顶部受光高光带（内上 38%，向下渐隐） |
| `edge` / `edgeAlpha` | `#4fe8ff` / **0.35** | 常态描边（低透明 —— 高到只给轮廓为止） |
| `hover` | `#12303c` | 悬停底（提亮一档）+ 描边升到 `UI.cyan` 实色 + 外 halo |
| `press` | `#08161c` | 按下底（压回最暗）+ 描边 `UI.cyanHi` |
| `lock` | `#161c20` | 锁定底：**去青的中性暗，不是纯黑**（纯黑又会变成"黑板"） |
| `bar` / `barAlpha` | `#081119` / **0.92** | 顶栏底（横贯玻璃梁，比槽位更暗更不透明，避免抢标题） |

**"玻璃"与"黑板"的唯一分界 = 顶部那条受光高光带**（`hi`，24 条横向色带模拟向下渐隐）。
锁定态**不画高光** —— 高光会误导"这个能点"。

### 2.2 四态对照（与旧版差异）

| 状态 | 旧（`MENU.slot`） | 新（`GLASS`） |
|---|---|---|
| 常态 | `#0c1117` 实心近黑 | `#0c202a` @0.82 + 高光带 + 青描边 0.35 |
| 悬停 | `#232c39` | `#12303c` + 实色青描边 + halo |
| 按下 | `#0c1117`（与常态同色） | `#08161c` + `#c8f8ff` 描边（**可区分**） |
| 锁定 | `#0a0e14` | `#161c20`（去青中性） |

⚠️ **`GLASS` 只给主界面用**。战斗 HUD 与弹窗仍走 `MENU` / `BRIGHT`，**不要顺手改** ——
那两处的底是实心面板，槽位本来就该"凹进去"，改成玻璃反而糊。

### 2.3 为什么 `Graphics` 要手搓"高光带"

Cocos `Graphics` **没有渐变 API**。所以高光用 24 条横向色带 + 二次衰减模拟，
并且按圆角做**横向内缩**（距顶 `dy` 处内缩 `r − √(r²−(r−dy)²)`），
否则色带的直角会从圆角处溢出去。

## 3. 击杀特效

### 3.1 三张贴图

| 文件 | key | 用在哪 | 尺寸感 |
|---|---|---|---|
| `fx/sh_ring.png` | `fx_ring` | 普通小怪（`swarm` / `dash`，且 `r ≥ 12`） | 结束后半径 = `r × 2.6` |
| `fx/sh_burst.png` | `fx_burst` | **Boss** | `r × 5.4` |
| `fx/sh_bubble.png` | `fx_bubble` | 水母类（`drift`） | `r × 3.0` |

### 3.2 出图与处理规范（**与图标不同，别照抄**）

| 项 | 图标 | 击杀特效 |
|---|---|---|
| 背景 | 纯白（等乘色） | **纯黑**（发光） |
| 抠底 | 四边泛洪 + 连通域 | **alpha = 亮度**（`tools/process_fx.py`） |
| 理由 | 乘色需要亮底 | 辉光一路渐变到近黑，**任何泛洪阈值都切不干净** |
| 画布 | 512×512，外接圆 72% | 512×512，内容占 94% |

**为什么 alpha 用亮度**：发光贴图在 ADD/SCREEN 叠加下，黑的天然透明；
用亮度当 alpha 后，辉光自然衰减成透明 —— 这正是叠加想要的形状，RGB 保持原色不变。

⚠️ **本项目全线禁用 ADD 混合**（`Graphics` 不支持；Canvas 渲染器下会画成实心白块）。
所以叠加走**普通 alpha 合成** —— 因为贴图 alpha 已按亮度导出，视觉上与叠加等效。
**不要**看到"适合 ADD"就去开混合模式。

### 3.3 接入（`DiveGame.ts`）

| 项 | 值 |
|---|---|
| 事件源 | `SimEvent{t:'kill', x, y, r, color, kind}`（world.ts 已有，**未改模拟层**） |
| 图层 | `fxBitLayer`，排在 `gEnt` 之后、`gFront` **之前** |
| 理由 | `gFront` 装的是冲击波/火花/飘字 —— "最后的高光"，碎片压上去会让命中瞬间变浑浊 |
| 池 | 复用 `fishPool` 同款写法，`FXBIT_CAP = 28` |
| 生命周期 | 半径 ease-out 放大 + 轻微旋转 + 透明度"快起慢收" |
| 缺图行为 | 静默跳过，**矢量特效照旧**（不因缺图让战斗报错） |
| 与矢量并存 | 保留 `pushShock` + `pushRadialSparks` —— 矢量管连续动画，位图管手绘质感 |
