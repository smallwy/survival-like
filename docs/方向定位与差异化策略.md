# 方向定位与差异化策略

> 文档版本：V1（2026-10-09）
> 触发问题：*"现在这个做的游戏和三国没关系吧？明确当前的方向，深度调研这个玩法还有市场吗，是不是要做一些创新，不然同质化太厉害了。"*
> 结论先行：**玩法有市场；"三国 + 幸存者"没市场（是红海）；我们当前两头不靠。**

---

## 一、明确当前的方向（先把话说死）

### 1.1 立项时的方向：三国 = 皮肤包

`docs/立项策划案.md` 第 3 节原文：

> 美术方案（刻意压低）…… 后期若想换皮（**如"三国皮肤包"**），**只换着色与文案，不动结构**。

也就是说，**"三国"从一开始就被定义为换皮项，不是机制项**。所以今天"和三国没关系"是设计上的必然结果，不是执行跑偏。

### 1.2 实现层的举证（这个质疑完全成立）

| 维度 | 当前实现 | 和三国有关吗 |
|---|---|---|
| 角色 | `CHARS` = 4 项，字段只有 `id / name / color` | ❌ 仅名字和颜色 |
| 角色差异 | `startRun(char)` 只调用 `refreshPlayerLook()` | ❌ 血量/移速/起始武器/成长曲线**四人完全相同** |
| 武器 | 手枪 / 冲锋枪 / 霰弹枪 / 穿透步枪 / 激光束 / 环绕球 / 灼烧光环 | ❌ 现代火器 + 科幻，**没有一件冷兵器** |
| 敌人 | 小怪 / 快怪 / 胖怪 / 虫群 / 射手 | ❌ 通用西方奇幻命名 |
| Boss | 霸主 / 暴君 | ❌ 无三国指涉 |
| 数值体系 | HP / DPS / 冷却 / 穿透 | ❌ 无关 |

**结论：当前产品 = 一个通用幸存者，贴了四个三国名字的皮。** 既没有三国，也没有差异化——两头不靠。

### 1.3 一句话方向

> **当前方向：「低美术通用幸存者，三国作为可选皮肤」。**
> 这个方向在 2022 年成立，在 2026 年**已经不成立**（见第二、三节）。

## 二、市场判断：品类活着，但"门票"不等于"胜因"

### 2.1 品类基本面（正面）

| 事实 | 数据 | 来源 |
|---|---|---|
| Steam 官方承认品类 | 2026-05-18 正式新增 **Bullet Heaven** 官方标签 | Valve / howtomarketagame |
| 供给端在爆发 | 类幸存者新品上线量同比 2024 **+127%** | SteamDB 2026 H1（转引） |
| 需求端未退潮 | 2026 是有史以来发售日历最满的一年，社区评价"处于史上最强形态" | choostgames |
| 可长线运营 | VS / Brotato / Halls of Torment 至今仍在稳定出内容更新 | choostgames |

**→ 品类没有死，而且被平台正式命名。市场存在。**

### 2.2 但是：绝大部分入局者死掉了

| 事实 | 数据 |
|---|---|
| 换皮率 | 2026 春季新品节 Roguelite 生存新游中，**73% 采用 VS-like 框架** |
| 有效创新率 | 其中**仅 12%** 在核心循环上做出有效创新 |
| 差评集中度 | 好评率低于 70% 的换皮作品**占比超过 62%** |

### 2.3 关键论证：仿品坟场

一份对"VS 之后所有模仿者"的量化拆解（mythiclemon）：

| 游戏 | 评论数 | 相对 VS |
|---|---|---|
| **Vampire Survivors** | — (600 万+ 销量) | 基准 |
| Brotato（最好的仿品） | 32,330 | ≈ 1/4 |
| Halls of Torment | 21,694 | — |
| 20 Minutes Till Dawn | 13,326 | — |
| Soulstone Survivors | 12,622 | — |
| Nordic Ashes | 1,950 | — |
| Spirit Hunters | 1,029 | — |
| **七个仿品合计** | **97,380** | **仍不及 VS 一家** |

> 原文结论：*"The mechanic is the entry ticket to the genre, **not the thing that won it**."*
> —— 机制是**入场券**，不是胜负手。所有模仿者都拿到了入场券，然后都输了。

### 2.4 正面样本：Vital Shell（最重要的一课）

单人开发者，业余时间，约 15 个月，Godot。

- **它做了什么**：*"没有试图重造这个品类"*，就是 **20% 的改进 + 一个一眼能认出的美术风格**（PSX/N64 机甲）。
- **它没做什么**：没有"幸存者 + 约会模拟 + 恐怖 + 骑马"这种跨界缝合（作者原话点名批评这种失败模式）。
- **结果**：1,500+ 条 **Overwhelmingly Positive**。
- **最反直觉的洞察**：*"人们喜欢玩 Bullet Heaven，但**不会期待**它。"* 预售期营销指标一路只有 Silver 级，没人转发；上线后靠口碑自然爆。

**→ 结论：不需要革命性创新。需要的是「扎实执行 + 一个锐利的身份」。**

### 2.5 小结

| 问题 | 答案 |
|---|---|
| 玩法还有市场吗？ | **有。品类被 Steam 正式命名，仍是最活跃的独立品类之一。** |
| 做通用幸存者能成吗？ | **不能。73% 的新品都是这个，62% 死在 70% 好评线下。** |
| 需要革命性创新吗？ | **不需要。Vital Shell 证明了 20% 改进 + 强身份就够。** |
| 那需要做什么？ | **一个机制钩子 + 一个视觉身份。** 见第五节。 |

## 三、竞争格局：「三国 + 幸存者」已经是红海

这一节直接回答"同质化是不是太厉害了"——**是，而且是我们自己撞进去的**。

### 3.1 直接竞品（全部为已上线 / 即将上线）

| 游戏 | 平台 / 价格 | 上线时间 | 内容量 | 差异化钩子 |
|---|---|---|---|---|
| **Sanguo Survivors** | Steam $2.39 | **2026-09-07（一个月前）** | 15 名武将 × 各自起手武器 + 被动；火/水/土/风四系技能；多危险等级；28 成就 | 元素技能混合 |

| 维度 | 我们 | 竞品最低线 | 差距 |

**诚实结论：我们目前是市面上三国幸存者里内容量最小、主题最虚的一档。**

### 3.3 还剩下的空白（这是机会）

把四个竞品的能力矩阵摊开，**四个方向全部无人做**：

| 能力 | Sanguo Survivors | 乱世无双 | 斩将夺旗 | Survivors:3K | **空白?** |
|---|---|---|---|---|---|
| 元素/技能体系 | ✅ | ✅ | ✅ | ✅ | 已饱和 |
| 武将数量 | ✅ | ✅ | ✅ | ✅ | 已饱和 |
| 军团/副将 | — | ✅ | — | ✅ | 半饱和 |
| **兵种相克 + 阵型** | — | — | — | — | **空白** |
| **阵前单挑（Boss 变对决）** | — | — | — | — | **空白** |
| **势力对抗 / 劝降收编** | — | — | 仅局外剧情 | — | **空白** |
| **非像素/非二次元的国风视觉** | — | — | — | — | **空白** |
| **计谋/策（主动战术）** | — | — | 仅状态效果 | — | **基本空白** |

> 注意一个规律：所有竞品都在做**「更多」**（更多武将、更多技能、更多元素），没人做**「不同」**。
> 而三国演义真正的戏剧记忆点——**单挑、计谋、义结金兰、兵种调度**——幸存者类**一个都没碰**。

## 四、自我诊断：我们的问题不是美术，是"没有身份"

把玩家差评（真实语料）和我们的实现逐条对齐：

| 玩家差评原话 | 我们中招了吗 |
|---|---|
| "爽感是稳定的，但**变化是稀薄的**" | ✅ 8 个升级项，全是 +% 数值 |
| "**构筑变化不够明显**""装备只是数值 +1" | ✅ 所有升级都是线性乘算 |
| "成长曲线**平滑过头**，缺少阶段性质变的爽点" | ✅ 无进化/质变节点 |
| "感觉像在玩**不同颜色皮肤的同一关卡循环**" | ✅ **这就是我们的角色系统原文** |
| "后期成长停滞、终局内容单薄" | ✅ 15 分钟线性，无终局 |
| "难度更取决于**数值与运气**而非操作技巧" | ✅ 纯自动攻击，唯一操作是走位 |

**六条全中。** 这不是巧合——我们的设计目标（"美术依赖极低 + 极简循环"）恰好生产了差评里描述的那个产品。

### 关键判断

> **我们的短板不在美术完成度，在于「没有任何一个玩家能一句话说出的身份」。**
> "三国幸存者"不是身份，是分类——而那个分类里已经挤了四个人。

## 五、方向选择：三条路

前提共识（来自 2.4）：**不要动核心循环**。移动 + 自动攻击 + 三选一升级是入场券，推翻它等于放弃品类用户。

所以差异化的着力点是：**在核心循环之上嫁接一个钩子 + 换一个身份。**

---

### 方向 A：做深三国——把三国做成机制

**主张**：三国不是皮肤，是**兵种、阵型、势力、计谋**。

- **武将 = 兵种原型**，且机制真的不同
  - 关羽：重甲慢速，单刀横扫，高伤低机动 → "一刀开路"
  - 张飞：怒吼威慑（范围减速 + 打断），坦克型 → "堵桥"
  - 赵云：高机动穿刺，七进七出（短距闪现）→ "穿阵"
  - 诸葛亮：不自己打，召唤八阵图/连弩台 → "布阵"
- **武器换冷兵器**：青龙偃月刀 / 丈八蛇矛 / 方天画戟 / 诸葛连弩 / 火矢 / 铁蒺藜
- **兵种相克**：枪克骑、骑克弓、弓克枪 → 敌潮按兵种配置，玩家要**换武器应对**，而不是堆数值
- **势力敌潮**：魏（虎豹骑）/ 蜀（藤甲兵）/ 吴（水军弓手），不同势力不同行为模式

| 项 | 评估 |
|---|---|
| 差异化强度 | ★★★★★（三国唯一"名副其实"的做法） |
| 成本 | **高**：重做数值体系 + 兵种克制 + 大量新素材 |
| 风险 | 中——兵种相克在弹幕密度下可能"玩家读不过来"（幸存者类要的是可读的混乱） |
| 参考 | Survivor Legion（把"个人生存"改成"编队调度"，被评价为"一个决定改变了一切"） |

---

### 方向 B：一个锐利的机制钩子——「阵前单挑」

**主张**：不重做内容量，只把 **Boss 战**从"血厚大怪"改造成三国演义的核心记忆点。

- 到达 Boss 时间 → 敌潮**暂停**，两军对峙，进入**单挑**状态
- 一对一，有 **攻 / 守 / 破绽** 三段；读招拆招（简化的见招拆招，不用 QTE 纯反应）
- **赢了**：一合斩将 → 掉落**金色进化 upgrade**（直接触发一次质变）
- **输了**：不直接死，扣大血 + 敌潮加倍（保留幸存者类的容错）

| 项 | 评估 |
|---|---|
| 差异化强度 | ★★★★★（幸存者类**几乎无人做**"对决"；20MTD 是手动瞄准、Halls of Torment 是走位躲避，都不是对决） |
| 成本 | **中低**：复用现有 Boss 框架，加一个状态机 + 一套 UI |
| 风险 | 低。失败也只是"多了一个 Boss 玩法" |
| 额外收益 | **预告片极好剪**：万军之中二人对峙 → 一合斩将。这是 Vital Shell 说的"一眼能认出的身份" |
| 附带解决 | 玩家差评"缺少阶段性质变的爽点"——单挑胜利 = 明确的质变节点 |

---

### 方向 C：换视觉身份——国风（皮影 / 汉画像砖 / 水墨）

**主张**：竞品的视觉是**像素**（Sanguo Survivors）或**二次元娘化**（乱世无双）。国风视觉是 100% 三国原生，**且无人做**。

- 我们的像素管线是**程序化**的（`tools/pixelgen.py`），改造成本天然低
- 皮影戏质感 = 换调色板（朱砂/赭石/黛青/宣纸底）+ 描边加"关节钉" + 侧逆光
- 剪影会变得**极端清晰**——正好是弹幕里最需要的可读性

| 项 | 评估 |
|---|---|
| 差异化强度 | ★★★★（视觉身份，天然适合截图/预告片传播） |
| 成本 | **低**：改 `pixelgen.py` 的调色板 + 描边规则 |
| 风险 | 低-中。皮影风格单靠它不够，**必须配一个机制钩子**（即 B） |
| 参考 | Vital Shell 的核心胜因就是"90 年代美学"这一件事 |

## 六、推荐与落地路径

### 推荐：**B + C 组合**，A 作为内容深化路线

理由：

1. **符合 Vital Shell 教训**：不重造轮子，靠"20% 改进 + 强身份"取胜 → B 是那个改进，C 是那个身份
2. **符合 VS 坟场教训**：核心循环是门票不能动 → B/C 都不动核心循环
3. **避开红海**：四个竞品全在卷"更多武将/更多技能"，B/C 卷的是**"不同"**
4. **成本可控**：B 复用 Boss 框架，C 复用像素管线，都是增量
5. **宣传性**：单挑 + 皮影视觉 = 一段 15 秒的预告片就能说清"这是什么"

### 落地顺序

| 阶段 | 内容 | 产出 |
|---|---|---|
| **P0** | 方向落地：冷兵器武器库 + 四武将真实机制差异（A 的最小切片） | 游戏**立刻变成三国**，不再是皮肤 |
| **P1** | 「阵前单挑」Boss 改造（方向 B） | 独一无二的钩子 + 质变爽点 |
| **P2** | 国风视觉身份（方向 C） | 一眼能认出的截图 |
| **P3** | 兵种相克 / 势力敌潮（方向 A 完整版） | 三国机制化完成 |
| **P4** | 终局内容 + 长线更新节奏 | 解决"后期停滞"差评 |

> **P0 必须最先做**——它成本最低，但直接消灭用户提出的核心质疑（"和三国没关系"）。

## 六之二、落地进展（2026-10-09）

用户选定 **方向 A（三国全面机制化，保留像素风）**，并确认第一优先级是**消灭"和三国无关"这个质疑**。
本轮已完成 A 的最小可用切片：

| 项 | 落地位置 | 验证方式 |
|---|---|---|
| 武器库全冷兵器（8 件，无一件现代火器） | `gameData.ts` `WEAPONS` | 守卫断言 `WEAPONS` 不含 pistol/smg/shotgun/rifle |
| 弓/偃月/蛇矛/枪的像素绘制分支 | `pixelgen.py` `draw_weapon()` | `pixelgen.py` 重新生成 + 枪口坐标守卫（全部 ≤ 格子半径） |
| 四武将真实机制差异（起始武器/生命/移速/被动） | `gameData.ts` `CHARS` + `applyCharStats()` | 选人卡片截图逐项核对 |
| 兵种护甲与相克系统 | `Armor` + `WEAPONS[].vs` + `armorMul()` | 守卫断言相克已接在伤害路径；真机截图出现金色「克19」飘字 |
| 克制可读性（敌潮播报 + 飘字标记） | `announceStage()` + `damageLabel()` | 截图确认 toast 与飘字均正常渲染 |
| 敌人三国化命名与势力 | `ENEMIES` | 截图显示「黄巾力士 / 轻骑」剪影可区分 |

**实测对局数据**（`tools/shoot_game.py`，刘备，34 次采样）：
存活 92.6s、击杀 156、等级 7、终局同屏 9 只。击杀曲线线性、血量在 85~110 间震荡无死亡螺旋。

### 本轮踩到并已写进守卫的坑

`weaponById('pistol')!` —— 武器库换 id 后这一行返回 `undefined`，
但 `!` 非空断言把它一路放行，**tsc 与打包全绿**，运行时在 `refreshHud` 的 `o.def.name` 才崩，
表现是"**选人界面整个不渲染**"（异常发生在 `buildHud → create` 的中途，容器建了但没填内容，
`started` 停在 false，画面静止在初始态）。
现在守卫会断言：所有 `weaponById/enemyById` 字面量 id 真实存在 + **禁止对该类调用使用 `!` 断言**。

### 尚未做（按优先级）

1. **阵前单挑**（方向 B）—— Boss 战改一对一读招拆解，是本作最锐利的钩子，但尚未动工。
2. **兵种相克完整版** —— 阵型、势力敌潮、劝降收编。目前相克只在"伤害倍率"这一层。
3. **内容量补齐** —— 8 件武器 / 7 种敌人 / 8 个升级项，相对竞品（15~50 名将、40~200+ 技能）仍然偏薄。
   方向 A 的机制骨架已经搭好，接下来是往骨架里填内容。
