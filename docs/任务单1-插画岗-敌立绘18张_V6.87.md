## §2 通用硬约束（18 张逐条适用 · 冻结）

### §2.1 画面（出图时就要满足，否则后处理会毁图）

| # | 约束 | 为什么 |
|---|---|---|
| ① | **一律头朝左**（0°） | 渲染层靠 `scale.x = -1` 镜像（`DiveGame.ts:4154`）；头朝右的图会左右颠倒 |
| ② | **均匀浅色底**（近白 / 浅灰都行） | `key_fish_bg.py` 按**与画布边缘采样色的色距 < 34** 抠底 ⇒ 底色均匀即可，但**不带渐晕 / 棋盘格 / 地面阴影** |
| ③ | **发光只在材质内部与轮廓线，⛔ 不许外溢光晕** | 一旦有外光晕，抠底**完全失效**（alpha 会盖满全图）。这是 V6.4 定的铁律 |
| ④ | 画面内 **⛔ 无文字 / 水印 / 签名 / 箭头 / 标注 / 多个主体 / 重复部件 / 对比图** | 会进成品；水印还会被当成背景漏掉 |
| ⑤ | **细描边**（2px @512 ≈ 0.14px @36px） | 粗描边在 36px 下吃掉整个形状 ⇒ 全变成"黑块 + 白边" |
| ⑥ | **光源左上**，与全项目一致 | `MEMORY_ART.md` §光照 |
| ⑦ | 侧视、**正交投影**（无透视缩短）、单主体、不重叠 | 与现有 4 张真图同视角，图鉴网格里排一起才不像两批货 |
| ⑧ | 主体居中、占画幅 **60% ~ 80%**，四周留透明边 | 太小看不清细节；贴边会在裁切时被切掉 |

### §2.2 输出口径（后处理会自动做，供你预判）

| 项 | 值 | 依据 |
|---|---|---|
| 长边 | **512**（等比，不要求正方形） | `check_art.py` 的 `FISH_LONG = 512` |
| 短边 | ≥ **64** | `FISH_MIN_SIDE`，防"一根细条" |
| 裁切 | **包围盒须贴住 ≥ 3 边** | 补成正方形会让 `frameAspect` 变小 ⇒ 实机显示同比缩小 |
| 重心 x | **40% ~ 48%**（头朝左） | `FISH_CX`；>50% 才是真反向（整场鱼会翻） |
| 四角 | 透明 | 抠底干净的自动判据 |
| 边缘 | 抗锯齿的 1px 半透明边会被 `ERODE=1` 吃掉 | 不留白边，避免贴到深色水里出现亮边 |

## §5 出图 → 验收（**六步，一步不能漏，顺序不能反**）

```bash
# ① 抠底 + 裁到内容 + 长边缩到 512（输入 = 原始生成图，输出 = 真源）
python tools/key_fish_bg.py <生成图> web/src/assets/fish/<id>.png --long 512

# ② 尺寸口径：长边 512 / 短边 ≥64 / 裁到内容(≥3 边) / 重心 x 40~48% / 四角透明
python tools/check_art.py fish

# ③ 36px 剪影可分性：两两 IoU 必须 < 0.72（含"应到清单"，缺图会报「待出」）
python tools/check_fish_silhouette.py

# ④ 同步 web → cocos（⚠️ `_ASSET_RULES` 是手维护清单，漏一行 ⑥ 会红）
python tools/sync_art.py

# ⑤ meta 口径统一 `trimType: "none"`（给新落盘的图补 meta，必须在 ④ 之后）
python tools/gen_fish_meta.py

# ⑥ 总闸门
python tools/verify_cocos.py
```

⚠️ **`--strict`**：`check_fish_silhouette.py --strict` 会把"应到清单里但没落盘"也算 FAIL。
出图期间用默认（只警告）；**整批交完再跑 `--strict`**，那时它才是闸门。
