# L1 背景亮度规格 · V6.40（转插画岗）

> 面向：`cocos-game-artist`（角色 / 场景插画）
> 依据：用户反馈「第一关的背景图 **太亮** 有点不符合了 **也不能太暗**」
> 现状：`cocos/assets/resources/env/L1.png`（1536×984）

---

## 1. 问题：不是"亮"，是**层级断裂**

实测五层背景的平均亮度（`numpy` 直接算 sRGB 亮度，脚本见文末）：

| 层 | 平均亮度 | 中位 | P90 | 下方 1/3 | 观感 |
|---|---|---|---|---|---|
| **L1** | **0.585** | 0.581 | 0.785 | 0.551 | ⚠️ **浅海珊瑚礁**（蓝天 / 阳光 / 彩色珊瑚） |
| L2 | 0.250 | 0.241 | 0.354 | 0.178 | 中浅海 |
| L3 | 0.085 | 0.055 | 0.196 | 0.151 | 深渊岩壁 |
| L4 | 0.168 | 0.155 | 0.253 | 0.222 | 热泉（红移） |
| L5 | 0.058 | 0.043 | 0.093 | 0.076 | 最深渊 |

**结论**：L1 = L2 的 **2.3 倍**、L3-L5 的 **3.5~10 倍**。
它是**另一套配色逻辑**（亮色的热带浅海），跟 L2 以下不在同一个世界里。

**它的问题不是"太亮"，是"不该是浅海"** —— "深海回响"的第一层就应该是**深海**，
不是阳光能穿透的珊瑚礁。

---

## 2. 目标：一条连续、可读的深度阶梯

### 2.1 亮度（关键数字）

| 层 | 现状 | **目标** | 说明 |
|---|---|---|---|
| **L1** | 0.585 | **0.30 ± 0.03** | 压到"还有光、但光是稀的"——**仍是全五层最亮**，玩家能看出"这是最浅的一层" |
| L2 | 0.250 | **0.24 ± 0.03** | 微调即可（现状基本合格） |
| L3 | 0.085 | **0.14 ± 0.03** | ⚠️ **要提亮一点**：现状偏黑，岩壁细节全丢了 |
| L4 | 0.168 | **0.17 ± 0.03** | 保持（热泉层，红移） |
| L5 | 0.058 | **0.08 ± 0.02** | 微提，保底可读 |

**校验线**：**必须单调递降** `L1 > L2 > L3 > L4 > L5`（L4 因热泉自发光可允许小幅回升，但不得高于 L2）。
现状 L1 是断崖，L4 > L3 也是逆序 —— 两处都要修。

### 2.2 色相 / 饱和度

| 项 | 现状 L1 | 目标 |
|---|---|---|
| 主色相 | 青绿 + 阳光暖黄 | **冷青蓝**（`#1a4a5c` ~ `#0b2436`） |
| 饱和度 | 高（彩色珊瑚） | **中低**：整体降饱和约 40%，只留少量生物发光点色 |
| 光源 | 顶部阳光强烈、光柱密集 | **顶部微弱天光**：一道或两道稀疏光柱，不照到画面下半 |
| 高光 | 大面积受光（`P90 = 0.785`） | **P90 ≤ 0.50** —— 没有大面积亮部，只有零星发光点 |

### 2.3 内容（L1 仍是最富的一层，只是换题材）

保留"信息量"，换掉"阳光浅海"：

- **可保留**：珊瑚 → 改成**深水珊瑚 / 冷水珊瑚**（暗色、稀疏、带发光点）
- **要改**：海床沙地 → 换成**暗色岩床 + 沉积物**
- **要加**：稀疏的**下沉碎屑 / 海雪**、一两处**远处的微弱发光点**（暗示"深处有东西"）
- **要去掉**：阳光光柱照到海底、大面积明亮受光面、彩色热带珊瑚

### 2.4 安全区（**必须遵守**）

战斗画面中央要放潜航器与敌群，所以：

| 区域 | 要求 |
|---|---|
| 中央 60% × 60% | **低对比**：不要有强对比的物件（避免敌人剪影被背景吞掉） |
| 全图 | **无高频细节**（细碎纹理在 1304 宽的屏上会闪烁 / 摩尔纹） |
| 上 1/3 | 可以最亮（HUD 顶栏压得住） |
| 下 1/3 | 最暗（HUD 底栏与潜航器在这里，需要压得住） |

## 4. 附：量化脚本（改完自检用）

```bash
python - <<'PY'
import numpy as np
from PIL import Image
for i in range(1, 6):
    a = np.array(Image.open(f'cocos/assets/resources/env/L{i}.png').convert('RGB')).astype(np.float32)/255
    lum = 0.2126*a[:,:,0] + 0.7152*a[:,:,1] + 0.0722*a[:,:,2]
    print(f'L{i}  mean={lum.mean():.3f}  p90={np.percentile(lum,90):.3f}  '
          f'bottom={lum[int(lum.shape[0]*0.66):,:].mean():.3f}')
PY
```

**验收线**：`L1 ≈ 0.30`、且 `L1 > L2 > L3 > L4 > L5` 成立。

## 5. 附：如果暂时排不上插画岗

可以在引擎侧**临时压暗**（不改图）：`DiveGame` 的 `bgNode` 加一层乘法 tint
或在 `gBg` 叠一层暗色 scrim。**代价**：乘色只能压暗不能提亮，且是"整层一起压"，
压不到"只压阳光、保留发光点"这种精细度。**属于过渡方案，不是终态。**
