### 2.1 气泡雷族 `mine`（陷阱族）

| id | 名称 | iv | dmg | range | 价 | 特殊 |
|---|---|---|---|---|---|---|
| `mine` | 气泡雷 | 0.55 | 18 | 0 | 34 | 基础 |
| `mine_ch` | 连锁雷 | 0.55 | 15 | 0 | 68 | `chainR = 90` |
| `mine_o2` | 氧气雷 | 0.55 | **11** | 0 | 74 | `o2per 2.5` / `o2cap 10` |

**全局常量**（`world.ts` 顶部，集中放）：

| 常量 | 值 | 依据 |
|---|---|---|
| `MINE_ARM` | 0.40s | ⚠️ **不加就是"每次都在自己脚下炸"**。0.55s 一颗雷 + 布防 0 = 武器直接废掉 |
| `MINE_CAP` | 6 | ⚠️ 不封顶 ⇒ 稳态 21 枚（0.55s/颗 × 活 12s），退化成"地毯轰炸" |
| `MINE_LIFE` | 12s | 比一个波次短，保证场上雷是**这一波布的** |
| `MINE_TRIG` / `MINE_R` | 34 / 88 | 触发半径必须 > 敌人半径（最大 34 = 水母） |
| `MINE_CHAIN_R` | 90 | **略大于爆炸半径 88** ⇒ 相邻两枚必然互引 |
| `MINE_CHAIN_DEPTH` | 4 | ⚠️ 不限深会 A→B→A 无限递归（同 `explode` 共鸣腔的限深理由） |
| `MINE_O2_PER` / `MINE_O2_CAP` | 2.5 / 10 | 见 §4 配平红线 |

### 2.2 网族 `net`（控场族）

| id | 名称 | iv | dmg | 减速 | 灼烧 | 策反 | 价 |
|---|---|---|---|---|---|---|---|
| `net` | 网发射器 | 1.10 | 8 | 50% × 2.0s | — | — | 32 |
| `net_el` | 电网 | 1.10 | 6 | 55% × 2.5s | 6dps × 3.0s | — | 70 |
| `net_cv` | 驯化网 | 1.10 | **4** | 50% × 2.0s | — | **4s 内讧** | 74 |

- 网是**慢速弹**（420，枪弹是 780）⇒ 看得见飞出去的过程，能预判"网要在哪张开"
- 网**撞到第一个敌人或飞到射程尽头都张开**（两个入口共用 `openNet()`）
- ⚠️ **Boss 免疫策反**（减速仍然生效）—— 否则"网住 Boss 让它帮你打小怪"摧毁关卡设计

### 2.3 诱饵族 `lure`（聚怪族）

| id | 名称 | iv | dmg | 存活 | 吸引半径 | 价 |
|---|---|---|---|---|---|---|
| `lure` | 生物光诱饵 | 2.40 | 0 | 5.0s | 130 | 30 |
| `lure_bo` | 爆炸诱饵 | 2.40 | 55 | 5.0s | 130 | 72 |
| `lure_wl` | 光墙 | 2.40 | 0 | 5.0s | 90 × 3 个（间距 70） | 70 |

- **投放点 = 敌人密度最高处**（`densestSpot()`），不是最近敌人 —— 投在最近敌人身上没用，它本来就在朝你来了
- ⚠️ `densestSpot()` 是 O(n²)，**只在 2.4s 一次的投放时跑**，不要挪进每帧路径

## 3. 三把武器共用的底层改动：目标改写

驯化网 / 诱饵 / 光墙本质都是**改写敌人的寻路目标**。所以只加了一个函数：

```
enemyAim(e) → { x, y, mob }
优先级：内讧 > 诱饵 > 玩家
```

- **内讧**（`charmT > 0`）：追**最近的同类**，返回 `mob` 非空 ⇒ 接触时改咬同类
- **诱饵**：半径内有诱饵就追它（**阵营不变**，只是被牵着走）
- **默认**：玩家

⚠️ 内讧时**找不到同类要回落追玩家**，否则场上只剩一只被策反的鱼时会杵在原地，读作"卡死了"。
⚠️ 内讧敌人**不踩自己的雷**（`updateMines` 里跳过 `charmT > 0`）。

**新增的敌人三状态**（`Enemy` 接口）：

| 字段 | 服务于 |
|---|---|
| `slowT` / `slowMul` | 网 / 电网 |
| `burnT` / `burnDps` / `burnTick` | 电网 |
| `charmT` / `charmTick` | 驯化网 |

- ⚠️ **冲刺速度也吃减速** —— 否则"网住了但一个冲刺就飞走"，减速白给
- ⚠️ 抽出 `mkEnemy()` 工厂：加这三个字段时手写两处对象字面量**只改了一处**，TS 当场报错

## 4. 氧气雷的配平红线（计划书 §4.1）

击杀补氧会退化成"杀得越多活得越久"，**爆炸回氧比它更危险 —— 连击杀都不需要**。三条锁同时上：

| 锁 | 实现 | 位置 |
|---|---|---|
| ① 伤害砍 39% | `dmg 18 → 11` | `WEAPON_DEF.mine_o2` |
| ② 单次爆炸封顶 +10 | `o2cap` 参数（默认 `Infinity` ⇒ 老调用点不受影响） | `explode()` |
| ③ 同一敌人只计一次 | `seen: Set<Enemy>` | `explode()` |

缺任何一条 = "站雷堆里无限回血"，**直接把氧气机制作废**。

> 顺带：`explode()` 加 `o2cap` 是**纯增量**改动 —— 多重回声（`o2per 0.6`）不传 cap，行为一字不变。

## 5. 特效增强（本轮第 5 条需求）

### 5.1 诊断：三类都不够

| 类别 | 改动前 | 缺口 |
|---|---|---|
| **施法** | 只有 `muzzle` 事件，且 **sonar / arc 两族从不发** | ① 声呐/电弧完全没有开火反馈 ② 11 把武器共用一个黄点，加特林和重炮一样大 |
| **打击** | `hit` → 冲击环 + 斩击痕 + 火花，**全武器同一套** | 无法从特效判断"这是谁打的" |
| **击杀** | `kill` → 双层环 + 迸溅 + 位图碎块，**只按体型分** | 被炸死 / 电死 / 烧死结束得一模一样 |

### 5.2 事件层扩展（三个字段）

```
SimEvent.hit   += cause?: DamageCause
SimEvent.kill  += cause?: DamageCause
SimEvent.muzzle += fam?: WeaponFamily, power?: number
```

`DamageCause` 七个值：`bullet / pulse / arc / blast / burn / net / bite`

⚠️ **刻意没有 `charge`（前摇）事件** —— 蓄力进度完全能从 `weapon.timer / ivLast` 推出来，
模拟层不该为表现再维护一份"我正在蓄力"的状态（两份状态迟早不一致，且不会报错）。

### 5.3 施法：形状认族，尺寸认威力

| 族 | 形状 |
|---|---|
| sonar | **无方向**爆闪环（波前从机体往外扩，没有"枪口方向"） |
| gun | 尖头短闪 + 散射火花 |
| torpedo | 双层：冷焰芯 + 压力环（推背感） |
| harpoon | 细长直线喷流（"一根东西穿出去"） |
| echo | 三层光点**反向排列**（它打延迟爆发，枪口该是"聚"不是"放"） |
| acid | 锥形雾团（喷嘴雾化，不是火光） |
| net | 三根散开的细索 |
| arc / 未知 | 紫电火花 |

`power` 1/2/3 只改尺寸。**形状认族、尺寸认威力，两条信息正交。**

### 5.4 打击：7 种来源

| cause | 画法 |
|---|---|
| bullet | 冲击环 + **斩击痕** + 火花（唯一带方向的一套） |
| blast | 双层同心环 + 无方向迸溅，**不画斩**（爆炸没有来向） |
| pulse | 纯同心环 |
| arc | 沿来向拉一道**折线**残影（"电是折的"是链击的识别符） |
| burn | 只冒余烬，**环和斩都不画**（DoT 每 0.35s 一次，画环会叠出不散的亮圈） |
| net | 十字**网目**折线（"缠上了"而不是"打疼了"） |
| bite | 品红（与玩家造成的伤害**颜色切开**） |

⚠️ **暴击是覆盖式的**：不管来源，一律紫罗兰 + 加大。「这刀更重」优先于「这是什么武器打的」。
⚠️ 分化的是**形状语汇**不是**图元数量** —— 每条分支与原来持平或更省，靠加粒子做区分会在满屏时糊成一团。

### 5.5 击杀：基础三层 + 死因语汇

基础层（所有击杀都有）：双层冲击环 + 径向迸溅 + 位图碎块。
在它之上按 `cause` 补 1–2 个图元：

| cause | 终结语汇 |
|---|---|
| blast | 外扩余波（琥珀） |
| arc | 四条折线向外炸开 |
| burn | 余烬**上飘**（唯一带方向的死法语汇） |
| bite | 品红双环 |
| net | 网目**向内**收拢（与爆炸相反） |
| pulse | 干净同心环 |

### 5.6 前摇蓄力环（施法感的真正来源）

> **一个没有任何前摇的攻击，无论命中时多大特效，读起来都只是"突然发生了"。**

- 触发：`ivLast ≥ 1.4`（鱼雷 / 回声 / 诱饵）+ 开火前 28% 的装填窗口
- 外环：半径 36 → 9 **向内收拢**，透明度同步上升
- 内环：后 55% 才出现，反向同步收 —— 两环一正一反读作"在咬合"（单个环只读作"在缩"）
- ⚠️ **不能走 `pushShock` 池**：那是"一次性扩散"，收拢环要每帧重画，走池会每帧 push 一个把
  `SHOCK_CAP` 挤爆 —— 症状是打击特效**整体消失**（安静且致命）

### ⚠️ 顺手修掉的两个重复真源

1. **`WEAPON_NAME` / `WEAPON_FAMILIES` 在 `codex.ts` 与 `unlocks.ts` 各有一份** ——
   加三个族时只改了 codex 那份，unlocks 那份漏了，TS 当场报 "missing properties: mine, net, lure"。
   两份定义看着"只是重复"，实际是**每个新增武器族都要记得改两处**的陷阱。现在只有 codex 一份。
2. **`SimEvent` 里有两个 `muzzle` 定义**（加字段时没删旧的）—— 联合类型会把它们合并成
   `fam`/`power` 可选，读的时候 TS 报"属性不存在"。已删旧的一条。
