## 1. 硬约束（每条提示词都必须满足，否则后处理会毁图）

| # | 约束 | 为什么 |
|---|---|---|
| ① | **纯白背景**（近白、均匀、不带渐晕/棋盘格） | 抠底靠"从四边泛洪 + 紧容差"，背景越干净越稳 |
| ② | **发光只在内部与轮廓线，不许外溢光晕** | 一旦有外光晕，亮度阈值抠底**完全失效**（alpha 会盖满全图）。这是 V6.4 定的铁律 |
| ③ | **画面内不许有文字 / 水印 / 地面阴影 / 多余物件** | 文字会进成品；阴影会把泛洪"桥"到武器上 |
| ④ | **3/4 侧视带俯角**，能看到武器本体 + 底部圆形炮座 | 与已有 15 张立绘同视角，卡面里排在一起才不像两批货 |
| ⑤ | **同一个圆形金属炮座**（武器类） | 武器**共用同一套「装载器」**，底座一致本身就是"同一套挂载系统"的可读性 |
| ⑥ | 单张主体**居中、占画幅约 86%** | 后处理按 0.86 填满 1200×600 画布，主体太小会显得卡面很空 |
