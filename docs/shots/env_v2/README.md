## 减密工具

```bash
# 对齐参照图密度 + 裁到目标画布（改游戏图的标准命令）
python tools/thin_fish.py docs/shots/env_v2/L4v4b_lift.png \
  --out docs/shots/env_v2/L4_thin \
  --match cocos/assets/resources/env/L4.png \
  --canvas 1536x984

# 只量密度，不出图（★ 只能对 PNG 跑）
python tools/measure_fish.py cocos/assets/resources/env/L*.png docs/shots/env_v2/L*_thin.png
```

⚠️ **密度判据只能对 PNG 跑**：webp q=95 也有 0.06% 像素偏差 >8（均值 1.86）——
肉眼不可见，但检测阈值只有 7，会把编码噪声当成鱼（L4 实测 PNG 60 条 vs webp 84 条）。
`measure_fish.py` 现在会自动警告有损格式。

### ⚠️ 五次返工记录（同一根因的五种表现，别再走回头路）

| 尝试 | 现象 | 真因 |
|---|---|---|
| 逐团搬贴图补洞 | 减密后**反而变密**（51→86） | 搬来的块带鱼 |
| 同上 + 扩大 donor 搜索 | 接缝被检出成鱼 | 块与原地亮度不连续 ⇒ **接缝本身是高频** |
| 换成 24px 块中值背底 | 无接缝但**一片方块** | 块中值有梯田 |
| 按"高频强弱"整图取舍 | 鱼只剩一圈**光环**（51→72） | 抗锯齿边\|残差\|只有 1~3，落在"弱高频"里 |
| **连通域 mask + 归一化卷积** | ✅ 无缝无块，密度可收敛 | —— |

另两条判据级教训：
- **检出的是"团"不是"条"**：一条鱼常被切成 2~3 团 ⇒ 一次补洞必偏多 ⇒ 必须**迭代收敛**
  （每轮重新检测，且上一轮保留的鱼要**先认领**再选新的，否则第 2 轮会把它们当待删删掉）。
- **判据必须单一真源**：检测口径散在两个文件时，会出现"工具说对齐了、量出来还差 8 倍"。
