工程与工具的完整说明在 **`README.md`（根目录）** 与 **`cocos/README.md`**，这里只列**你必须先确认的三件**：

| 需要什么 | 干什么用 | 缺了会怎样 |
|---|---|---|
| **Cocos Creator 3.8.8** | 打开 `cocos/` 跑 `Dive.scene` —— **唯一能看到画面的地方** | 什么都验不了 |
| **Python 3 + Pillow** | `tools/` 的预览 / 后处理 / 同步脚本 | 出图与预览跑不了 |
| **Node** | `tools/dive_sim_smoke.js`（无头冒烟） | 只能靠 `verify_cocos.py` |

```bash
# ① 真源 → cocos 副本（改过 shared/ 必跑）
python tools/sync_shared.py
# ② 美术同步（--check 只检查漂移，不写盘）
python tools/sync_art.py
# ③ 七阶段闸门：漂移 / 编译 / 冒烟 / 视图类型 / 美术 / 工程 / 模块图
python tools/verify_cocos.py
```
