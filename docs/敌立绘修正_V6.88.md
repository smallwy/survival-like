## §2 ① 抠底工具盲区（已修，根因）

### 症状

`orbit` 的细触须绕成一个**封闭环**。抠底后：

```
alpha>128 占 64.6%
其中"颜色接近浅白(min>200)"占 49.1%   ← 这一片就是没抠掉的背景
raw 图正中心 RGB = [253,253,254]（背景）
抠底后正中心 RGBA = [253,253,254,255]（alpha 255 ⇒ 原封不动留下）
```

⇒ 环内那片背景**整片留在图上**，实机读作"一个大白盘"，**36px 剪影也被填成实心盘** ⇒ 中空这个识别特征被抠底吃掉了。

### 根因

`tools/key_fish_bg.py:9` 的算法是：

> 「**从画布四边泛洪、只清除与边缘连通的亮像素**」

闭合轮廓把内腔**围在里面** ⇒ 泛洪进不去 ⇒ 判为"非背景"。这是算法的固有局限，**任何中空形状（环 / 圈 / 空心壳）都会中招**。

### 处置

新增**第二轮"内部背景补种"**（`key_out(..., inner=True)`，可用 `--no-inner` 关闭）：

- 三件套判据：**颜色接近背景基色** + **未与画布边缘连通** + **面积 ≥ 全图 0.4%**；
- 面积门槛的用途是**放过主体自身的浅色高光**（实测 < 0.2%），只清真正的背景岛。

### 影响面（17 张有 raw 的图逐张对比，关闭 vs 开启）

| 图 | 关闭 | 开启 | 差值 | 判读 |
|---|---|---|---|---|
| `orbit` | 64.6% | **15.1%** | −49.4 | ✅ 预期修复 |
| `boss_angler` | 37.8% | **35.6%** | −2.2 | ✅ 张嘴形成的**口腔内腔**，删对 |
| `brood` | 73.4% | **72.3%** | −1.1 | ✅ 卵孔内圈的一小圈浅色高光，孔中青绿光**保留** |
| 其余 14 张 | — | — | **±0.0** | 逐像素一致，无误删 |

### 连带收益

剪影闸门里 `brood ↔ orbit`（IoU **0.736**，上一轮 FAIL）**自动消失** ——
`orbit` 的剪影恢复成中空环后不再撞车。上一轮我把这对判为"判据盲区、不改"，
**结论只对了一半**：中空本来就该在，是抠底把它填实了。

## §4 ③ spitter 重出

| | 旧 | 新 |
|---|---|---|
| 尺寸 | 512×358 | **512×244** |
| 结构 | 三层球（上囊 + 中体 + **下球**） | 单囊体 + 唯一背膜囊 |
| 色调 | 黄绿 | **黄绿**（中途一版跑成褐金已弃） |
| 判读 | 玻璃/乐器/烟斗 | 趴着的软体生物 |

提示词上真正起作用的两句：

1. 「整个身体的**底部是一条连续向下弓起的圆弧**，不许有第二个球、不许有分叉的腿、不许有底座、不许有支架、不许有烟斗形弯管」
2. 「整体色调是**鲜明的黄绿色**半透明软体，**不是褐色、不是土黄、不是古铜色**」

⚠️ **反面经验**：只写"不要像器皿"没用；要**逐个点名否掉具体的错误结构**（球 / 腿 / 底座 / 弯管）与**具体的错误色相**（褐 / 土黄 / 古铜）。

## §6 残留：`brood ↔ kamikaze` 0.722（**既有问题，非本轮引入**）

- `brood` 512×445（72.3% 不透明）· `kamikaze` 512×375（67.0%）—— 尺寸差 **1.19 倍**，不算大；
- `tables.ts` 显示两者**在多个层同时出现**（如 `kamikaze 0.07 / brood 0.05`、`brood 0.06 / kamikaze 0.05`）；
- 它们的**颜色**（青绿卵孔 vs 红裂缝钙质壳）与**行为**（产卵巢 vs 自爆冲撞）完全不同。

⇒ 判据盲区（涂黑剪影抹掉了"卵孔"与"螺壳尖"），但**同层出现 + 尺寸接近**这一条让它比单纯的盲区更该处理。
**建议**：给 `kamikaze` 一个更"异形"的轮廓方向（螺壳的尖与开口再夸张些），**待用户拍板**。
