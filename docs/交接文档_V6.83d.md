## 1. 这是个什么项目

**深海 · 生物发光题材的幸存者类（Brotato-like）游戏**。5 层 × 4 波的整局（15 分钟），
层间商店三选一 Build，**氧气就是唯一血条**。

| 支柱 | 一句话 |
|---|---|
| **氧气即血条** | 随时间流失 + 被敌人打都扣同一个池子；捡骨回氧 |
| **五层递深** | 阳光带 / 弱光带 / 午夜带 / 热泉带 / 深渊带，各有专属环境压力 |
| **19 种敌人 + 2 Boss** | 区分度**全在行为**（绕圈 / 冲刺 / 方向盾 / 裂体 / 远程…），不靠换颜色 |
| **Build 深度** | 10 族 / 30 形态武器 · 30 被动 · 3 潜航器 · 64 张卡池 |

**当前唯一的开发真源是 `shared/` + `cocos/`**（`web/` 是已冻结的 Phaser 原型，只当素材真源用）。

## 3. 工程结构 —— 哪份是真源（★ 最容易搞错的一节）

| 路径 | 是什么 | 能不能手改 |
|---|---|---|
| `shared/dive/` | ★★ **引擎无关真源**（模拟层 / 表 / 类型） | ✅ **只改这里** |
| `cocos/assets/scripts/shared/` | **自动生成副本** | ⛔ 手改会被 `sync_shared.py` 覆盖 |
| `web/` | Phaser 原型 —— **2026-10-13 冻结，非权威源** | ⛔ 不改逻辑；只当素材真源 |
| `web/src/assets/` | ★ **美术真源**（env / 机体 / 鱼 / 立绘） | ✅ 改美术改这里 |
| `cocos/assets/resources/` | 美术副本（含 `.meta`） | ⛔ 由 `sync_art.py` 写 |
| `cocos/` | Creator 3.8.8 工程（场景 `Dive.scene`） | 场景/prefab 手改要谨慎 |
| `tools/` | 验证 / 出图 / 普查脚本 | ✅ |
| `docs/` | 规格与复盘正文 | ✅ |
| `.workbuddy/memory/` | 判据与铁规（MEMORY.md + 两个分册） | ✅ |

### 改了 `shared/` 之后的固定三步（★ 少一步就是静默故障）

```bash
python tools/sync_shared.py     # ① 真源 → cocos 副本
python tools/verify_cocos.py    # ② 7 阶段闸门
cd web && npx tsc --noEmit      # ③ web 端类型检查（改了 shared 必须过）
```

- 漏 ① ⇒ **编辑器里跑的是旧代码**（改了没生效，却看不出哪里不对）
- 漏 ③ ⇒ 原型侧静默坏掉（`web` 虽冻结，但它引同一份 `shared`）

改了**美术**则用 `python tools/sync_art.py`（web 素材 → cocos 副本 + 校验 `.meta`）。

## 7. 两个普查工具 · 当前数据结论

这两个脚本是 V6.82 之后新加的 —— **它们回答"表里写了"和"玩家真的遇到"之间的差**。

### 7.1 刷怪普查（`census_enemies.js`，12 局实测 2026-10-16）

```
到达率：L1 阳光带 ██████████ 100%  (12/12)
        L2 弱光带 █████████▏  92%  (11/12)
        L3 午夜带 ███▎        33%  ( 4/12)
        L4 热泉带 ▊            8%  ( 1/12)
        L5 深渊带 ▏            0%  ( 0/12)
结局：12 局全部阵亡 · 0 局打通
```

> ⚠️ **12 局是小样本**，逐批有 ±10% 波动（L3 历史值在 33–42% 之间跳）。
> 但**「L5 = 0 / L4 <10」这个结论在多批样本里稳定成立**，不看单点数值。

★★ **后 40% 的内容，玩家在正常一局里根本看不到。** 这是当前**最大的风险**，
比"内容不够"更该优先处理 —— **到达率是所有内容的乘数**。

**先分流再动手**：换一个**激进走位**的 bot 重跑（现有 bot 是"保守走位 + 优先捡骨"）。
- 激进 bot 能到 L4/L5 ⇒ 是**走位策略**问题，不是难度墙；
- 激进 bot 也到不了 ⇒ 是**真实的氧气/难度墙**，要调数值。

已做的改善：所有生物都**至少落在一个到达率 ≥40% 的层**（V6.79 曾把「盘旋猎手」放在 L1，
而模拟两次都死在 L1 ⇒ 玩家永远遇不到；V6.82 的「牧群者」同坑复发，平均每局 0.2 只，修完 → 1.8）。
**V6.83 把 `mimic`/`bloom` 从规格写的 L4–L5 下放到 L3（33%）** —— 照抄规格等于没做。

### 7.2 经济普查（`probe_economy.js`）

| 指标 | 改造前 | A+B 之后 |
|---|---|---|
| 买走 | 15.2 张 | **31.6 张** |
| 花掉 | 543 金 | **1424 金** |
| 重掷 | 0 次 | **13.3 次** |
| **买不起剩在那的** | 0.1 张 | **0.0 张** ⚠️ |

★★ **每局收入 ≈ 3940 金，只花掉 36%。**
根因**不是"掉太多"，是消费端封顶** —— `dead()` 会滤掉已满级 / 不可用的卡，
**一局能买的上限就那么多，买满之后钱完全没用**（连重掷都没意义，没新东西可刷）。
⇒ 需要 **C（给钱第二个用途）**：推荐 **C1 商店买氧**（氧气是唯一血条 ⇒ 天然的、
无限的、且**随难度自平衡**的消耗口）。

## 8. 铁规速查（★ 最会咬人的）

完整 18 条在 `.workbuddy/memory/MEMORY.md`。**下面这些是换机器后最容易重复踩的**：

| # | 铁规 | 一句话后果 |
|---|---|---|
| **1** | 以 `shared/dive` + `cocos` 为准，**先落文件再写引用** | Cocos 解析失败**不登记依赖边** ⇒ 编辑器全黑而验证全绿 |
| **2** | **"没报错 + 图也在" ≠ "画出来了"** | 静默失效五类（层序/漏清/读只写不读的字段/回调里直接画/**后写的那条永不执行**） |
| **3** | Cocos `Graphics` **无 translate/rotate/save/restore**；`Gfx` 世界 y = `H−simY` | 裸 Sprite 要自己翻 y；**写混 = 上下镜像，不报错** |
| **6** | 位图 / 背景图 `.meta` 必须 `trimType:"none"`；比例只有一个口径 | `auto` 整体偏移 ⇒ **挂点错位而不报错** |
| **7** | ⛔ **写文件禁直写**（先截断后报错 = 文件已清空） | 临时文件 + `os.replace`；恢复源 `~/.workbuddy/file-history/` |
| **10** | AI 出图**必须本地后处理**（比例 / 挂点 / 开孔） | 判据：拉伸 ≤1.8× + 轮廓内透明占比 ≤2% |
| **14** | **亮边是"UI 框"的语汇** | 封板/补板/兜底轮廓一律走**暗缝**；**半闭合亮弧同罪** |
| **15** | **两张表必须互相对账**，⛔ 不手写第二份清单 | 加内容忘了接图鉴 ⇒ 只表现为"永远显示剪影"，**不报错** |
| **17** | 凡"**按权重抽一个**"，必须**归一化**，⛔ 不用顺序阈值 `if/else` | 深层 `Σ其他 > 1` ⇒ **尾部恒定饿死**，而**表里权重看着都对** |
| **18** | 判定"某机制存不存在"**不能只 grep 期望的函数名** | 先 grep **被影响的状态**；"分式记账"必须验证 Σ 与实际增量闭合 |

> ⚠️ 另有两条**操作纪律**（写文档/记忆时）：
> ① **按行号连做多次删除必须从后往前**；② **切片重排字符串极易复制出一份**
> —— 要么用单点 `replace`，要么加断言自检（本项目为此连栽两次）。
