## 0. 一句话

**盘旋猎手不正面冲你 —— 它绕着圈越缩越近，贴身才咬。**
直线后退对它无效（它不从正面来），玩家必须**横向位移 / 绕桩**。

## 4. 唯一的新逻辑（最小参考片段）

`world.ts` 的两处常量：

```ts
/** 盘旋猎手：停止收缩的半径（px）。太接近会贴脸抖动 */
const ORBIT_R_MIN = 46
/** 盘旋猎手：径向收缩系数（× speed）。0 = 纯绕圈永不近身，1 = 直冲 */
const ORBIT_SHRINK = 0.45
```

`updateEnemies` 的分支链里加一段（**必须排在 `:879` 的 `e.fx/e.fy` 赋值之后**，否则朝向会被覆盖）：

```ts
} else if (e.kind === 'orbit') {
  // ---- 盘旋猎手：切向绕圈 + 半径收缩（螺旋），从不正面冲 ----
  const ang = Math.atan2(e.y - this.py, e.x - this.px)
  const rad = Math.hypot(e.x - this.px, e.y - this.py) || 1
  // 切向单位向量 = 垂直于「敌 → 我」的方向 ⇒ 绕圈
  const tanX = -Math.sin(ang), tanY = Math.cos(ang)
  // 径向单位向量（朝我）⇒ 越绕越近；小于下限就停止收缩
  const inX = (this.px - e.x) / rad, inY = (this.py - e.y) / rad
  const shrink = rad > ORBIT_R_MIN ? ORBIT_SHRINK : 0
  e.x += (tanX + inX * shrink) * e.speed * slow * dt
  e.y += (tanY + inY * shrink) * e.speed * slow * dt
  // 朝向走**切向**（不是朝我）：玩家一眼看出"它在绕，不是在冲"
  e.fx = tanX; e.fy = tanY
}
```

## 8. 可发现性复盘（2026-10-15 晚 · 用户实机反馈「都没看到新的生物」）

**症状**：用户玩了一局 —— 「没有太感觉到，都没看到新的生物」。

**归因**（先跑普查，不猜）：headless 跑整局、统计**每层实际刷怪构成** ——

| 层 | swarm | dash | drift | armor | **orbit** | orbit% |
|---|---|---|---|---|---|---|
| L1 | 155 | 16 | 0 | 0 | **0** | **0.0%** |
| L2 | 89 | 62 | 32 | 13 | **18** | 8.4% |

★ **两次整局模拟都死在 L1 / 早 L2（o2 = 0）** ⇒ **一次典型的短局根本走不出 L1，而 L1 的 orbit 占比是 0。**

**真实原因不是 bug，是配比**：`orbitRatio` 照抄了「**L1 教学层不给机制**」那条既有规则
（重甲 / 漂移水母同样 L1 = 0）。但那条规则是为**机制型**敌人写的（重甲逼你换武器、水母是肉盾）；
盘旋猎手是**行为型** —— 它不要求玩家学任何新系统，只改"怎么躲"。
⇒ 把它一起关在 L1 之外，等于**做了一件在玩家最常待的地方看不到的内容**。

**处置**：L1 `orbitRatio` **0 → 0.06**、L2 **0.08 → 0.12**。复跑普查：

| 层 | orbit | orbit% |
|---|---|---|
| L1 | **9 / 12** | **8.9% / 7.2%**（两个种子） |

### ★★ 教训（后面 13 种都要用）

**做完一个敌人，先跑一遍"整局刷怪普查"，看它在玩家实际能到的层里出现几次。**
占比写在表里 ≠ 玩家看得见 —— **「我加了内容」和「玩家遇到了内容」是两件事**。
（普查脚本：`tools/` 下临时脚本即可，读 `DiveWorld.spawned` 按层差分。）
