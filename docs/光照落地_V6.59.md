## §2 ⚠️ 本轮挖出的真 bug：V6.56 把运动方向写反了

**证据（git）**：
```
48c9e86~1  interface Mote { … vy: number … }        // 旧
           m.y += m.vy * dt                          // vy = -6 ~ -20 ⇒ m.y 减小 ⇒ 向上
           // 注释自己写着"原 vy = -6~-20 方向是对的（向上掠 = 下潜感）"

48c9e86    m.y += mul[0] * this.scrollV * m.jit * dt // scrollV = +46，mul = +1.00 ⇒ m.y 增大 ⇒ 向下
           // 注释把旧值写成了 "+6~20"（丢了负号）—— 符号就是这么丢的
```

**结论**：V6.56 提速的同时**把方向翻了个个儿** —— 颗粒与远景鱼群在正常带里**向下飘**（= 上浮），
只有 L4 因为 `MOTE_MUL` 取负才"向上"。这正好反掉 V6.52/V6.53 要的「下潜感」，
而且**不报错、不崩溃、图也在**（典型静默失效第 5 例）。

**修法**：`y += … ` → `y -= …`（两处：`drawBg` 的颗粒、`drawSchools` 的鱼群）。
`MOTE_MUL` **一个数都没动** —— 它是"相对正常方向的倍率"，正常方向由符号定。

**入长期记忆的铁律**：`SCROLL_BASE` 恒为正 ⇒ 消费者**一律 `y -=`**。写成 `+=` 得到的是"上浮"。

### 3.2 绘制顺序 = 物理顺序（**不能调**）

```
远景鱼群  →  能见度雾  →  探照灯 + 按带光源  →  扫带 / 水压环
   最远        压水体           光源在雾之上            压全场
```

光源画到雾**下面** ⇒ 屏幕边缘的光柱被雾掐掉一半，看起来像渲染 bug（V6.51 §3.2）。

## §4 三处被预览图否掉的写法（**别再走回头路**）

`tools/preview_lights.py` 的合成图上当场看出来的三个症状 —— 每个数值都合法，合起来是错的：

| 写法 | 症状 | 修法 |
|---|---|---|
| 雾 **8 环** + 线性 α 爬升 | 环与环之间的 α 台阶肉眼可见，`rIn` 处留一条**硬圆环** | **12 环** + `α ∝ k^1.6` |
| 探照灯"每档算一个 α"（5 档厚描边） | 深底上显出**一圈圈靶环** | 改**同 α 由外向内叠**（覆盖次数 = 亮度） |
| 光柱 3 层**横向偏移 16px** | 读作"三根并排的条纹"，不是一道光 | 三层**同心嵌套**（宽淡包窄亮） |
| 烟柱 4 段**间距 2.6w**（半高 0.25w） | 4 个独立的**橙色飞碟** | 间距收到 `0.55w` + 椭圆加高 ⇒ 连成**柱** |

> **规律**：`drawFog`（要空心）用**环带**；`drawLamp`（要实心）用**同 α 累叠**。
> 两者都用同心圆，但"每像素被覆盖几次"的读法相反 —— 抄错就得到靶环 / 空靶。

## §6 实机确认清单（Creator 3.8.8 · `Dive.scene`）

静态全绿只是**下界**。以下 7 条必须在引擎里目视：

1. **L1→L5 逐带下潜**：每一带是否都有"光的主角"（光柱 / 残光+灯 / 荧光 / 热泉 / 点阵）？
2. **颗粒方向**（§2 的修复）：**悬浮物是不是向上掠过**？向下飘 = 符号又写反了。
3. **远景鱼群**同样向上掠过（L4 除外，那一带向下）。
4. **光柱**：读作"几道透下来的光"还是"一片光幕/栅栏"？后者就减 `BEAM_N` 或宽度。
5. **探照灯**：是柔和光晕还是能看到靶环？有环 ⇒ 层数不够，加 `ATMO_QUALITY` 那档的 8→12。
6. **雾**：是"看不远"（同色浑浊）还是"我瞎了"（黑）？后者说明 tint 取错了色。
7. **L4 暖色反转**：L4 比 L3 亮、比 L3 暖吗？这是"打破单调递减"的节奏点。
