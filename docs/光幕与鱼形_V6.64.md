## §0 结论先行

| 项 | 判定 | 客观判据 | 结果 |
|---|---|---|---|
| 光柱"太突兀" | **根因是几何，不是亮度** | 横向 alpha 剖面（屏宽 20%~80%）的 `min/max` | 旧 `0.00` → 新 **`0.39`** |
| 光柱"柱子各自在叠" | **不该用"再叠一层"实现起伏** | 剖面上应看不到周期性尖峰 | 已消（见 §1.3） |
| 远景鱼"不像鱼" | **缺三个结构事实** | 缩到目标显示尺寸 100%（26px）看剪影 | 已出，见 §2 |

**一句话**：阳光在水面**没有遮挡物**时它就是**一整片**；波纹调制的是**亮度**，不是"有光 / 无光"的开关。

## §1 光柱 → 光幕（V6.61 的前提是错的）

### 1.1 三次修正的链条

| 版本 | 做法 | 用户反馈 / 实测 |
|---|---|---|
| V6.60 | 4 条**等距平行**直条 | 「视觉上能看到平行的柱子吗」—— 且不物理（无衰减无扩散），两头不靠 |
| V6.61 | 4 条 → **汇聚消失点** + Beer–Lambert `e^(−1.75t)` + 分波长吸收 + 散射扩散 + 逐条独立相位 | 「现在是 **3 个柱子**，阳光应该是**平面的**，柱子太突兀」 |
| V6.64a | 条数 **4→13** + 宽度正弦行波 + 相位递增（间距 ≈100px） | ⚠️ **实测剖面 `min` 仍 = 0** —— 缝只是从 326px 缩到几十 px，本质没变 |
| **V6.64b** ✅ | **拆两层**（见 1.2） | 剖面 `min/max = 0.39` = **连续光幕** |

**V6.61 的前提错误**：放射柱隐含"水面有**离散遮挡物**"（云隙光 / 船影）。
但 **L1 / L2 是开阔水域，水面无任何遮挡** ⇒ 阳光是**一整片同时入射**。
玩家该看到的是「整片水从上方被照亮」，再叠加水面波纹造成的**连续明暗起伏**。

### 1.2 正确模型：**整片基底 + 乘性起伏包络**

```
① 基底光幕 BEAM_SHEET_A ── 铺满全屏宽 · 随深度 e^(−1.75t) 衰减 · 分波长吸收
                            ↓ 保证剖面处处 > 0（"平面"的那一半）
② 起伏包络 BEAM_ENV_GAIN ── 13 条行波只贡献一个乘性因子 (1 + env×GAIN)
                            ↓ 在基底之上加起伏，允许有疏密，但不会掉到 0
最终画出来的只有「一片」：alpha 剖面 = 基底 × (1 + 包络)
```

### 1.3 ⛔ 走过的弯路：不能用"再叠一层半透明形状"做起伏

第一版 V6.64 保留"逐条各画一个平行四边形"的做法，只把条数加到 13。
结果叠出来的 alpha 是**加法**（`a₁ + a₂(1−a₁)`），条带中心必然比基底高出一档
⇒ 预览图上清清楚楚看得出 **13 道竖着的亮带**。物理上也不对：水面波纹调制的是**入射强度**，
不是"再盖一层光上去"。

⇒ 正确做法就是 1.2：**条带不单独画，只在剖面里贡献数值**。

### 1.4 实现要点（`DiveGame.ts`）

| 函数 | 职责 | ⚠️ 坑 |
|---|---|---|
| `beamEnvelope(y, yBot)` | 算某一行的横向起伏包络，**1.5px 分辨率台阶函数** | **含透视收敛（`k`），每行都要重算**，不能全屏共用一条 |
| `beamSheetStrip()` | 逐段画条带 | **相邻段必须首尾相接** —— 留缝 = 一片竖条纹 |

- 1.5px 分辨率在 1304 宽上有 870 档，肉眼看不出一档一档；每多一档只多 2 个顶点。
- 图元预算：基底 vs `seg 段`（3 段 × 宽向分段）；条带本身**不占图元**。

### 1.5 常量与判据

| 常量 | 值 | 说明 |
|---|---|---|
| `BEAM_SHEET_A` | `0.115` | 基底 alpha。调参**只看剖面数字**，别按"看着太淡"调高 —— 外面还要乘包络 |
| `BEAM_ENV_GAIN` | `0.35` | 0 = 一片死平（灰纱）；太大 ⇒ 波谷趋 0 又变回明暗分明的竖条 |
| `BEAM_W_BASE` / `BEAM_W_AMP` | `80` / `36` | 有基底兜底后，条带只需提供起伏，不再靠自身宽度补缝。**不能再宽**（接近间距 2× ⇒ 起伏被抹平） |
| `BEAM_COL_TOP` / `BEAM_COL_BOT` | `0xfff2dc` / `0xcfe9fb` | ⚠️ **别调回 `0x93cdf0`** —— 变色太快，画面中间会留一条横向色阶带 |
| `BEAM_ABSORB` / `BEAM_DIFFUSE` | `1.75` / `0.8` | Beer–Lambert 指数衰减 + 散射横向扩散 |

**判定闸门**：`min/max > 0.3` = 连续光幕；`≈ 0` = 离散柱子。实测：

```
旧(V6.61): min=  0 max= 26 mean=  5.6 min/max=0.00  -> 离散柱子
新(V6.64): min= 17 max= 44 mean= 33.3 min/max=0.39  -> 连续光幕 OK
```

## §2 远景鱼形（V6.64）

### 2.1 从"椭圆 + 三角尾"到"单多边形鱼形"

**原来的问题**：椭圆**没有任何鱼的结构特征** —— 没有最厚点的位置、没有尾柄收细、没有分叉尾鳍。
压到远景尺寸（26~78px）后读作**一片叶子 / 一只蝌蚪**。

**三条结构事实，缺一个就散**（`FISH_OUTLINE`，15 点归一化轮廓）：

| # | 事实 | 取值 | 为什么 |
|---|---|---|---|
| ① | **最厚点在体前 38%**（不是正中） | `[0.38, 1.00]` | 鱼的重心靠前 = 「头在这一端」的读法 |
| ② | **尾柄收细，但不过头** | `0.82` 处 `0.38` | 有"腰"才有"尾巴"；**收到 0.22（第一版）= 26px 上只剩约 2px = 断开** |
| ③ | **尾鳍纵向张开、宽于体高** | 尾叶半高 `1.05` > 体高 `1.00` | 第一版 `0.70` **比身体还窄** ⇒ 整体读作**飞镖 / 箭头** |

### 2.2 额外收益：图元减半

**1 个图元 / 条**（原来是椭圆 + 三角 = 2）。L1 的 46 条从 **92 → 46** ——
省下的预算正好给 V6.64 的基底光幕。

### 2.3 摆动只在尾部

`swing` 用 `wTail = max(0, (u−0.6)/0.4)` 加权 ⇒ **头几乎不动、尾巴摆幅最大**。
整条平移读作"贴图在滑"，不是"鱼在游"。
