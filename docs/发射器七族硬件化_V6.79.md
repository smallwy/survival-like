## 1. 结论

**用户第二轮的同一句话，根因不是审美，是生产方式的断层。**

| 轮次 | 用户原话 | 我一直改了什么 | 为什么没解决 |
|---|---|---|---|
| V6.70 | 「只有脉冲机关枪装在炮头上是很适配的，其他的器械都没做好吗」 | 把**枪族 / 鱼雷族**的前端重做成真炮管 | 只改了两族 |
| V6.73 | —— | 给**全族**补了一个共用的尾部**机匣** | 解决了"有没有身体"，**前端族特征一直是符号** |
| V6.79 | 「为什么还有自己画的箭头这些 脉冲机关枪是正确的 不都要改吗」 | **5 族前端全部硬件化** | ← 本轮 |

⇒ **"都是装上去的零件"才是判据**，不是"颜色对不对 / 好不好看"。V6.73 的机匣改造让断层更难看出来：
每族都有金属屁股，前端却还是弧线、实心圆、折线 —— 玩家的读法是"**这件武器做了一半**"。

用户圈的东西定位：
- **"箭头"** = **鱼叉族**（旧版是 2.2px 细线 + V 形倒钩）；
- **"炮塔图形"** = **声呐 / 回声族**（旧版都是"一个实心圆 + 几圈细弧"）。

## 2. 七族形态表（族与族的差别**全部落在剪影上**）

| 族 | 剪影 | 实现 | 变体差异 |
|---|---|---|---|
| `gun` | 双平行管（大口径） | V6.70 起已硬件（`barrel` ×2） | 加特林 +2 细管；霰弹加喇叭口 |
| `torpedo` | 集束三管 | V6.70 起已硬件（`barrel` ×3） | 单粗管 / 集束 |
| `sonar` | **外扩喇叭**（`h0<h1`）+ **开口环** + 口内振子 | `metalTube` | `sonar_fc` 喇叭更大 + 口部双环；`sonar_rs` 口外三振子 |
| `acid` | **收细喷嘴锥**（`h0>h1`）+ 喷口内孔 | `metalTube` | `acid_fd` 尾端配重环；`acid_ra` 口外三液滴 |
| `harpoon` | **粗杆 + 亮箍 + 三根向前张开的齿** | `metalTube` ×N | `harp_tr` 三根平行杆 + 更张更长；`harp_cb` 尾端配重环 |
| `echo` | 短粗筒 + **封闭厚盘** + 中心凸起 | `metalTube` + 端面盘 | `echo_mu` 盘外三振子；`echo_fo` 盘外粗环 |

★ **声呐 vs 回声的分界 = 开口 vs 封死**。它们曾经都是"一个圆"，正是**必须靠剪影分开**的那一对：
现在一个是**张口的喇叭**（能看见暗腔 + 振子），一个是**封死的厚盘**（实心 + 中心凸起）。

## 3. 四条体积线索（金属件的全部内容）

`barrel()` / `metalTube()` 逐条复刻同一套语汇，保证玩家看不出"这两族是两套零件"：

1. **管身 = 四边围成的锥形圆柱**（不是一个线条）；
2. **上缘受光带 / 下缘暗线**（上亮下暗 = 圆柱感）；
3. **轮廓走暗缝**（`UI.abyss` 半透明）—— ⛔ **绝不描本色亮边**：闭合或半闭合的亮色轮廓
   就是"UI 框"的语汇（铁规 14），无论颜色多对，读出来都是"贴纸的边"；
4. **前端可选内孔 / 端面**。

**为什么新开 `metalTube` 而不是给 `barrel` 加参数**：`barrel` 被枪族 / 鱼雷族 / 机匣三处共用，
它的 `hh` / `bore` / `rIn = hh×0.46` 都是预览试出来的边界值。动它 = 同时动三处已验收的观感。
`metalTube` 的唯一增强是**两端半径可不同** —— 而"喇叭"（`h0<h1`）与"喷嘴"（`h0>h1`）
恰恰是等半径的 `barrel` 画不出来的形态，也恰恰是"这一族长什么样"的全部内容。

## 4. 零件 vs 效果（分层判据）

| | 是零件 ⇒ 必须有体积 | 是效果 ⇒ 保留细线 |
|---|---|---|
| 电弧族 | **电极柱 + 球头** | **电弧**（电离空气，没有厚度） |
| 声呐族 | **喇叭 + 振子** | 开火时那道口环弧 |
| 酸液族 | **喷嘴锥** | 喷口亮点 |

★ 同源判据（V6.65 立）：**判一个东西该用矢量还是位图，不看它物理上多对，
看它"承不承认边缘是模糊的"**。承认真（体积光 / 软阴影 / 光晕 / 烟）⇒ 必须位图；
不承认（几何零件 / UI 框 / 硬边提示）⇒ 矢量反而更准。电弧不承认 ⇒ 细折线 + `neon()`。

## 5. 踩坑记录（每条都花了一轮）

### 5.1 鱼叉族试了**三版**才跳出"箭头"这个字形 ★★

| 版 | 做法 | 读数 |
|---|---|---|
| ① | 细线 + V 形倒钩（V6.29–6.78 旧版） | **箭头** ⇐ 用户圈的 |
| ② | 粗杆 + **实心三角矛头** + 倒钩 | **还是箭头** —— 加粗只让它更像箭头 |
| ③ | 粗杆 + **菱形叶片** + 向后大张的长倒须（±0.56s） | 6× 读成 **X / 星号**，1× 退回来仍是 "→" |

⇒ **结论：只要前端收敛成一个尖，它就一定是箭头。** 粗细 / 形状 / 倒钩方向
都改不出这个坑。要跳出去，**前端必须分成多股** —— 而鱼叉本来就是**叉**：
杆 → 亮箍（装叉头的接头）→ 2~3 根**向前张开**的齿。

⚠️ **基础款也必须是三齿**：二齿在 1× 下的外轮廓就是 `—<`，仍旧读作箭头；
中央那根**伸得比两侧长**、露出叉口之外 ⇒ 剪影是 `—Ψ`，箭头读法才被破掉。

### 5.2 arc 电极在 1× 下黑成一坨

`eR = s*0.075` ⇒ 直径 3px、球头 4px。管身是 `shade(BODY_METAL, 0.60)` 的**暗体**，
3px 宽时没有受光带可读 ⇒ 两根柱 + 两个球头全糊成**一条黑竖条**。
⇒ 提到 `eR = s*0.125`（直径 4.5px），`eOff` 0.30→0.34，`TIP_R` 0.55→0.48。

### 5.3 预览默认值 = 旧样式（"预览比实机差一层"的老坑）

`draw_barrel` 的默认值是 `plain=False, no_ring=False`（本色口环 + 本色管身轮廓），
而实机 V6.77 已拍板"去黄"。漏传就画出**实机上已不存在的黄色炮口**。
⇒ `draw_emitter` 的 gun/torpedo 分支 + `draw_turret` 的机匣调用**全部显式传
`plain=True, no_ring=True`**。**本次第一版 7 族图又踩了一次。**

### 5.4 对照图不能伪造历史

`--emit7` 第一版把 **gun/torpedo 的 BEFORE 也画成"三条线"** —— 但这两族 **V6.70 就已硬件化**，
用户正是拿它们当"正确"的标杆。画成三条线会让读者以为"枪族也刚被改"，
反而看不出 5 族的落差在哪。⇒ BEFORE 行枪/雷两族**画实机同款**。

### 5.5 验收尺度：结构看 6×，判据是 **1×**

`EMITTER_SIZE = 18` ⇒ 整台发射器实机约 **36px**。1× 图才逮到了"harpoon 仍是箭头"
这个 6× 图上**不明显**的问题 —— 细杆在这个尺寸上必然退化成线。
**这个尺寸下能读出来的只有剪影大形**，任何"细"的语汇都是白写。

## 6. 怎么复现 / 怎么看

```bash
python tools/preview_hull_side.py --emit7        # 七族 BEFORE/AFTER 对照（6×）
python tools/preview_hull_side.py --emit7        # 同命令另出 emitter_7fam_ingame.png（1× / 2×）
python tools/preview_hull_side.py --combatmix    # ★ 6 炮位装 6 族不同武器，合成在真实背景上
python tools/preview_hull_side.py --combat       # 6 炮位全 gun 族（向后兼容核验）
python tools/preview_hull_side.py --turret       # 炮座三档（挂点 / 底座+壳体 / 开火）
```

`--emit7` 只画**族特征**，不画全族共用的尾部机匣（图头已注明）；
想看"装到炮座上的完整样子"用 `--turret` / `--combat` / `--combatmix`。

⚠️ 预览的 Python 版 `draw_emitter()` / `draw_tube()` / `_disk()` 是 `DiveGame.ts`
对应函数的**逐行复刻**，**改那边必须同步改这里**，否则预览会开始骗人。
