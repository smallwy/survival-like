## 1. 一句话定位

> **深海版土豆兄弟：氧气就是你的血条、你的倒计时、你的子弹，也是你下潜的门票。**

玩家驾驶潜航器下潜，在每层遭遇 4 波深海生物潮，武器自动开火、只需走位；击杀掉落氧气泡（**必须走位去捡**）。每层结束时你必须决定：**再赌一层，还是上浮兑现。**

## 3. 核心玩法：波次制 + 深海

### 3.1 单局结构

```
┌─ L1 阳光带 ──┬─ L2 暮光带 ──┬─ L3 无光带 ──┬─ L4 热泉带 ──┬─ L5 深渊带 ─┐
│  4 波 × 40s  │  4 波 × 45s  │  4 波 × 50s  │  4 波 × 55s  │  4 波 × 60s │
│  波间 8s     │  波间 8s     │  波间 8s     │  波间 8s     │  Boss 波    │
└──────────────┴─[下潜决策]───┴─[下潜决策]───┴─[下潜决策]───┴─[下潜决策]───┘
                                                              ↓
                                                        上浮兑现 / 阵亡
```

| 项 | 值 |
|---|---|
| 总波数 | **20 波**（5 层 × 4 波） |
| 单波时长 | 40s → 60s（逐层递增） |
| 波间喘息 | **8 秒**（不回氧，只做拾取与三选一） |
| 层末 | **补给站**：买氧气 / 武器 / 道具 → **下潜 or 上浮决策** |
| 单局总长 | **20-25 分钟** |
| 死亡 | 氧气归零 = 溺水，**本局收益全损** |
| 上浮兑现 | 带走 **100%** 收益（生物质 + 图鉴解锁） |

**模式**：单人、单局、本地存档。不做联机（§11）。

### 3.2 氧气四合一（V6 的立身之本）

> **氧气 = 生命 = 计时器 = 技能燃料 = 下潜门票。四个资源塌缩成一个数字。**

```
氧气 = 0                    → 溺水，本局结束
氧气持续下降                → 与是否挨打无关（区别于 Brotato 的血量）
击杀掉落氧气泡              → 需走位拾取，6 秒后消失
主动技能「排气爆发」         → 消耗 20 氧，半径 250px 清场
下潜下一层                  → 一次性支付 15/20/25/30 氧
```

**关键：氧气不是换皮的血条。** Brotato 的血量只在挨打时掉（被动），氧气**持续在掉**（主动），且与深度挂钩。这把 survivors 的"火力 vs 敌潮"单轴，变成"火力 vs 敌潮 vs 续航"三轴。

### 3.3 下潜 / 上浮决策（V6 相对 Brotato 的唯一结构增量）

> **Brotato 只能一路打到死。我们让玩家在每层末选择收手。**

| 选项 | 收益 | 代价 |
|---|---|---|
| **继续下潜** | 下一层敌人掉落倍率 ×1.4，Boss 波给图纸 | 支付下潜门票；氧气上限压缩；消耗速率上升；**阵亡则本局全损** |
| **上浮兑现** | 带走 100% 生物质与图鉴解锁 | 放弃后续层的所有收益 |

**为什么这一条重要**：它给游戏加了一个 **风险偏好维度**。保守玩家在第 3 层收手，激进玩家赌到第 5 层——同一局游戏产生不同的自我叙事，这是 survivors 品类里相对少见的。

### 3.4 五层深度带（敌潮 + 消耗）

| 层 | 深度 | 氧气上限 | 消耗/秒 | 每波掉落上限 | 敌潮组成 | Boss |
|---|---|---|---|---|---|---|
| **L1 阳光带** | 0-200m | 100 | 1.0 | 60 | 荧光小鱼群（群）、珊瑚虾 | — |
| **L2 暮光带** | 200-1000m | 100 | 1.3 | 52 | 银斧鱼（闪避）、刺鳐（冲刺） | — |
| **L3 无光带** | 1000-4000m | 85 | 1.7 | 44 | 幽灵水母（慢高血）、吞噬鳗（突进） | — |
| **L4 热泉带** | 4000-6000m | 70 | 2.2 | 36 | 甲壳蟹（重甲）、热泉虾群（群） | — |
| **L5 深渊带** | 6000m+ | 60 | 3.0 | 30 | 深渊螺（远程）、混编 | **深渊守望者** |

**下潜门票**：L1→L2 付 15 / L2→L3 付 20 / L3→L4 付 25 / L4→L5 付 30。

### 3.5 敌人分类（4 类，对应不同走位压力）

| 类别 | 代表 | 行为 | 要求玩家 |
|---|---|---|---|
| **群** | 荧光小鱼群、热泉虾群 | 数量压制，低速直冲 | 需要 AoE |
| **冲刺** | 刺鳐、吞噬鳗 | 蓄力后高速突进 | 需要预判闪避 |
| **重甲** | 甲壳蟹、深渊螺 | 高血慢速 / 远程 | 需要单体穿透 |
| **Boss** | 鮟鱇女王、深渊守望者 | 多阶段，全屏技能 | 需要位移与爆发 |

## 4. 氧气机制详解（决定成败的一章）

### 4.1 三道硬约束（缺一不可）

> **如果直接做「击杀补氧」，会退化成"杀得越多活得越久"，与火力成长是同一件事，氧气就只是换皮的血条。**

| # | 约束 | 规则 | 解决什么 |
|---|---|---|---|
| **①** | **氧气泡必须走位拾取** | 击杀掉落物**不自动吸收**，需移动到气泡位置；气泡 **6 秒后消失** | 把"击杀"与"补给"拆成两个动作，制造走位风险：去捡 = 靠近敌潮 |
| **②** | **每波掉落总量上限 + 逐层衰减** | L1 每波最多掉 60 氧 → L5 最多 30 氧；超出不再掉落 | 防止无限续航，强制"越深越紧" |
| **③** | **氧气上限随深度压缩** | 100 / 100 / 85 / 70 / 60 | 深处容错更小，与消耗速率形成双重压力 |

### 4.2 数值表

| 项 | 值 |
|---|---|
| 初始氧气 | 100（L1） |
| 基础消耗 | 1.0 /秒（L1），逐层 ×1.0 / 1.3 / 1.7 / 2.2 / 3.0 |
| 单个氧气泡 | **+4 ~ +8 氧**（按敌人类型） |
| 气泡存活 | **6 秒**，最后 2 秒闪烁提示 |
| 排气爆发（技能） | 消耗 **20 氧**，冷却 12 秒，半径 250px 清场伤害 |
| 下潜门票 | 15 / 20 / 25 / 30 |
| 补给站氧气罐 | 花生物质购买，+40 氧（价格逐层上涨） |
| 被动「鳃」 | 击杀回氧 +50%，但氧气上限 -15（典型的风险取舍） |

### 4.3 氧气带来的三类新决策

| 决策 | 说明 |
|---|---|
| **要不要去捡那个气泡** | 气泡在敌潮另一侧 → 捡 = 补给，不捡 = 安全 |
| **要不要开排气爆发** | 20 氧换一次清场 → 是救命还是浪费 |
| **要不要下潜** | 门票 + 上限压缩 + 速率上升 → 三重代价换 1.4 倍掉落 |

**这三条是 Brotato 没有的。** 它们让"氧气"从 UI 上的一个数字，变成玩家脑子里的一条持续计算。

## 5. Build 系统

### 5.1 少而深（应对我们的产能短板）

> Brotato 有 6 武器槽 + 数百道具 + 数十角色；DRG:S 有 4 职业 × 10 武器 + 300 成就。
> **我们 1 人 + AI 做不出这个量。用"质变密度"补"数量不足"。**

| 项 | 数量 | 说明 |
|---|---|---|
| 装备槽 | **3** | 主动装备（武器） |
| 被动槽 | **6** | 属性 / 特殊道具 |
| 武器 | **8 种**，每种 **2 条进化分支** | 共 24 种形态，进化 = 质变（改机制，不是 +5% 伤害） |
| 被动道具 | **30** | 至少 8 个是机制改变型 |
| 潜航器 | **3 台** | 机制差异，不是数值差异 |

### 5.2 八种武器与进化

| 武器 | 机制 | 进化 A | 进化 B |
|---|---|---|---|
| **鱼叉枪** | 直线穿透 | 链锯鱼叉（持续伤害段） | 三叉戟（三向散射） |
| **声呐炮** | 环形冲击波 | 共振炮（连锁弹射） | 定向聚焦（扇形高伤） |
| **网发射器** | 减速控场 | 电网（减速 + 灼烧） | **收容网**（转化为友方单位） |
| **生物光诱饵** | 吸引敌人聚集 | 爆炸诱饵（延时爆） | 光墙（封锁走位） |
| **水流推进器** | 位移 + 撞击伤害 | 涡流（拉扯敌人） | 冲刺撞击（无敌帧 + 高伤） |
| **气泡雷** | 放置陷阱 | 连锁雷（串联爆） | **氧气雷**（爆炸回复氧气） |
| **酸液喷射** | 持续伤害区域 | 腐蚀云（大范围低伤） | 高压酸柱（小范围高伤） |
| **回声炮** | 延迟爆发 | 多重回声（多次触发） | 全域回声（全屏） |

> **「收容网」和「氧气雷」是重点**：它们把"击杀"这个行为与"氧气"这个资源**反向挂钩**（用敌人换氧气），能产生真正新鲜的 build 流派。

### 5.3 三台潜航器（机制差异）

| 潜航器 | 特性 | 流派 |
|---|---|---|
| **灯艇 Lumen** | 氧气上限 +25，视野半径最大，伤害 -15% | 稳健续航流 |
| **刺鳐 Raia** | 移速 +35%，撞击伤害，氧气泡拾取范围 -40% | 高风险走位流 |
| **深潜者 Bathy** | 氧气上限 -20，击杀回氧 **+50%**，装备槽 **+1** | 激进清怪流 |

### 5.4 meta 解锁（跨局）

| 类型 | 内容 |
|---|---|
| 新潜航器 | 达成条件解锁（如"上浮兑现累计 10 次"） |
| 新武器 | 图鉴解锁（击杀特定敌人） |
| 永久强化 | 生物质购买的微量属性（上限受控，避免破坏局内随机性） |
| 图鉴 | 20 种生物标本陈列 |

|---|---|
| 风格 | 赛博霓虹矢量（`render/neon.ts` 运行时几何绘制，**零 png**） |
| 分层 | 5 层独立签名：色板 / 地形 / 地标物 / 生物族 / 粒子（沿用 V3 §4） |
| **新增难点** | **满屏 100+ 敌人时的可读性**（Bullet Heaven 的核心技术门槛） |
| 色相隔离 | 青蓝 = 玩家/UI；生物用青绿/品红/琥珀/紫 |
| 双渲染器 | Canvas 降级路径必须保留（WebGL-only API 禁用） |

**可读性硬规则（V4 重点）**：
- 敌人**只画轮廓 + 发光核心**，不填实体色 → 100 只重叠时不会糊成一片
- 氧气泡用**唯一的高亮白色**，且带上升动画 → 在混乱中最先被看见
- 玩家永远是最亮的青蓝 → 任何时刻都能找到自己

## 10. 风险与止损

| 风险 | 等级 | 应对 |
|---|---|---|
| **品类极度过饱和，观众已免疫** | 🔴 高 | 前 30 秒必须给出三张牌（§2.3）。做不到就不要上线 |
| **被 Brotato 比价压制** | 🔴 高 | 定价 ≤ $7.99；首发 $4.99 |
| **内容量不足（我们 vs Brotato 的数百道具）** | 🔴 高 | 少而深（§5.1），用质变密度补数量 |
| 击杀补氧导致无限续航（氧气退化） | 🔴 高 | 三道硬约束（§4.1）**必须全部实现**，少一条就退化成换皮 |
| **满屏可读性崩坏** | 🟡 中 | 只画轮廓 + 发光核心（§6）；150 敌人为性能与可读性红线 |
| 版号 | 🟡 中 | S4 启动，预留 3-4 个月 |
| 一人 + AI 产能 | 🟡 中 | S1 只做手感验证，内容后补 |

**止损线（写死）**：
> 若 S1 结束（第 3 周）时，**单波战斗自己玩起来不爽**，或**氧气条没有产生"要不要去捡"的犹豫**——立即停止投入内容。
> 这两条是 V6 的全部立身之本。**不要靠加内容救一个手感不成立的核心。**

## 11. 明确不做

| 不做 | 理由 |
|---|---|
| 手动瞄准为主 | Brotato 的核心是**自动开火 + 走位**；手动瞄准会变成另一个品类 |
| 多人联机 / 组队 | 产能不允许 |
| 3D | 产能不允许；矢量 2D 是美术护城河 |
| 开放世界、大地图探索 | 波次制不需要（V5 已证伪该方向的容量） |
| 护甲相克 / 复杂属性表 | 与"一个数字"的设计哲学冲突 |
| 局外氪金影响局内强度 | 会直接招致"换皮"差评（62% 换皮作品就是这个特征） |
| 独立港口场景 | 层末补给站足够 |
