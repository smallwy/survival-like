## 3. 怎么判（3 局，勾选式）

> 判定口径：**不是"有没有这个机制"，是"我第几局开始不看数字就知道自己在变深"**。

- [ ] **第 1 局 · L1→L2**：打完第 1 波时，除了怪没了，**画面有没有"沉了一下"**（窜 + 环 + 数字滚）？  
  → 如果只有数字在动 = 节拍太弱，得加振幅。
- [ ] **第 1 局 · 带内**：同一层里从第 1 波到第 4 波，**水色是不是在缓慢变**（不是换带才变）？
- [ ] **第 2 局 · 网**：撒网命中后，那只鱼是**完全不动**、还是只是"走慢了"？能不能一眼分辨？
- [ ] **第 2 局 · 雷**：布雷之后，你**有没有在等它炸**（数秒）？还是根本不知道它什么时候炸？
- [ ] **第 2 局 · 重甲**：遇到"不追你、打不动"的怪时，你**有没有想换武器**？没有 ⇒ 护甲只是血厚。
- [ ] **第 3 局 · 惊喜**：这一局里，你**有没有一次"哎？"**（精英的脉冲光晕 / 连杀骨雨）？
- [ ] **第 3 局 · L3 末**：鮟鱇女王的"诱饵光"有没有让你**犹豫要不要过去**？（犹豫 = 机制成立）
- [ ] **总判**：第 3 局的"下潜纵深感"比第 1 局强吗？（第 1 局会因新奇而偏高，看的是**第 3 局还剩下多少**）

## 4. ⚠️ 规格 ≠ 现状：两处需要你拍板

### 4.1 海雪的"连续化"与"上涌气泡"被取代了（V6.49 §2 → V6.51 §9 第 4 步）

方案原文（§2 表格）：

> 海雪 `motes` ｜ 每层固定条数 ｜ 密度 **+ 下落速度** 连续变；深度 > 4000m 时**海雪换成上涌气泡**

现状：

| 子项                   | 现状                                                                                   | 说明                                                                |
| -------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| 密度按 `depthM` **连续**变 | ❌ 仍是**按带的常数** 34/48/70/90/110（`tables.ts:608-624` 的 `motes`）                         | 换带整批重建（`DiveGame.ts:2595-2600`），与 `schools` 同规 —— "换带瞬间整片水换了一种东西" |
| 下落速度按深度变             | ❌ **刻意不做**。`DiveGame.ts:2591` 原注释：**"⛔ 深度不影响速度 —— 别做'越深越慢'，那会削弱下潜感。深度只影响密度/尺寸/亮度。"** | 速度只在换带爆冲时被 `scrollV` 一起推快（这是 V6.56 的设计）                           |
| >4000m 换成**上涌气泡**    | ❌ 没有气泡。L4（4000–6000m）换成了「**热泉微粒**」：暖橙、**向下走**                                        | 见 4.2                                                             |

**这不是漏做，是 V6.51 用一套更贵的设计把它取代了**：把"同一种白点变密"换成"**五种不同的物质**"。  
`MOTE_STYLE` 的注释写得很直白：*"如果悬浮物还是同一种白点，玩家会觉得'我只是换了张壁纸'。"*

⇒ **要不要按字面补回"连续密度"？** 我的建议：**不补**。连续性会跟"换带整批重建"打架，  
而"物质本身换掉"比"同一物质变密"是更强的深度线索。**你拍板。**

### 4.2 ★ L4 的颗粒是**反向**的 —— 这可能是"下潜感不够"的**一半根因**

`MOTE_MUL`（`DiveGame.ts:670-676`）：

```
L1 [1.00, 0.35]   ← 颗粒向上掠（下潜感）
L2 [1.00, 0.35]   ← 同上
L3 [1.00, 0.35]   ← 同上
L4 [-0.62, -0.22] ← ⚠️ 反向：颗粒向下走
L5 [1.00, 0.35]   ← 向上掠
```

L4 是唯一反向的一层，理由是 §4.3 里那条设计：`ventPush = 190` 把玩家往上顶 ⇒  
**"热流是向下的"**，让"机制"和"视觉"说同一句话。

**但它有个副作用**：下潜题材里，"颗粒向上掠"**就是**下潜感本身。  
在 4000–6000m 这**整整一层**里，玩家看到的是颗粒跟自己一起往下走 —— 那读&#x4F5C;**"下沉停了"**。  
而 L4 占全局 **1/5 的时长**。

⇒ **两个候选（二选一，你拍板）**：

- **A 保留反向**（现状）：保住"热泉把我顶住"这句台词，接受 L4 的下潜感断档。
- **B 改成"双层"**：**气泡向上**（热涌）+ **矿砂向下**（冷水回补）同时存在。  
  物理更对、两种读法都在，且下潜感不断档 —— 代价是 L4 的图元数翻倍（当前海雪上限 90/帧）。

> 我倾向 **B**：它把 4.1 里被砍掉的"上涌气泡"顺手补回来了，且不用改 `MOTE_MUL` 的语义、  
> 只在 L4 那一层把颗粒拆成两群。**但这是表现层改动，改完必须同步 `tools/preview_descent.py`。**
