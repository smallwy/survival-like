## 本轮（v6.39）做了两件事

### 一、图标语义深海化 —— 解决「太没有创新」

**判定：问题不在"画得好不好"，在"画的是什么"。**

上一版 6 个图标（书 / 旗 / 扳手 / 定位针 / 滑杆 / 问号）是**通用软件语汇** ——
换到任何一个后台管理系统都成立，与深海零关系。

**风格锚点一条没动**（粗描边 + 实底 + 四档明暗 + 冷白单色可染），**只换图形语义**：

| 入口 | 旧 | 新 | 轮廓 |
|---|---|---|---|
| 图鉴 | 打开的书 | **磨砂金属标本罐**（观察窗 + 水母 + 气泡） | 竖长方 |
| 里程碑 | 三角旗 | **半圆**深度计（弧 + 直底边 + 单根粗指针） | 半圆 |
| 装置坞 | 扳手 + 螺母 | **压力舱门**（实心圆盖 + 辐条 + 螺栓） | 正圆 |
| 海域 | 地图定位针 | **航海图卷轴**（双圆筒 + 星形罗盘玫瑰） | 横长方 |
| 设置 | 三条滑杆 | **阀门手轮**（实心盘 + 4 方柄） | 近方 |
| 帮助 | 圆圈问号 | **探照灯**（梯形灯罩 + 实心扇形光锥） | 近方 |

新增**母题三要素**（"深海特色"的机制，不是形容词）：
① 圆形仪器倾向 ② 必带机械件（凸块，不是细线）③ 必有浸水痕迹（气泡 / 水波 / 锈蚀）。

**文件名完全不变** ⇒ `Title.ts` **一行没改**（换的只是 png 内容）。
实测：受光面 **0.96**（≥0.95 ✅）、暗面 0.50–0.77、留白率 **72.1%**。

### 二、局内暂停菜单 —— 修的是可用性缺陷

**改前的事实**：`DiveGame.ts` 战斗分支里 `ESC` 走的是 `restartRun()` ——
**把「退出」写成了「重开」**；而 `toTitle()`（回主界面）**只被结算屏调用**。

⇒ **玩家在局内没有任何退出路径**：想退出只能自杀；按 ESC 反而白打一局重开。
且 ESC 是键盘专属 ⇒ **触屏玩家零出口**。

| 改动 | 内容 |
|---|---|
| 入口 1 | `ESC` → 暂停（**不再是重开**） |
| 入口 2 | **HUD 右上角常驻暂停按钮**（视觉 38×38 / 热区 64×64，矢量两条竖杠） |
| 菜单 | 继续游戏 / 重新开始 / **返回主界面（带二次确认）** |
| 连带 | 鱼骨与生物质整组左移让角（`W−106→W−150`、`W−24→W−64`） |
| 代码位置 | 绘制写在 `update()` 四个阶段分支**之外**（末尾追加）—— 四个分支一行没动 |

规格文档：`docs/局内暂停菜单_规格.md`
