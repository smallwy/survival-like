## 0. 结论先行

1. **核心判据**：新遗物**必须改变武器行为**，不能是"全局 +X%"。V6.28 的原话是
   「遗物改武器行为 = 乘法空间」—— 全局 buff 拿到哪个都差不多，**绑武器的才会长出流派**。
2. **提 4 条**（遗物池 8 → 12），分别绑 **电弧 / 鱼叉 / 回声 / 武器等级**四个不同维度。
3. **只落机制、不出立绘**：加一个 `RELIC_ART_FALLBACK`（暂复用语义相近的已有遗物图），
   手感确认后再出图 —— 与 `EVO_ART_FALLBACK` 同款做法，**不阻塞、不静默缺图**。
4. ⚠️ **氧气是红线**：V6.24 刚把氧改成稀缺（L5 净亏）。新遗物里凡是碰氧的（导体缠绕），
   数值必须保守，否则一夜回到"氧用不完"。

## 1. 现状核实：8 个遗物到底怎么生效的

全部通过 `world.ts` 里的 `hasRelic(id)` 条件判断落地（**不是**统一的 `onEquip` ——
`onEquip` 只有 `osteoblast` 用了，做 stat 改动）。

| 遗物 | 效果 | 落地位置 | 算"机制型"吗 |
|---|---|---|---|
| `echo_heart` 回声心脏 | 氧<30% 伤害 +50% | `world.ts:1296` `dmgMulNow()` | 半 —— 自动触发，不改打法 |
| `osteoblast` 骨殖转化 | 击杀回氧 ×2 | `world.ts:747` | ✗ 数值 |
| `tidal_compass` 潮汐罗盘 | 拾取 +80% / 鱼骨 +30% | `world.ts:785, 1289` | ✗ 数值 |
| `resonance_core` 共振核心 | 暴击溅射最近一敌 40% | `world.ts:712` | **✓ 绑武器** |
| `gluttony` 贪食腺体 | 鱼骨 +100% | `world.ts:1290, 1244` | ✗ 数值 |
| `abyss_mark` 深潜印记 | 每层伤害 +12% | `world.ts:1297, 305` | 半 —— 改节奏，不改打法 |
| `current_fin` 洋流鳍 | 3s 未受击移速 +30% | `world.ts:463` | 半 —— 自动触发 |
| `silent_plating` 静默装甲 | 受击后 1.5s 闪避 +40% | `world.ts:596` `plateT` | 半 —— 自动触发 |

> **修正 V6.28 的一处口径**：V6.28 把洋流鳍/静默装甲列为"纯数值"，其实它们是**条件触发**的
> （有 `plateT` / `noHitT` 计时）。真正的问题不是"数值 vs 机制"，而是 ——
> **8 条里只有 1 条（共振核心）绑定了武器行为**。其余都是"改我的面板"或"改我的自动状态"。
> 所以这一刀的目标非常明确：**再补 4 条绑武器的**。

## 2. 四条提案

### 2.1 `conductor_coil` 导体缠绕 —— 绑【电弧 × 氧气】

| 项 | 内容 |
|---|---|
| 效果 | 你的**链式电弧每跳一次回 0.8 氧** |
| 价格 | 62 |
| 代价 | 氧气上限 −10（防过载） |
| 钩子 | `world.ts:1138` `fireArc()` 的 `while (cur && hit.size < chain)` 循环内 |
| 为什么是乘法 | 氧原本只来自**拾取 / 击杀**；这条把它接到**武器行为**上。Lv 越高 chain 越长（`2 + lvl`，Lv5=7 跳）→ **"升满电弧"从加伤害变成加续航**，玩家会为回氧去 build 电弧 |

**数值依据**：Lv5 电弧单次 7 跳 × 0.8 = **5.6 氧/次**，射速约 1.1s → 约 **5 氧/秒**。
对照氧消耗：L1 drain 1.0/s、L5 drain 3.0/s。**看起来能盖住消耗**，但电弧要"跳得到 7 个敌人"
（密集波才成立，散开时跳 2~3 个）。**保守取值 0.8**，实测若过强再降到 0.5。
⚠️ 另需一个**每帧回氧上限**（防 arc_ov 的 chain=11 一次灌满）。

### 2.2 `bleeding_anchor` 破血锚 —— 绑【鱼叉 × 暴击】

| 项 | 内容 |
|---|---|
| 效果 | 鱼叉命中时，对**本次射击已穿过的其他敌人**再补一刀 —— **你当前暴击伤害的 30%** |
| 价格 | 58 |
| 钩子 | `world.ts:1197` `updateBullets()` 的 `b.kind === 'harpoon'` 分支（`b.hit` 里已经有穿透记录） |
| 为什么是乘法 | 鱼叉本来就**穿透不销毁**；配合「三重鱼叉」（3 叉）→ 每叉穿 3 敌 = 最多 6 次溅射。**它是"火力量"流派的放大器**，把"穿透"从"能打多个"变成"打得越来越疼" |

**数值依据**：`resonance_core` 是"暴击溅射 40% 给最近 1 敌"（`world.ts:712`）。
本条换成"30% 给**已穿过**的**多个**" —— 30% 比 40% 低是刻意的（多个 > 单个，总额更大）。
**限制每颗子弹最多触发 3 次**，防止 3 叉 × 6 敌的极端叠加。

### 2.3 `resonance_chamber` 共鸣腔 —— 绑【回声】

| 项 | 内容 |
|---|---|
| 效果 | 你的**回声爆炸**时，在半径内**最近 2 个未被炸到**的敌人处，各生成一个**小回声**（半径 55%、伤害 40%） |
| 价格 | 60 |
| 钩子 | `world.ts:660`（`echoes` 到期 → `explode()`）+ `world.ts:1218` `explode()` |
| 为什么是乘法 | 回声从"单点延迟爆"变成"**链式引爆**"。配合 V6.29 的「多重回声」（三口品字）→ 一次开火最多 3 + 6 次爆炸；再配氧耦合 → 形成"爆炸流" |

**数值依据**：小回声 40% 且**连锁深度限制 2 层**（大回声 → 小回声 → 不再连锁）。
⚠️ **必须限制深度**，否则三敌人互指会无限递归。

### 2.4 `overload_core` 过载核心 —— 绑【武器等级】维度

| 项 | 内容 |
|---|---|
| 效果 | **满级（Lv5）**的武器 **射速 +25% / 伤害 +12%**；**未满级无加成** |
| 价格 | 68（全池最贵） |
| 代价 | 未满级武器**伤害 −8%** |
| 钩子 | `world.ts:1125` `w.ivLast = def.iv / (… )`（射速）、`weaponStats()` / 开火时 `w.dmg`（伤害） |
| 为什么是乘法 | **它改的是"升级决策"本身**。原本 6 槽"平均铺"最优；有了它，"**专精一两把到满级**"才划算。这是现有 8 条遗物里**完全没有的一个维度** —— 其余都作用于"战斗中"，只有这条作用于"商店里的选择" |

**数值依据**：射速 +25% 单独看不如一件属性卡（`s_rate`）；它值钱在**叠加** ——
满级 + 挂载扩容座（`twinRate`）+ 射击速度属性，才是它的真正收益。带"未满级 −8%"的代价，
是因为**不给代价的话它永远划算，就没有取舍了**。

## 3. 为什么是这 4 个维度

```
                  武器行为耦合矩阵（★ = 已有，☆ = 本次新增）
              gun  torpedo  arc   sonar  harpoon  echo  acid
共振核心(暴击溅射)  ·     ·       ·      ·       ·       ·     ·    ← 通用暴击，不绑特定武器
导体缠绕(每跳回氧)  ·     ·       ☆      ·       ·       ·     ·
破血锚(穿透补刀)    ·     ·       ·      ·       ☆      ·     ·
共鸣腔(爆炸连锁)    ·     ·       ·      ·       ·       ☆    ·
过载核心(满级奖励)  ☆     ☆       ☆      ☆       ☆      ☆    ☆   ← 绑"等级"维度，全族通吃
```

**覆盖到 4 个不同维度**（链式 / 穿透 / 爆炸 / 等级），**刻意不重**。
剩下的 gun / torpedo / sonar / acid 留作下一批（第 5 条候选见 §6）。

## 5. 立绘策略：先机制、后出图

4 条新遗物需要 4 张商店立绘。**推荐先加回退表、不出图**：

```ts
// artKeys.ts —— 与 EVO_ART_FALLBACK 同款：先复用语义相近的已有遗物立绘
const RELIC_ART_FALLBACK: Record<string, string> = {
  conductor_coil: 'resonance_core',   // 都是"能量耦合"意象
  bleeding_anchor: 'abyss_mark',
  resonance_chamber: 'echo_heart',
  overload_core: 'gluttony',
}
```

**理由**：① 机制手感是这一刀的核心，立绘是壳；② 手感没定就出图 → 万一遗物设计要改，图白出；
③ 回退表让 `verify_cocos.py` 的美术完整性检查**不会报缺失**（`artPaths()` 从 `RELIC_DEF` 推导 key，
新增遗物会立刻要求 `item_<id>.png`）。
**手感确认后**再走生图 → `process_item_art.py` → 删回退，与 6 条进化立绘同一条流水线。
