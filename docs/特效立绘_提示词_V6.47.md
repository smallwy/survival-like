## 1. 硬约束（每条提示词都必须满足，否则后处理会毁图）

| # | 约束 | 为什么 |
|---|---|---|
| ① | **纯白背景**（近白、均匀、不带渐晕/棋盘格） | 抠底靠"从四边泛洪 + 紧容差"，背景越干净越稳 |
| ② | **发光只在内部与轮廓线，不许外溢光晕** | 一旦有外光晕，亮度阈值抠底**完全失效**（alpha 会盖满全图）。V6.4 定下的铁律 |
| ③ | **画面内不许有文字 / 水印 / 地面阴影 / 多余物件** | 文字会进成品；阴影会把泛洪"桥"到武器上 |
| ④ | **3/4 侧视带俯角**，能看到本体 + 底部圆形炮座 | 与已有 21 张立绘同视角、同底座，卡面并排才不像两批货 |
| ⑤ | **同一个圆形金属炮座**（三族共用件） | 武器共用一套「装载器」，底座一致本身就是"同一套挂载系统"的可读性 |
| ⑥ | 单张主体**居中、占画幅约 86%** | 后处理按 0.86 填满 1200×600 画布，主体太小卡面会很空 |

## 2. 剪影差异化矩阵（**先看这张表，再看提示词**）

商店卡里的立绘框约 **268×96**。九张图挤在一个滚动列表里时，
**第一眼信息是外轮廓，不是细节或颜色**。所以九张的剪影必须两两不同 ——
这是本轮的**主要设计约束**，颜色只是辅助区分。

| id | 名称 | 载体 | 剪影形状 | 相对基础的变化 |
|---|---|---|---|---|
| `mine` | 气泡雷 | 碟形布雷器 | **矮横圆盘 + 顶部圆丘** | — |
| `mine_ch` | 连锁雷 | 同上 | **更宽**（横长 1.4×） | 横向拉长 |
| `mine_o2` | 氧气雷 | 同上 | **更高**（背部双瓶） | 竖向加高 |
| `net` | 网发射器 | 网筒抛网器 | **横长方 + 前端四爪张开** | — |
| `net_el` | 电网 | 同上 | 前端**更粗更密**（线圈绕组） | 前端加厚 |
| `net_cv` | 驯化网 | 同上 | 前端**六根触须状臂**（比四爪更碎） | 前端变"活" |
| `lure` | 生物光诱饵 | 球囊发光器 | **细高球囊（竖长）** | — |
| `lure_bo` | 爆炸诱饵 | 同上 | **更粗**（环箍 + 侧挂药块） | 径向膨胀 |

**三族之间的轮廓关系**：矮横（雷）/ 横长（网）/ 竖高（诱饵）—— 三个主方向互不重叠，
所以在滚动列表里即使被裁掉一半也能认出是哪一族。
