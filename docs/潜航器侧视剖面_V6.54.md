## §2 侧视剖面 = 九条线索

按绘制顺序（后画的在上层）：

| # | 线索 | 参数 | 作用 |
|---|---|---|---|
| ⓪ | 投影 | 同形偏移 `(+5, +8)`，`UI.abyss @0.42` | "这条船微微浮着"（偏移必须小，水下阴影是弥散的） |
| ① | 侧壁（厚度） | 同形下移 `6px`，`shade(BODY_METAL, 0.28)` | 下缘露一条边 = "有厚度" |
| ② | 主体 | `shade(BODY_METAL, 0.74)` | 梭形中调 |
| ②b-1 | 上半壳提亮 | 上半段轮廓缩放 `0.95/0.90` 上移 `3px`，`shade(BODY_METAL, 0.88)` | "上亮下暗" |
| ②b-2 | 上缘光带 | 贴轮廓两级描边：`w=10 @0.26` → `w=4.5 @0.40` | "边缘在发光"，**无硬边界** |
| ②c | 下腹暗带 | 下半段两级描边：`w=10 @0.26` → `w=5 @0.42` | 坐实"下方是船腹" |
| ③ | 背脊挂载带 | 沿艇背内缩 `0.78`，`w=3`，**主题色 `w.sub.color`** | **主题色唯一落点**；炮座镶在这条线上 |
| ④ | 指挥塔 + 潜望镜 | 梯形 `y -0.88 → -1.46`（**突破剪影**）+ 细杆到 `-1.78` | "这不是鱼"的第一笔 |
| ⑤ | 尾舵 | 上下两片，根在艇内 `(-0.70,-0.62)`、尖在艇外 `(-1.02,-1.42)` | 第二处破剪影 |
| ⑥ | 舷窗带 | 5 点，`x -0.34 → 0.54`，中间一颗放大到 `2.8` | **"这是侧视"最强单一线索** |
| ⑦ | 艉部推进器 | 艉端竖椭圆护罩 `(HH*0.26, HH*0.64)` + 轴心亮点 | 把"哪一头是艉"锁死 |
| ⑧ | 霓虹外轮廓 + 上缘受光弧 | 整圈 `UI.cyan @0.88 w=1.6`；上缘 `UI.cyanHi @0.32 w=3` | "玩家机体是画面里最亮的青系" |

⛔ **不加 bloom**：线宽挂在轮廓上会外扩成一圈比机体还大的光环（V6.53 及以前的坑 ⑤）。
⛔ **全部明暗用世界固定方向，没有任何部件吃朝向** —— 与 `drawTurret` 同源铁律
（形状的朝向不该进它自己的明暗参数；否则部件一转，亮面跟着转 = "贴纸在打折"，且**不报错**）。

## §3 ⚠️ 数值耦合：三个数必须一起算

机体**不能随便改尺寸** —— 座圈六个座位要压在艇舷上，而座位位置由模拟层的投影决定。

```
SUB_D      = 88        艇长
HULL_H     = 56        艇高
SEAT_RATIO = 28 / 48   座圈高度投影比
SEAT_RING_R = 48       座圈半径（模拟层，**不要动**）
```

**推导**：±90° 两座 `cos = 0`，纵向落在 `SEAT_RING_R × SEAT_RATIO`。要让它们压在机体高边缘：

```
48 × K = 28        （28 = HULL_H / 2）
K = 28 / 48 ≈ 0.5833
```

**验算另外四座**（`±30° / ±150°`，横向 `48 × cos = ±41.57`）：

| 座位 | 世界坐标 | 该 x 处轮廓 y | 差 |
|---|---|---|---|
| ±90° | `(0, ±28.0)` | `-27.8` | **0.2 px** ✅ |
| ±30° | `(±41.6, ∓14.0)` | `∓13.2` | **0.8 px** ✅ |
| ±150° | `(∓41.6, ∓14.0)` | `∓10.7` | 3.3 px ✅（塔盘半宽 8.8 ⇒ 一半压在艇身上） |

⇒ 六座炮全部"镶在艇缘"而不是飘在旁边。

**改任一个数都必须重算上表**。漏算**不会报错**，只会看起来"炮浮着"。

## §4 座圈投影（唯一动到模拟层的地方）

`shared/dive/tables.ts`：

```diff
- export const SEAT_RATIO = 0.5          // 3/4 俯视压扁率（60° 俯角的 cos）
+ export const SEAT_RATIO = 28 / 48      // 侧视高度投影比
```

⚠️ **这是投影，不是战斗数学**：射程 / 伤害 / 索敌优先级 / 开火频率**一行未动**。
变的只有「同一个座位画在哪、从哪出弹」。

⚠️ 但 `seatPos()` 同时被 `turretPose()`（开火原点）和 `seatTarget()`（索敌原点）调用
⇒ **子弹起点与索敌结果会跟着变**。这是必要代价（投影与画面必须同源，否则子弹从炮口旁边飞出）。
**需实机确认手感。**

`SEAT_ANGLES_DEG = [30,-30,90,-90,150,-150]` **一个数都没动** —— 它是 web/cocos 共享数据。

## §5 朝向：只做镜像，不做倾斜

新增字段 `faceX`（`+1` 朝右 / `-1` 朝左），在 `drawPlayer()` 每帧更新一次：

```ts
const wantX = Math.cos(w.aim)
if (wantX > 0.25) this.faceX = 1
else if (wantX < -0.25) this.faceX = -1
```

- ⛔ **不用 `aim` 做旋转** —— 那是俯视写法（回转体转起来看不出变化，只让"炮沿着船壳滑动"）。
  用户 2026-10-13 已明确否过一次，这条结论在侧视下**依然成立**。
- ⚠️ **死区 ±0.25 是必须的**：`aim` 在玩家原地微调时会在 ±90° 附近抖，没死区会看到艇身来回抽。
- 镜像**只乘在 x 上**（`y` 不翻）⇒ 掉头时背永远是背、腹永远是腹。
  若连 y 一起翻 = 艇腹朝天（俯视时代"转 180°"的同款错误）。
- **倾斜留 v2**：座圈投影在模拟层，机体倾斜而座圈不倾 = 炮脱离艇身。

## §6 预览脚本

```bash
python tools/preview_hull_side.py              # 主图（含座圈六座校验）
python tools/preview_hull_side.py --big        # 3 倍放大（看体积线索）
python tools/preview_hull_side.py --sheet      # 分层拆解（6 格，看每条的贡献）
python tools/preview_hull_side.py --silhouette # 剪影辨识度 100% / 75% / 50%
python tools/preview_hull_side.py --flip       # 左右朝向对比（验镜像只翻 x）
```

输出 `docs/shots/hull_side*.png`。

⚠️ **脚本里的常量是从 `DiveGame.ts` 抄的** —— 改 TS 必须同步改脚本，
否则预览图会变成"骗人的图"（比没有预览更糟）。脚本头部已标。

**已有产出**（本轮）：
- `hull_side.png` / `hull_side_big.png`：主形体
- `hull_side_layers.png`：六格分层，直接看出每条线索的贡献（本次三处修正全靠它定位）
- `hull_side_silhouette.png`：**三档尺寸都是可辨识的"潜水器"剪影** ✅
- `hull_side_flip.png`：左右镜像对比
