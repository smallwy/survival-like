> 前置：`docs/主界面版式_V6.38.md`（五分区与栅格）、`docs/主界面深海化_V6.40.md`（整图背景 / 玻璃槽）。

## 0. 这轮改什么，为什么

用户原话三条，逐条落到可改的东西上：

| 需求（原话） | 落到规格 | 不做什么 |
|---|---|---|
| 「开始下潜感觉安排到右下角一个开始游戏 IcoN 里面」 | 中央主按钮 340×68 → **右下角 236×62 的「开始游戏」** | 不删中央区：中央改成船坞待机（见 §2） |
| 「选择机体和首个机枪 进入游戏给个选项」 | 新增**「出击准备」面板**：选潜航器 + 选开局武器，点开始游戏后才出现 | 不改主界面左右栏入口的归属 |
| 「主界面中间最好来点符合实际有趣的动画」 | **船坞待机动画**（闸门 + 悬浮机体 + 机械臂 + 气泡 + 鱼 + 声呐环） | 不做逐帧序列帧，全部运行时几何 + 节点属性 |

**为什么"选艇 + 选枪"要合成一屏而不是分两步**：这两个选择互相牵制（深潜者少 20 氧气上限但多一个装备槽 ⇒ 更愿意带鱼雷这类慢枪）。分两屏玩家得来回翻，同屏并列一次就能看出"艇+枪"组合长什么样。

## 1. 右下角「开始游戏」

| 项 | 值 | 依据 |
|---|---|---|
| 视觉尺寸 | **236 × 62** | 高 62 与 V6.38 的中央主按钮同档（该值是"主操作"的唯一基准，不新增第二套） |
| 中心位置 | `x = W − 32 − 118 = 1154`，`y = 640` | 右边距 **32** 与顶栏 `BAR_PAD` 同值；y=640 落在右栏底部（≈550）与底栏（706）之间，上下各留 59 / 35 |
| 实际占位 | x ∈ [1036, 1272] | 右缘 1272 ⇒ 距屏边 32；不与右分类栏（y ≤ 550）竖向重叠 |
| 热区 | **= 视觉区**（不再另做放大热区） | 236×62 已远高于点击区下限 88×88 的单边要求；叠一层不可见热区会让"看着没挨着却点到了" |

**文案**：`开 始 游 戏`（字间空格照 V6.38 的中文按钮惯例）。

⚠️ **这里措辞刻意不叫「开始下潜」**：按钮之后还有一步（出击准备），叫"下潜"会让玩家以为按了就进游戏，出现"怎么又弹窗"的挫败。**"开始游戏"= 进入准备流程**，"确认出击"= 真的下水。

## 2. 船坞待机动画（中央区）

### 2.1 构图与尺寸

中央区上半屏已被 **标题 176 / 副标题 236 / 装饰线 272** 占掉，所以舞台整体压在 272 以下。

| 元素 | 值 | 依据 |
|---|---|---|
| 闸门 | **340 × 258**，中心 `(W/2, 414)` | 占据 y ∈ [285, 543] ⇒ 上沿离装饰线 272 留 13px，下沿离底栏 706 留 163px |
| 潜航器显示直径 | **138** | 取 V6.38 中央主形象框 184 的 0.75 —— 闸门内要留出机械臂与气泡的活动空间 |
| 机械臂 | 肩关节在闸门左右上角外 12px；臂长 88（右臂 72） | 一长一短 + 相位错开，避免读成"钟摆" |
| 气泡 | 22 个，半径 1.6–5.0 | 只在闸门内画（越界不画，视觉上"在门里"） |
| 声呐环 | 2 圈，最大半径 170，周期 2.6s | 椭圆 `ry = rx × 0.42`，与机体 / 座圈的 3/4 俯视口径一致 |
| 鱼 | 3 条，周期 11s，纵向错开 46px | 从左向右横穿，位置 y = 352 / 398 / 444 |

### 2.2 动画参数（周期取非整数比）

| 动画 | 参数 | 为什么不取整数比 |
|---|---|---|
| 机体悬浮 | 振幅 **7px**，周期 **3.4s** | — |
| 机体摇摆 | 振幅 **3.2°**，周期 **3.4 × 1.7 = 5.78s** | 1 : 1.7 而非 1 : 2 —— 整数倍会让"浮动"与"摇摆"每几秒重新同步一次，读起来像脉动 |
| 机械臂 | 角速度 0.55 rad/s，振幅 5° / 4° | 两臂相位差 1.9 rad |
| 气泡 | 上升 16–42 px/s，横向摆动 6 px/s | 直线上升像"电梯"，加横向正弦才是水里 |
| 声呐环 | 生命周期 2.6s，透明度 `(1−p)² × 0.34` | 二次衰减：线性淡出会在末段"尾巴拖一坨" |

### 2.3 实现约束（**必须遵守**）

- **所有动画只写 `setPosition` / `angle` / `opacity`，不重画几何** —— 主界面会停留很久，每帧重画几百条线是纯浪费。唯一每帧重绘的是声呐层与气泡层，各只有 2 段弧 / 22 个圆。
- **机械臂几何一律朝 +x 画**，左臂靠 `setScale(-1,1,1)` 镜像。**左右臂的 base 角不能靠镜像推** —— Cocos 局部矩阵是 `T · R · S`（先缩放后旋转），镜像后同一个 base 角会朝反方向转。定稿：左臂 `base = −40, flip = false`；右臂 `base = +40, flip = true`。
- **层序硬约束**：`gStage / gSonar / gBubble / 机械臂 / heroArt` 属**场景**，必须整组建在 `tTop`（顶栏底 + 槽位底）**之前**。晚建的后果很具体 —— 鱼群横穿全屏时会盖在左右分类栏的图标上。
- 舞台**不参与 `layout()` 重绘**：它按设计坐标（`W=1304`）绘制，`fitHeight` 下 `W` 不变，所以视口变化不需要重排。

## 3. 「出击准备」面板

### 3.1 面板几何

| 项 | 值 |
|---|---|
| 面板 | **1040 × 600**，居中 ⇒ `x0 = 132`、`y0 = 74.5` |
| 面板底 | `GLASS.bar` @ 0.97 + 圆角 18 + 1.6px 青色霓虹描边 |
| 全屏关闭区 | 半透明暗幕 `0x03070b` @ 0.74（**scrim，不是 pageFill**），外扩 `padW/padH` |
| 顶栏横梁 | 高 62，圆角 18；标题「出 击 准 备」26px；右上角显示 `${bio} 沉淀` 16px |
| 关闭叉号 | 视觉 + 热区 **44 × 44**，面板右上角内缩 56 / 10 |

### 3.2 两行卡片

| 行 | 卡片尺寸 | 张数 | 行内起点 | 行 y |
|---|---|---|---|---|
| 潜航器 | **312 × 132** | 3 | x = 168（两行左边对齐） | `y0 + 112` |
| 首个武器 | **230 × 148** | 4 | x = 168 | `y0 + 290` |

- 间距 `CARD_GAP = 16`；两行总宽都是 **968**，居中于面板 ⇒ 左右各留 36px。
- 潜航器卡：左 66px 放立绘（显示直径 `SUB_DISC_CARD = 78`），右侧三行文本（名称 22 / 定位 15 / 特性 13）。
- 武器卡：立绘在卡片上半（容器 **同 2:1 比例**，宽 `WPN_CARD_W − 44 = 186` ⇒ 高 93），下方名称 17 + 说明 12 居中。
- **选中态**：卡片叠一档亮度 + 外扩 5px 描边 + **左侧 3×高 的青色竖条**（不依赖颜色的第二线索）。未选中的立绘 `sprite.color = 0x93aab4` 压暗，选中的 `0xffffff` —— **乘法只能压暗**，所以底色取浅灰而非纯白。

### 3.3 底部两键

| 键 | 尺寸 | 位置（面板内） | 语义 |
|---|---|---|---|
| 返回 | 160 × 56 | 中点左偏 230 | 关面板回主界面 |
| 确认出击 | **260 × 56**（宽一档） | 中点右偏 30 | 真下水 |

「确认出击」宽一档是**主次权重**的表达，不是随意取值。

### 3.4 键盘映射（两行都是横排，所以需要"焦点行"概念）

| 键 | 面板关着 | 面板开着 |
|---|---|---|
| `←` `→` | 循环潜航器 | **在当前聚焦行内**循环（焦点 = 潜航器行 ⇒ 换艇；= 武器行 ⇒ 换枪） |
| `↑` `↓` | 无 | 切换焦点行（潜航器 ↔ 首个武器） |
| `1` `2` `3` | 直选潜航器 | 直选潜航器（武器没有数字直选 —— 4 把且有分行语义，用 ←→ 更明确） |
| `Enter` / `Space` | 打开出击准备 | **确认出击** |
| `Esc` | 无 | 关闭面板（**关面板，不是退游戏**） |

⚠️ **面板开着时 `DiveGame.onKeyDown` 必须整体接管并 `return`**。漏了这层，面板里的 `↑↓` 会漏到下面被记成移动键，下一局开局时角色自己往一个方向漂（与暂停菜单"开暂停必须清 `keys`"是同一类坑）。

### 3.5 焦点视觉

聚焦行的**标题升一档色**（`TXT_LIGHT.dim` → `accent`），并在该行卡片左缘外画一条 **3px 竖条**（青 = 潜航器行、玉 = 武器行）。键盘玩家据此知道"现在 ←→ 会改哪一行"。

## 4. 数据与单一真源

新增 `shared/dive/loadout.ts`：

```ts
export const START_WEAPONS: readonly WeaponId[] = ['sonar', 'gun', 'torpedo', 'arc']
export const DEFAULT_START_WEAPON: WeaponId = 'gun'
export function startWeaponIndex(id: WeaponId | undefined): number
```

- **默认取 `gun`（机关枪）而不是列表第一项（声呐）** —— 机关枪是原版一直用的开局武器。改成声呐会**静默改掉所有老玩家的第一局手感**。
- `WorldOptions.weapon?: WeaponId` → `DiveWorld` 存在 `private readonly startWeapon` 字段上（**不能直接塞给 `startRun()`** —— 它也被重开路径调用，那里作用域没有 `opts`）。
- `DiveGame.lastWeapon` 记住本局开局武器：暂停菜单 / 结算屏的「再来一次」不会再弹面板，必须沿用上一局的枪。
- 武器**名称与说明取自 `WEAPON_DEF`**，不在视图层抄第二份。
