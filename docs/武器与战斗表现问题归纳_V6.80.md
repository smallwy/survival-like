## 二、第 1 条评估：施法速度（有数字）

**结论：太快。病根不是"某一门炮的基础射速"，是「射速复利」——4 个乘数全乘在 `iv` 的同一个轴上。**

`shared/dive/world.ts:2041` 的实际公式（改前）：

```
ivLast = 基础 iv ÷ [ (1 + (等级−1)×0.12) × seatBoost × (1 + 高压供能) ] × 过载核心
```

| 乘数 | 来源 | 最大幅度 |
|---|---|---|
| 等级 | 武器升级 | 5 级 = **÷1.48** |
| `seatBoost` | 双联座（每个外座） | 1 + `twinRate`（每层 **+0.25**） |
| 高压供能 | `rate`（每层 **+0.10**） | ÷(1+rate) |
| 过载核心 | 遗物 | 5 级时 **÷1.25** |

**实测推演（改前）**：

| 场景 | 有效间隔 | **发/秒** |
|---|---|---|
| `gun` 1 级裸装 | 0.110 s | 9.1 |
| `gun` 3 级 + 高压供能 ×2 | 0.071 s | **14.1** |
| `gun_gl` 5 级 + 高压 ×4 + 双联 + 过载 | 0.013 s | **≈74** |

> 成型后同一门枪每秒吐 70+ 发 —— 屏幕上它不是"在射击"，是一条**不间断的光带**，
> 看不见单发子弹，也就看不见"我打中了什么"。与「弹幕可读」直接冲突。

### 拍板结果：**方案 B —— 抬基础 + 等比补伤害**

- **只动基础款 `iv < 1.0s` 的族**（`gun` / `sonar` / `arc` / `harpoon` / `mine`）——
  它们的"快"是设计问题；`torpedo`(1.5) / `echo`(1.5) / `acid`(1.4) / `net`(1.1) / `lure`(2.4)
  本来就慢，**一律不动**。
- 整族 **`iv` ×1.36**，**`dmg` 按同一比例补偿** ⇒ **DPS 逐条不变**，只是"每发更大更稀"。
  ★ 这条是硬约束：DPS 一动，击杀速度就动，**P0 收支曲线**跟着动。
- `gun_gl` 是离群值（基础 19.2 发/秒）⇒ 单独多压一档到 **0.080**（×1.54），`dmg` 同步补。

| id | iv 改前 → 改后 | dmg 改前 → 改后 | 发/秒 |
|---|---|---|---|
| `gun` | 0.11 → **0.15** | 7 → **9.5** | 9.1 → 6.7 |
| `gun_gl` | 0.052 → **0.080** | 6 → **9.2** | 19.2 → 12.5 |
| `gun_sg` | 0.44 → **0.60** | 5 → **6.8** | 2.3 → 1.7 |
| `sonar` | 0.42 → **0.57** | 12 → **16.3** | 2.4 → 1.8 |
| `sonar_rs` | 0.55 → **0.75** | 9 → **12.2** | 1.8 → 1.3 |
| `sonar_fc` | 0.62 → **0.84** | 30 → **40.8** | 1.6 → 1.2 |
| `arc` | 0.90 → **1.22** | 16 → **21.8** | 1.1 → 0.8 |
| `harpoon` | 0.75 → **1.02** | 20 → **27.2** | 1.3 → 1.0 |
| `mine` 族 | 0.55 → **0.75** | 18/15/11 → **24.5/20.4/15.0** | 1.8 → 1.3 |

> ⚠️ **本口径没有给复利设上限**（那是我原来推荐的方案 A，用户选了 B）。
> 复利保留是**刻意的** —— 那是养成手感的一部分。若实机仍嫌密，再谈"封顶"。

## 四、实现清单（逐条）

### #2 追踪鱼雷（`tables.ts` + `DiveGame.ts` 弹体绘制）
- **新色 `UI.ember = 0xff8a3c`**（`shared/theme.ts`）。依据：`danger` 的定位写在代码里就是
  「**全场唯一纯红，只允许用在致命预警**」—— 玩家自己的弹体染预警色 ⇒ 分不清"这是危险还是我的武器"。
- **弹体**（`BULLET` 绘制，`b.kind === 'torpedo'` 独立分支）：
  螺旋桨气泡尾迹 → 外发光晕 → **等宽圆柱身** → **钝圆头** → **后掠尾翼（1.85× 身宽）** → 引信灯。
  ★ 判据：**圆头 = 鱼雷与子弹的分界**；**等宽身**（锥形是火箭）；**翼展不能大过身太多**
  （第一版 2.5× 时剪影被翼吃掉 ⇒ 又读成"箭头"，降到 1.85× 且翼根退到身尾）。

### #3 声纳波前（`DiveGame.ts` `w.pulses` 绘制）
三重递减波前（主前 + 0.83r / 0.66r 滞后回声）+ 沿主前均布 24 道**声呐束齿**（整组缓慢自转）
+ **距离衰减** `fade = 1 − 0.72k`。
- ⛔ **判定半径一点没动** —— `p.maxR` 就是伤害半径，视觉必须画在真半径上；
  "看起来没那么大"是靠外圈自己淡掉做的，**不是缩视觉骗判定**。
- ⚠️ 抖动/束齿相位**不用 `Math.random()`**（同帧多道波前会抖，同爆炸破片那条判据）。

### #4 电弧 = 闪电链（`DiveGame.ts` arcs 渲染）
- ⚠️ **传导机制从 V6.33 起就有**（`world.fireArc`：链 `2 + lvl`、跳距 190、`arc_ov` +4 不衰减）——
  本次**一个字都没改模拟层**，改的纯粹是"这一串跳跃长什么样"。
- 三条：① **每跳 = 独立闪电路径**（段内插值 + 垂直抖动，包络 `sin(πt)` ⇒ **两端钉在敌人身上**）；
  ② **逐跳衰减**（第 n 跳更细更暗 ⇒ 传导有损耗）；③ **落点爆闪 + 3 段缠绕弧**（"它中电了"）。

### #6 渔网（`DiveGame.ts` 弹体绘制 + `rootT` 状态绘制）
- **抛出**：网兜（闭合多边形，`b.life` 驱动**自转**）+ 8 条收口索 + 兜口铅坠 + **牵引绳**。
  ⚠️ 收拢态**不能摊开** —— 摊开会让玩家以为飞行途中就有判定范围。
- **捆住**：`rootT` 只由网族写入（`world.applyNet`），所以这里可以放心画"网"：
  **三道横向缠绕椭圆绳圈**（垂直于体轴 ⇒ 有方向感）+ **两条纵向收口索** + **捆住那一下的张力白闪**。
- ⚠️ 必须与「缠索」（玩家侧，`w.tetherSrc`）一眼分开：那边是"索 + 向外拽的短须"。

### #5 精英标记（`DiveGame.ts` `drawEnemies`）
空琥珀闭合环 → **三层低透明填充辉光**（r×2.05 / 1.45 / 0.98）+ **两颗沿体表绕游的光点**。
**⛔ 不画任何闭合线**。把"值得打"的读法落回**鱼自己在发光**（与鱼骨"发光 = 值得"同源）。

### #8 删除右上角鱼骨计数（`Hud.ts`）
整段删除（`strokeCircle(W−106, by+34, 7)` + 裸数字）。代价已记在代码注释里：
战斗中不再常驻显示购买力（V6.78 曾立的判据），鱼骨数现在只在**商店顶栏**与**结算屏**出现。
⚠️ **别顺手挪到别处"补回来"** —— 用户的诉求是这个位置突兀，不是"换个位置"。

### #9 游群扑击前摇（`shared/dive/world.ts`）
`swarm` 从"一路直冲"改成 **`chase → charge → dash → rest`**（与 `dash` 同构，但更短更近）。
- `SWARM_LUNGE_R = 130` / `SWARM_CHARGE_T = 0.30` / `SWARM_DASH_MUL = 1.75` / `SWARM_DASH_T = 0.26` / `SWARM_REST_T = 1.2`
- ★ 三条克制：① **只在贴脸前触发**（触发距离一大 = 一屏鱼集体停在半路）；
  ② **有冷却**（没有冷却 = 一群鱼反复原地抽搐）；③ **蓄力不位移，但冲刺速度照乘 `slow`**
  （同 `dash`：否则"网住了但一个扑击就窜到脸上"，控场武器白给）。
- ⚠️ 起手时**锁死方向**（`dirX/dirY`）—— 前摇存在的意义就是"我冲这里"。
- ⚠️ 表现层：swarm **不整机泛红、不画整圈预警环**（一屏可能十几只同时蓄力 ⇒ 满屏红环，
  正是用户刚在 #5 上报过的"自己画的圈"）⇒ 改用**后侧收势弧 + 细箭杆**。

### #10 受击反馈局部化（`DiveGame.ts` `drawVeil` / `drawPlayer` / `handleEvent`）
- **删**：`drawVeil` 里按受击来向铺满屏幕高的 **6 条红带**。
- **加**（全部落在自机）：① `handleEvent('playerHurt')` → 自机冲击环（r40 / 0.20s）+ 受击面溅射 8 颗；
  ② `drawPlayer` → **机身受击弧**（来向 ±72°，`SUB_D×0.52 ≈ 45.8`，略在剪影外 1.8px）+ 内侧白弧。
  **只覆盖来向，不是闭合环**（铁规 14）。
- 屏幕层（`gVeil`）**不再参与受击表达**。

⚠️ **沙箱开不了 Creator** ⇒ 以下必须实机目视：
1. 声纳三重波前在满屏弹幕里会不会糊成"一个厚圈"；
2. 闪电链在 6 只以上连锁时会不会过曝（每跳 4 层描边 × 段数）；
3. 游群扑击的**触发频率** —— 一屏 30 只时会不会读成"鱼群整体卡顿"（`SWARM_REST_T` 可能要调）；
4. 精英辉光在 L3/L4 深色层会不会被贴图吃掉；
5. 鱼雷的**暖橙**在青蓝水体里是否足够醒目（这是换掉红色的代价：红色最跳，橙色次之）。
