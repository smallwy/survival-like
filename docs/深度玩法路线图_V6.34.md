# 深度玩法路线图 · V6.34

> 起因：用户提问「目前游戏没有深度，只有几分钟的玩法吸引力。你怎么做深度玩法？是有关卡吗？」
> 本文档：**先用代码事实回答"是不是缺关卡"，再给把"几分钟"变"再来一局"的路线图。**
> 日期：2026-10-13 ｜ 适用引擎：Cocos Creator 3.8.8（web 原型本轮不追，见 §6）

---

## 0. 一句话结论

> **不是"缺关卡"。** 深海里的"关卡"等价物 = **5 层深度带（L1阳光带→L5深渊带）**，每层一个独立机制 + L5 Boss，
> **这些代码里都跑了**。单局其实是 **15–20 分钟**，不是"几分钟"。
>
> 真正让玩家"玩几分钟就走"的是另外两件事：
> **① 局间钩子几乎为零（死了不推进任何东西）② 组合空间偏窄（遗物 12 / 设计要 30）。**

---

## 1. 深度从哪来：三层叠加模型

这个品类（Brotato / 吸血鬼幸存者，Valve 官方标签 **Bullet Heaven**）**不靠"选关"做深度** —— 线性选关会杀死重玩性。
它的深度是三层叠加出来的：

| 层 | 作用 | 玩家的问题 | 现状 | 代码证据 |
|---|---|---|---|---|
| **L-A 局内压力弧** | 一局之内"越来越险" | "我撑得住吗？" | ✅ **已做** | 5 层 × 4 波 = 20 波；每层独立机制；L5 Boss；氧张力曲线 |
| **L-B 局间成长** | 死了也不白玩 → 想再来一局 | "这一局留下了什么？" | ❌ **几乎空** | `profile.ts` 只记分，**0 解锁** |
| **L-C 组合空间** | 每局 build 都不一样 | "这局试个新流派？" | 🟡 **半成品** | 武器 7 基础 + 14 进化 = 21 ✓；遗物 **12**（设计要 30）✗ |

**"关卡"在这类游戏里的三层替身**（玩家想要"阶段感"，正确做法不是选关）：
1. **深度带 = 章节**：L1→L5 就是五个"章"，每章换敌人 / 换机制 / 换视觉签名 —— **已有**。
2. **难度阶梯 = 二周目**：通关后解锁 Danger 1/2/3…，每级加一条全局规则 —— **未做**。
3. **里程碑**：图鉴 / 成就 / 最深层纪录 —— **只做了"纪录"，没做"解锁"**。

## 2. 现状盘点（全部来自代码，不是拍脑袋）

### 2.1 一局到底多长？（`tables.ts` LAYERS / LAYER_WAVES）

| 项 | 值 |
|---|---|
| 层 | 5 层（阳光带 / 弱光带 / 午夜带 / 热泉带 / 深渊带） |
| 每层波数 | 4 波，**每层总战斗时长 156s**（硬约束） |
| 一局战斗 | 5 × 156s = **780s ≈ 13 分钟** |
| 波间喘息 | 8s（只做拾取 + 三选一） |
| 层末 | 补给站（买氧/武器/遗物）+ **下潜 or 上浮决策** |
| **单局合计** | **≈ 15–20 分钟**（含波间与补给站） |
| 死亡 | 氧气归零 = 本局收益全损 |

### 2.2 已经落地的"深度"（比想象多）

| 系统 | 状态 | 位置 |
|---|---|---|
| 5 层独立机制 | ✅ | L2 暗流 / L3 涌流 / L4 热泉（顶开你）/ L5 压力（每波压上限） `tables.ts:359` |
| 下潜 / 上浮决策 | ✅ | `world.ts:1461 descend()` / `:1488 ascend()` |
| Boss 波 | ✅ | L5 末波 `world.ts:248 spawnBoss()`（深渊守望者） |
| 氧张力曲线 | ✅ | 全捡 1.28×→0.98×、常规 0.83→0.64 `tables.ts:352` |
| 潜航器（机制差异） | ✅ | 3 台（Lumen / Raia / Bathy） |
| 武器形态 | ✅ | **7 基础 + 14 进化 = 21**（`pool.ts`） |
| 遗物（改打法） | 🟡 | **12**（设计要 30）`tables.ts:285-345` |

### 2.3 真正空的两块

| 缺口 | 事实 | 后果 |
|---|---|---|
| **局间成长（L-B）** | `profile.ts` 只有 6 个字段：`bestBiomass / bestLayer / bestWave / runs / cleared / lastSub` —— **全是"纪录"，没有一个"解锁"** | 死了一局，玩家手上的选项**一件没多** → 没有"再来一局"的理由 |
| **遗物组合空间（L-C 的半边）** | 遗物 12 / 设计 30；且设计强调"至少 8 个机制改变型" | 12 选 6，能凑的差异化 build 有限 |

## 3. 为什么"只有几分钟吸引力"——两个真因

1. **头号：局间不推进。** roguelite 的粘性内核是"**失败了也在变强**"。
   现在死了 = 新纪录归零重来，玩家感受是"白玩一局"。**这是"几分钟就走"的最大来源，且与关卡数量无关。**
2. **次要：build 差异不够。** 武器侧其实达标（21 形态），但**遗物（唯一"改打法"的一类）只有 12 个**，
   组合乘法不够 → 每局手感趋同 → "看过了就不想再玩"。

## 4. 路线图（按性价比排序）

> 原则：**先用最高杠杆的一刀把"再来一局"的钩子装上**，再补组合空间，最后加长线目标。

| 优先级 | 内容 | 解决 | 量级 |
|---|---|---|---|
| **P0** | **meta 解锁层 + 图鉴**（profile v2） | 局间钩子（真因 1） | 中 |
| **P1** | 遗物 12 → 24+（机制型优先） | 组合空间（真因 2） | 中 |
| **P2** | 难度阶梯（通关解锁 Danger 1/2/3） | 老玩家长线目标 | 小 |
| **P3** | 每日种子 / 挑战模式 | 长尾留存 | 小 |
| **P4** | 第 4 类敌人（重甲）+ Boss 多样化 | 局内新鲜感 | 中 |

**顺序理由**：P0 是"没玩够"的解药，且改动集中（只碰 `profile.ts` + 存档 + 标题屏）；P1 需要 P0 的图鉴做"收集容器"才显价值；
P2/P3 是内容铺开后再加更划算。

## 5. P0 详细方案：meta 解锁层（把"记分板"升级成"解锁引擎"）

### 5.1 存档结构（`profile.ts` v1 → v2，向后兼容）

```ts
export interface Profile {
  v: number
  // —— v1 已有（保留）——
  bestBiomass: number; bestLayer: number; bestWave: number
  runs: number; cleared: boolean; lastSub: SubId
  // —— v2 新增 ——
  bio: number                 // 累计"沉淀生物质"（跨局货币，永不归零）
  unlocked: {                 // 解锁集（id 列表，默认给一套起始内容）
    subs:  SubId[]
    weapons: WeaponBaseId[]   // 进商店初始池的武器
    relics:  RelicId[]
  }
  codex: Record<string, number>  // 图鉴：id → 遭遇/击杀次数（>0 = 已见）
  danger: number              // 已解锁的最高难度档（0 = 基础）
}
```

> **兼容策略**：沿用现有 `normalizeProfile` 的"逐字段回退"原则 —— 读到 v1 档案时，
> 新增字段用 `defaultProfile()` 填默认（`bio=0`、给起始解锁集），**不丢老纪录**。`PROFILE_VERSION` 升到 2。

### 5.2 生物质怎么来（不破坏局内随机性的红线）

| 来源 | 值 | 说明 |
|---|---|---|
| 上浮兑现带出的生物质 | **30%** 沉淀为 `bio` | 溺水只沉淀 **10%**（失败也有微量推进，但远少于成功 → 仍鼓励上浮决策） |
| 首次击杀某生物 / 首见某武器 | +一次性奖励 | 图鉴驱动 |

> ⚠️ **红线**：沉淀比例**必须**低（≤30%）。高了会让"上浮兑现 vs 继续下潜"的取舍失效 —— 那是 V6 的立身之本（§3.3 计划书）。

### 5.3 解锁什么

| 类别 | 解锁方式 | 数量 |
|---|---|---|
| 潜航器 | `bio` 购买（第 2/3 台） | 3 |
| 武器 | 图鉴达成（击杀特定敌人 N 次）解锁进池 | 7 |
| 遗物 | `bio` 购买解锁进池 | 12 |
| 永久微强化 | `bio` 购买（上限受控：如氧上限 +2 / 拾取 +3%，**各限购 3 次**） | ~6 |

### 5.4 图鉴（收集容器）

- **20 种生物**（击杀 → 解锁标本条目：名称 / 层级 / 弱点 / 掉落）
- **21 种武器形态** + **12 遗物**（使用/装备过 → 点亮）
- 图鉴完成度 = 一个**长期目标**，也是"多玩几局"的直接理由。

### 5.5 难度阶梯

- 通关（击杀深渊守望者）→ 解锁 **Danger 1**；每级加一条全局规则（敌血 +15% / 氧耗 +10% / 掉落 −10%）
- 给老玩家一个"更大数字"的靶子（Brotato / VS 的标配长尾装置）。

## 6. 边界与风险

| 项 | 说明 |
|---|---|
| **web 原型** | 本轮**不追**（用户已确认）。web 自 V6.29 起落后于 `shared/dive`，追平应作为独立一轮处理 |
| **不破坏随机性** | meta 只解锁"**进池资格**"与"**微量属性**"，**绝不做"局外氪金直加局内强度"** —— 那会直接招致"换皮"差评（计划书 §11） |
| **沉淀比例红线** | ≤30%，见 §5.2 —— 保住下潜/上浮取舍 |
| **存档迁移** | 必须能在 v1 档案上安全升级（逐字段回退），旧玩家不丢纪录 |
| **标题屏改造** | `bio`/图鉴/难度入口要在标题屏有位置 —— 属 UI 改动，走既有 UI 规格（设计分辨率 1304×749 fitWidth） |

## 8. 还会有哪些机制玩法？（机制存量盘点）

> 用户追问「按你的分析，游戏会有其他的机制玩法吗」。先说**判断口径**：
> 一个机制值不值得加，看它是否制造**新决策**或**新组合**。纯粹"+5% 伤害"不算机制 —— 这也是计划书 §5.1「少而深」与 §11「明确不做」的立场。

### A 类 · 计划书**已设计、但没做**（最现成，不用重新设计）

计划书 §5.2 列了 8 把武器，实际只实装 7 族（`WeaponFamily`：sonar / gun / torpedo / arc / harpoon / echo / acid）。
**差在 4 把**——而且它们是**机制型**的，不是数值型：

| 武器 | 新维度 | 进化 A | 进化 B |
|---|---|---|---|
| 网发射器 | **控场** | 电网（减速 + 灼烧） | **收容网**（把敌人转化为友方单位） |
| 生物光诱饵 | **聚怪** | 爆炸诱饵（延时爆） | 光墙（封锁走位） |
| 水流推进器 | **位移** | 涡流（拉扯敌人） | 冲刺撞击（无敌帧 + 高伤） |
| 气泡雷 | **陷阱** | 连锁雷（串联爆） | **氧气雷**（爆炸回氧） |

> **收容网 + 氧气雷**是计划书特意点名的两条 —— 它们把"击杀"与"氧气"**反向挂钩**（用敌人换资源），
> 是能产生真正新鲜流派的机制。**这 4 把是整个机制存量里性价比最高的一批。**

### B 类 · 值得**新增**（按能创造的决策密度排序）

| # | 机制 | 它制造什么决策 | 服务的主线 |
|---|---|---|---|
| 1 | **场地机制**（洋流场 / 热泉喷口 / 可破坏礁石） | 去捡氧泡的**路径被地形改变** | 直接强化氧张力 ★最高性价比 |
| 2 | **重甲敌人**（计划书 §3.5 第 4 类，未做）+ 分裂/召唤/护盾 | 逼玩家**换武器 / 换 build** | 组合空间 |
| 3 | **冲刺 dash / 第二主动技能**（现只有「排气爆发」） | 走位的**风险—回报** | 局内操作深度 |
| 4 | **局内随机事件**（精英波 / 宝箱波 / 洋流突变 / 鲸落） | "**这一局不一样**" | 重玩性 |
| 5 | **Boss 多阶段 / 多形态**（现单一守望者） | 波峰的记忆点 | 局内新鲜感 |

### C 类 · **明确不建议加**（会偏离主线，§11）

护甲相克 / 复杂属性表、手动瞄准为主、联机、3D、局外氪金直加局内强度、独立港口场景。
（"爬塔 / 卡牌 roguelike" 那条也偏了 —— 会稀释"氧气四合一"这个差异化。）

### 落点

- **存量最大的是 A 类**：计划书自己就躺了 4 把没做，**直接实装即可**，不需要重新设计。
- **但顺序上仍建议先做 P0 meta** —— 机制回答"**玩什么**"，meta 回答"**为什么留下来**"。
  机制再多，没有局间钩子，玩家仍是"玩几分钟就走"。
