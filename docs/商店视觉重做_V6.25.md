# 商店界面视觉重做 —— 交付说明（V6.25）

> 对应代码 `BUILD_TAG = v6.25`｜截图 `tools/shots/v625_default|hover|info.png`
> 触发：用户反馈「这个界面总感觉很 low」，并给出 Brotato 的**升级**与**商店**两张参考图

---

## 一、先量了一遍，把"low"变成数字

对用户截图取样（卡内 / 卡与卡之间的背景）：

| 区域 | 平均亮度 | 亮度方差 |
|---|---|---|
| 卡与卡之间的背景 | **62** | **51** |
| 卡内 | 34 | 29 |
| 立绘区内部 | 37 | **26.6** |

**全场最亮、最"花"的地方是卡片背后的装饰，不是玩家要做的决策。** 两条根因：

1. **背景还在画海景装饰**（霓虹圆环、透视网纹、远处水母剪影）
2. **卡面是半透明的**（`alpha 0.96 / 0.74 / 0.42`），背景的光直接透进卡里 ——
   一张"实底卡"的卡内方差应该接近 0，实测 26.6，那是噪点不是氛围

Brotato 那两张图反过来：背景**近纯黑**（亮度 ~15、方差 ~5），卡是**不透明实底**、
比背景亮一档。**"清晰简单"来自对比，不来自装饰。**

## 二、改了什么

### 1. 新增一套菜单实底色板（`theme.ts` 的 `MENU`）

| 键 | 值 | 用途 |
|---|---|---|
| `page` | `0x0a0e14` | 页面底（近纯黑） |
| `slot` | `0x0c1117` | 立绘位 / 价格条（**比卡面更深**，让内容"跳"出来） |
| `card` | `0x1a212c` | 卡面实底 |
| `cardHi` | `0x232c39` | 悬停卡面 |
| `divider` | `0x2b3543` | 卡内分隔 |
| `edge` | `0x39455a` | 中性描边 |

明度阶梯必须满足 **`page` < `slot` < `card` < `cardHi`**。
游戏内 HUD 仍然用原来的霓虹半透明 —— 那里要的是氛围与穿透，不是信息密度。

### 2. 逐条对照

| 项 | 改前 | 改后 |
|---|---|---|
| 背景 | 海景装饰 + 0.42 暗幕 | **纯实黑页面** + 上下两条极淡压暗带 |
| 卡面 | 半透明（0.42~0.96）+ 投影 + neon 辉光描边 | **不透明实底** + `lineStyle` 硬边，无辉光、无投影 |
| 类型标识 | 卡顶 3px 色带（余光扫不到） | **整条边框 = 类型色**（Brotato 用边框区分稀有度，我们用它区分类型） |
| 状态表达 | 靠透明度分"可买 / 买不起" | 靠**边框亮度**分（可买 0.7 / 悬停 1.0 / 买不起 0.26）—— 类型色始终认得出来 |
| 立绘位 | 0.62 半透明画框 + 展台光晕 + 透视网纹 | **不透明深底槽** + 1px 细边（删掉展台三件装饰） |
| 属性卡 | 只有一根细进度条，整块立绘位几乎空 | **大符号 + 属性色进度条**（新增 `drawStatGlyph`，12 种属性各一个几何符号） |
| 名称 | 青色 22px | **纯白** 22px（青色留给数值，不让两种信息抢同一种颜色） |
| 描述 | 冷白 14px | **绿色 14px**（这是"这张卡给我什么"的收益行，Brotato 就是绿的） |
| 状态行 | 青/琥珀 13px | **灰色 13px**（它是元信息；只有"受阻"才保留橙） |
| 价格条 | 0.6 半透明底 | **不透明深底** |
| 底栏按钮 | 两个 neon 描边块 | 次按钮 = 扁平深色块单行；**主按钮 = 实心亮块 + 深色字（反白）** |

### 3. ★ 顺手挖出的一个真 bug：商店背后一直飘着远景生物

改完背景之后，卡片之间仍能看到**远处的生物剪影在飘**（截图里左右两侧的圆圈+竖线）。

根因：环境层画在 `gBg`（depth 5），但它**没有被 `uiCam.ignore`** ——
于是它被 uiCam 再画了一遍，**盖在商店底色之上**。这不是深度问题
（depth 10 的商店底本该压住 depth 5），是**两个相机的渲染次序**问题。

修法：`drawEnv()` 在弹窗相位直接 `clear()` 后 `return`，不画环境层。
（商店是一整张实底页，本来也不该有世界背景透上来。）

### 4. 顺带的两处小修

- `txt()` 加 `stroke` 参数 —— 实心亮按钮上的**深色字必须关掉默认的深色描边**，
  否则深色字 + 深色描边糊成一块
- 顶部提示行、顶栏、鱼骨胶囊、侧栏页签全部改实底

## 三、改完的实测

| | 改前 | 改后 |
|---|---|---|
| 左右留白背景 平均亮度 | 29.9 | **14.7** |
| 左右留白背景 **方差** | 3.0 | **0.0**（完全平坦） |
| 卡内亮度 − 卡间背景亮度 | **−5**（背景比卡亮） | **+12**（卡比背景亮） |

最后一行是关键：**焦点从"背景装饰"回到了"卡片"**。

## 四、还没做 / 要你定的

### 1. Brotato 的"升级"是**另一套系统**（这是设计问题，不是视觉问题）

Brotato 有两个界面：
- **升级！**（战斗中途，靠击杀攒经验触发）→ 4 选 1 属性，**不花钱**
- **商店**（波间）→ 花钱买武器 / 道具

我们现在只有**商店**，属性卡也放在商店里（要花鱼骨）。所以"战斗中随机升级"这件事**目前不存在**。

要不要加？两种做法差别很大，**我没有动**：

| 方案 | 说明 | 代价 |
|---|---|---|
| **A（现状）** | 全部走商店，属性卡也花钱 | 保留"钱怎么花"的取舍；但没有战斗中期的节奏变化 |
| **B 加 XP 升级** | 击杀攒经验 → 战斗中途弹 3 选 1 免费属性 | 更接近 Brotato 的节奏；但要新增经验条 + 升级弹窗 + 与商店卡池分层，且会**削弱氧气经济的紧张感**（免费属性=白给强度） |

### 2. 侧栏面板还没重做

`查看状态` 展开的属性 / 遗物面板仍是旧的半透明风格，和新的卡面语言不一致。
（而且被动槽改 6 会把它撑出视口，那块要一起改。）
