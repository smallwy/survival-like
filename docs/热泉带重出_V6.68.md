## §1 根因：热泉不发光，是**矿物**

| | 我写的 | 真实的 |
|---|---|---|
| 机理 | 「地热自发光照亮水体」 | 喷出的是**热水 + 矿物微粒**，在 2°C 深海里瞬间冷却 ⇒ **浑浊烟羽** |
| 黑烟囱 | — | 富硫化物热液 ⇒ **黑色**烟羽 + 黑色烟囱体 |
| 白烟囱 | — | 富钙碱性热液 ⇒ **乳白色**碳酸盐烟羽 + 白色塔 |
| 那点"橙红" | 被我当成自发光 | 是 **ROV 探照灯 + 岩面铁氧化物沉积**，**不是**自发光 |

⇒ **⛔ 只要画面里出现"橙红色自发光"，它在玩家眼里就只有一个读法：火/岩浆。**

**"热"要靠间接线索给**，不靠"它自己在发光"：

- 岩面上的一小片**暗锈橙沉积**（面积小、不发光、贴在下缘岩面，像岩石本身的锈斑）；
- 烟羽**向上翻涌扩散**的运动形态；
- **成排的管虫丛**（热泉的标志性生物）。

## §2 ★ 新增判据层二：**"这地方鱼会来吗"**

V6.67 立了层一 —— **"背景图是擂台，不是风景照"**（中部要空、地形只放上下缘）。
本轮补层二：**环境必须能承载"生物在这里生活"这件事**。

**三问**（任一答不上来，这张图就不能用作打鱼场）：

| 问 | 热泉带（真） | 火焰（错的画法） |
|---|---|---|
| ① **有食物吗** | ✅ 化能合成细菌 → 管虫 → 虾蟹 → 鱼，**深海最繁盛的食物链** | ❌ 高温灭菌 |
| ② **温度对生物是危险还是舒适** | ✅ 喷口极热，但生物活在**烟羽外围的 2°C 冷水**里 | ❌ 整片都热 |
| ③ **画面里有生物吗** | ✅ 管虫丛 + 成群盲虾小鱼 + 两三层鱼群 | ❌ 不可能有 |

★ **第 ③ 条是最直接的证明** —— 不用跟玩家解释生态，**画面上有生物本身就是"这地方能住"的证据**。
反过来：**"发光"是极强的负向符号**（火 = 危险 + 高温 + 无生命），它会一次性否掉①②③。

> ⚠️ **这条判据不限于热泉带** —— 任何"鱼群出没"的背景都先过这三问，
> 再谈构图和亮度。**先问"鱼会不会来"，再问"好不好看"。**

## §4 ★ 两条判据是我自己定错的（V6.68 修正）

### 4.1 「上下无缝」对**有地形的带**不成立

- 原判据（V6.58）：`首行/末行逐列平均亮度差 ≤ 14` —— 为**纵向滚动 wrap** 服务。
- 实测：L1 `49.0` / L2 `47.7` / L4v4a `67.8` / L4v4b `74.9` 全部 FAIL。
- **但这是必然的**：有海床的带**顶部是水、底部是海床**，首末行本来就不同色 —— **那是内容，不是缺陷**。
- ⇒ 判据改为**只对无地形带（L1/L2/L5）生效**（`SEAM_SKIP = {'L3','L4'}`）。
- 连带：整图纵向滚动本身已按 V6.67 建议改**视差**（背景不动、只动颗粒与鱼群）
  ⇒ 真要说接缝，该看的是**横向**能不能平铺，不是上下。

### 4.2 「局部光源」不能用 p98 判

- 我第一版写 `p98 ≥ 110` ⇒ **L3 判 FAIL（p98 = 100）**，但 L3 的观感是**对的**。
- 原因：生物荧光是**一堆分散的亮小点**，最亮那 2% 里混了大量"半亮的荧光线" ⇒ p98 被拉低。
  **面积大但峰值低**被误判成"没有亮区"。
- ⇒ 改为**双条件**：`p99 ≥ 130`（**峰值够亮**）**且** `亮部占比 ≥ 1.5%`（**面积够**）。
  缺一个都不行 —— 否则"一个亮斑"或"一片灰亮"都能骗过单一判据。
- 修完：L3 `p99 153 / 2.7%` ✅、L4a `169 / 25.3%` ✅、L4b `160 / 21.2%` ✅。

**⚠️ 两次都是同一个毛病：把"定性判据"写成了"精确判据"。** 阈值一律留 ±2 噪声余量
（此前 `FISH_CX` 已踩过一次）。
