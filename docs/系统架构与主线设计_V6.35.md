# 系统架构与主线设计 · V6.35

> 起因：用户澄清「我说的不是局内玩法，是整个游戏的不同系统 / 机制实现 / 和主线玩法。」
> 本文档：把"游戏"拆成**四层系统栈**，盘点每一层的实现现状，并回答"主线玩法"到底是什么、该怎么补。

---

## 0. 口径：把"游戏"拆成四层

| 层 | 时间尺度 | 它回答的问题 |
|---|---|---|
| **L0 核心循环** | 秒级 | "手上有事做吗？"（打·走·捡） |
| **L1 局内系统** | 分钟级 | "这一局怎么玩？"（波次·商店·build·氧·下潜） |
| **L2 元系统** | 局级 | "上一局留下了什么？"（解锁·图鉴·难度·经济） |
| **L3 主线** | 全局（跨很多局） | "我在朝哪走？"（旅程·目标·结局） |

> 之前几轮（V6.28~V6.34）打磨的都是 **L0/L1**；用户的疑问落在 **L2/L3**。

## 2. 什么叫"主线玩法"——现在是个**循环**，不是一条**线**

现在的主线是：**下潜 → 打 20 波 → 上浮兑现 / 溺水**。
这是一个 **loop**（可重玩），**没有终点、没有方向**——只有一个 `cleared` 布尔记录"击杀过守望者"。

要让游戏有"主线"，有三种形态：

| 形态 | 是什么 | 优点 | 代价 |
|---|---|---|---|
| **A · 纯循环** | 不设终点，靠难度阶梯撑长（Brotato / 吸血鬼幸存者） | 最省，最像对标品；最耐玩 | 没有"旅程感 / 结局"，单机玩家会觉得"没通" |
| **B · 海域关卡主线** | 地图上**多个下潜点**，每个 = 一套 5 层 + 专属 Boss + 专属敌潮；攻克一个解锁下一个 | **这就是你最早问的"关卡"**；给方向与结局；仍保留 roguelite 随机性 | 需要"关卡选择"系统 + 每关的内容量 |
| **C · 母港 / 基地经营** | 回港升级潜艇 / 科技树 / 科技解锁 | 给"系统厚度"，像一款更大的游戏 | 工作量大；**且稀释"氧气四合一 · 少而深"** —— 计划书 §11 已明确不做 |

### ★ 推荐：**A（底）+ B（一层薄主线）**，明确不做 C

- **A 做底**：单局 roguelite 循环保持现在这样（已经能玩）。
- **B 做线**：加一个**海域 / 下潜点**选择 —— 每个海域一张"5 层深度带"，主题、敌潮、Boss、色板都不同；
  通关一个 → 解锁下一个 → 直至"最终海沟"。**这就是把 loop 变成 line 的那一刀。**
- **C 不做**：母港经营会把开发量翻倍，并稀释唯一的差异化。**要克制。**

## 3. 推荐的完整系统架构（补完之后的样子）

```
L3 主线      ┌ 海域关卡选择 → 逐个攻克 → 结局/二周目 ┐
L2 元系统    ┌ 生物质沉淀 → 解锁(潜航器/武器/遗物/强化) ┐
             ┌ 图鉴(生物/武器/遗物) · 难度阶梯 · 成就 ┐
L1 局内      5 层 × 4 波 · 商店 · Build · 氧气 · 下潜决策
L0 核心      战斗 · 走位 · 自动开火 · 捡氧
```

| 要补的 | 解决 L0-L3 的哪一层 | 量级 |
|---|---|---|
| **元系统**（存档 v2 + 解锁 + 图鉴） | L2 | 中 |
| **海域关卡系统**（多下潜点 + 解锁链） | **L3（把 loop 变 line）** | 中大 |
| 难度阶梯 / 成就 | L2 | 小 |
| 音频 / 教程 | 支撑层 | 小-中 |

---

## 4. 顺序（建议）

1. **L2 元系统**（P0，见 V6.34 §5）—— 先让"死了也在推进"成立。
2. **L3 海域关卡**（P0.5）—— 再把"一局"升级成"一段旅程"。**这是"主线玩法"的正解。**
3. L2 补齐（难度阶梯 / 成就）+ 支撑层（音频）。
4. 机制内容（V6.34 §8 的 A 类 4 把武器 / 场地机制）。

> ⚠️ 顺序理由：L3 建在 L2 之上 —— 海域关卡需要一个"跨局成长"来承接；
> 先做 L2 再做 L3，L3 才有意义（否则通关一个海域后仍然"没留下什么"）。

---

## 5. 边界（不做）

| 不做 | 理由 |
|---|---|
| 母港 / 基地经营 | 开发量翻倍，稀释差异化（计划书 §11） |
| 局外氪金直加局内强度 | 招"换皮"差评 |
| 科技树 / 复杂养成 | 与"氧气四合一 · 少而深"冲突 |
| 联机 / 3D / 开放世界 | 计划书 §11 已排除 |
