# 生物形状规格 · 18 种（V6.83 · 交插画岗）

> 上游：`docs/生物谱系_20种_V6.82.md`（行为与数值）· `shared/dive/world.ts` 的 `ENEMY_BASE`
> 本轮问题（用户实机反馈）：**「立绘的几乎都是鱼类，六边形雷同性太多了」**
> 本文只解决**形状**一件事：行为与数值不在此列。

---

## 0. 问题定性（先说清"雷同"是怎么来的）

不是画得不够细，是**几何起点就是同一个**。当前 13 张占位图里，**7 张共用同一个模板**：

```
_spindle() = 一个 6 点多边形（左右两个尖的菱形近似）
```

`swarm / dash / splitter / shard / lancer / darter / spitter` 全都是它 —— 于是它们在
**36px 的实机尺寸下是同一个剪影**，只能靠颜色区分。而本作的读法**不是靠颜色**
（满屏 150 只时颜色分不出多少种），**只能靠剪影**。

> ★ 判据（本轮立的）：**把两张图缩到 36px、涂成纯黑，如果能互换 —— 就该重画。**

## 1. 形状族：只有 5 族，且必须来自"它的行为"

不要为"差异化"而差异化。**每种生物的轮廓应该解释它的行为** —— 玩家看一眼就知道该做什么。

| 族 | 轮廓语言 | 行为解释 | 本族成员 |
|---|---|---|---|
| **A 鱼形** | 纺锤 / 流线，**有明确的头** | "它会朝你游过来" | `swarm` `dash` `splitter` `darter` `lancer` |
| **B 盘形** | 圆形 / 扁盘，**没有头尾之分** | "它不追你，它是一个点" | `drift` `armor` `orbit` `jelly` |
| **C 巢形** | 圆鼓，**表面有孔/口** | "它会生出东西 / 会喷东西" | `brood` `bloom` `spitter` |
| **D 虫形** | 细长管状，**有环状分节** | "它会贴住你" | `leech` `burrower` |
| **E 碎屑** | **不规则、不对称** | "它不像活的" | `mimic` |
| **S Boss** | 大而复杂，**有明暗双区** | "它占屏幕的一角" | `watcher` `angler` |

**每条生物的控制点：族 必须是上表里的一个，且族内不许共用几何模板。**

## 3. 三对最容易撞的，必须显式拉开

| 对 | 撞在哪 | 怎么拉开 |
|---|---|---|
| `swarm` ↔ `splitter` ↔ `shard` | 都是小纺锤，只差一道缝/大小 | **`splitter` 的裂口要"断开"**（露出一条背景色的缝，而不是画一条深色线）；**`shard` 改成"碎片"** —— 不规则小三角，不是鱼 |
| `drift` ↔ `jelly` | 都是水母 | `drift` = **厚伞 + 短须（6 条以上）**，读作"一大团"；`jelly` = **薄伞 + 5 条长须 + 体表充能环**，读作"一盏灯" |
| `lancer` ↔ `darter` | 都细长 | `lancer` 的**吻要长到能单独被看见**（≥ 体长 1/3）；`darter` 的**尾鳍要大到能单独被看见**（≥ 体长 1/3）。一个"前面长"，一个"后面长" |

## 4. 通用规矩（出图必须遵守）

| 项 | 值 | 依据 |
|---|---|---|
| **朝向** | **一律头朝左**（0°） | 渲染层按"左 = 基准"做镜像（`drawEnemies` 的 `scale.x`），头朝右的图会**左右颠倒** |
| 画布 | **512 × (200 ~ 340)**，透明底 | 与现有 13 张一致 |
| 主体留白率 | 图形占画布 **60% ~ 80%**；四周留 **≥ 40px** 透明边 | 太小看不清细节，贴边会在九宫格/打包时被裁 |
| 描边 | **2px @512**（≈ 0.14px @36px）—— **别用粗描边** | 粗描边在 36px 下会吃掉整个形状 ⇒ 所有生物变成"黑块 + 白边" |
| 光源 | **左上**，与全项目一致 | 见 `MEMORY_ART.md` §光照 |
| 配色 | **按语义归族，⛔ 不新开槽**：`jade` 常见 · `magenta` 稀有/危险 · `steel` 甲壳 · `lime` 软体 | 见 `MEMORY_ART.md` §生物 |
| 输出 | 单主体、**不重叠**、**正交视角**、纯色白底 + 透明底双版本 | 纯色底版用于人眼检查，透明底版进引擎 |

---

## 5. 验收判据（**必须做，不是建议**）

1. **涂黑测试**：全部 19 张缩到 **36px**、涂成纯黑，**任意两张不能互换**。
2. **并排测试**：缩到 36px 排成一行（就是实机里鱼群的样子），**能一眼数出有几种**。
3. **6× 检查**：结构细节在 **6 倍放大**下检查（线条是否干净、孔洞是否通透）。
   ⚠️ 但**判据永远是 1×** —— 6× 好看的细节在 36px 下等于不存在。
4. 判据不过 = **重画**，不是"再调调"。

## 6. 优先级（按"能不能 36px 读出来"排）

| 优先 | 生物 | 为什么先改 |
|---|---|---|
| **P0** | `splitter` `shard` | 与 `swarm` 完全混在一起，而 `swarm` 是每局 172 只的最大群体 ⇒ 玩家会以为"只有一种鱼" |
| **P0** | `lancer` `darter` | 同上，且它们是"高速逼近"类，辨识度直接关系躲避判断 |
| **P1** | `jelly` `burrower` | 有专属行为（周期放电 / 下潜），但形状读不出"它和别的不一样" |
| P2 | 其余 13 张 | 形状已成立，只需**按 §4 的通用规矩精修**（描边 / 留白 / 光源统一） |
