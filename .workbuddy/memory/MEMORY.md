# 深海回响 · 项目长期记忆

> 归档跨会话必须遵守的规约。**日常进展看 `YYYY-MM-DD.md`，详细坑位看 `cocos/README.md` 已知坑表。**

## 项目结构（单一真源）

| 目录 | 角色 |
|---|---|
| `shared/` | ★ **引擎无关单一真源**（数值表 + 模拟核心 + 美术 key 表 + 档案逻辑）。改逻辑只改这里 |
| `shared/dive/artKeys.ts` | ★ "游戏需要哪些美术"的唯一说明（两个引擎 + 验证脚本共用） |
| `web/` | Phaser 3.90 + Vite + TS 原型（**可玩参考 + shared 配置层类型检查兜底**，非权威源） |
| `cocos/` | Cocos Creator 3.8.8 目标工程（分支 `cocos`） |
| `tools/sync_shared.py` | 真源 → Cocos 副本同步 + 漂移检查（`--check`） |
| `cocos/assets/scripts/shared/` | ⚠️ **自动生成的副本，不要手改** |

`shared/index.ts` 是 `export *` —— 加导出名前**必须先全目录搜同名**，撞名是编译期硬错 `TS2308`。

## 铁规

1. **移植以 `shared/dive` + `cocos` 为准，不凭记忆，也不以 `web/` 为准。** `web/` 是早期 Phaser
   原型（停在 V6.27、无 L2/炮塔/商店），只作**浏览器手感试纸**与 **shared 配置层类型检查兜底**
   （`cd web && npx tsc --noEmit` 退出 0 即 shared 配置合法）。新逻辑落 `shared/dive` 与 `cocos`，
   移植前读 **`cocos/assets/scripts/...` 与 `shared/dive/...` 的当前版本**。
   已踩：曾按旧版 web 多画了 V6.13 早删除的"空座 + 座圈连线"。
2. **顺序：先落文件、再写引用。** Cocos 增量编译**解析失败不登记依赖边**，
   新文件晚到 = importer 永久带着失败 import 躺缓存 = 编辑器全黑而验证全绿。
   判据在 `cocos/temp/.../resolution-detail-map.json` 的 `__unresolved_*`。
3. **验证是"静态可验"的下界，不是"画面对"的证明。** 全绿之后**必须**在 Creator 里
   跑 `Dive.scene` 目视确认。沙箱验不了引擎真实行为与观感。
4. **左右都要过**：改 `shared/` 后跑 `python tools/verify_cocos.py`（应 7/7）**和**
   `cd web && npx tsc --noEmit`（退出码 0）—— 真源是双端共用的。
5. **Cocos `Graphics` 没有 `translate/rotate/save/restore`。** 旋转零件一律手算坐标。
   配套：`Gfx.arc()`（分段折线，引擎 `arc` 在 y 翻转后方向镜像）、`Gfx.roundRect()`（内部翻 y）。
6. **椭圆：Phaser 收直径、Cocos 收半径。** 从 Phaser 实现抄任何 `*Ellipse(w,h)` 的值都要 `÷2`。
7. **"没报错 + 图也在" ≠ "画出来了"。** 层序（后建=上层）、`active` 开关是静默失效高发区。
   任何 `active=false` 的节点，重开点必须**每帧执行**或有明确的回开事件。
8. **UI 分层语义**：`scrim()`（半透明暗幕，弹窗用）≠ `pageFill()`（不透明铺满，页面用）。
   把弹窗底画成 `pageFill` 就是"全屏、太大"。
9. **换底色必须同时换文字色**（`TXT` ↔ `TXT_LIGHT`），只换底 = 白字白底。
10. **命名规范**：中文名目录加数字前缀（按字符编码排序是乱的）；归档改名说清关系，**归档≠删除**。

- 字号：**正文不低于 12px**（本机桌面应用既定下限）。

  对比靠**实底 + 硬边**，不靠发光。
  **谱系别再绕回去**：V6 近黑→「太暗」；V7 近白→「太亮」；V8 中调 ✅

## 立体感 / 体积的通用手法（矢量 UI 与游戏物件通用）

在 32px 这个量级，**可读的体积线索只有四条，缺一条就平**：
`⓪投影（右下偏移暗盘）→ ①侧壁（同形下移 + 变暗）→ ②受光弧（左上粗弧）→ ③暗弧（右下粗弧）`。
- **光源固定在世界坐标**，不能跟着被照物旋转（否则受光面会随物体转，"像贴纸在打折"）。
- 小尺寸先放大再谈明暗：直径 < 32px 的零件，加细节只是噪声。

## 立绘 / 文字 的三条硬规约（2026-10-13 新增）

1. **立绘框必须与素材画布同比例（2:1）**。素材管线 `tools/process_item_art.py` 规定立绘是
   2:1 画布、内容按 `FILL=0.86` 居中。框不是 2:1 ⇒ 立绘放不满 + 上下死空间（V8 的 176×148 就是这样）。
2. **`Hud.putArt` 必须用 `sf.originalSize` 定比例，不能用 `sf.rect`**。
   素材 meta 是 `trimType: auto` ⇒ `rect` 是**裁剪后**的（344×264），而引擎 `Sprite.trim=false`
   时按 **`originalSize`(600×300)** 定标 ⇒ 用 `rect` 会非等比拉伸（实测横向压掉 35%）。
3. **飘字必须「加粗 + 深色描边」**。深海背景 + 满屏火花/拖尾里，细体无描边数字会被背景同化 ——
   "字号小"往往只是表象，真因是没描边。描边宽随字号比例走（`max(2, round(size*0.16))`）。

## 字体（现状 = 没有字体资源）

- 项目**无任何 ttf/otf**，`Label` 走 `useSystemFont` 默认字体（`Title.ts:49` 有说明）。
- 所以"换字体"类需求目前**做不到**，只能做「加粗 / 描边 / 放大 / 字号阶梯」。
  要真换字体须先引入字体资源并统一 web 与 cocos 两端。

## 设计止损线（计划书 §10）—— 判定与守则

- **判据**：① 单波爽不爽 ② **氧气有没有"要不要去捡"的犹豫**。
- **2026-10-13 用户判定**：「**氧气现在让我犹豫去捡了**」→ ②**通过**。氧气的"犹豫"
  从设计意图变成体感事实 ⇒ 「要不要继续投内容」这个总开关**可打勾**。
- **为什么现在才犹豫（数就在 `tables.ts`）**：`o2Base=3.0`、拾取半径 `pickupR=31`、
  收支曲线 **全捡 1.28×→0.98×（净赚）/ 常规 6~7 成拾取 0.83×→0.64×（净亏）**。
  两条线之差 = 犹豫所在：**多捡那 3~4 成 → 从净亏翻到净赚**。半径只有 31px ⇒ 想捡必须真绕。
- ⛔ **收支曲线是 P0 止损线唯一要守的数，别凭手感改**（`tables.ts:305` 已写死此警告）。
  要调氧感，只动这三处：`BONE_O2.o2Base` / `O2.pickupR` / 掉落密度 —— **不动 `drain` 结构**。
- **区分"犹豫"的两种性质**（决定调哪边，别调反）：
  A 奖励型（值不值得绕，权衡风险回报）= **对的，要保**；
  B 价值型（回氧太少、不值一趟）= **要修氧收支**。
