## 铁规

1. **以 `shared/dive` + `cocos` 当前版本为准**（不凭记忆、不以 `web/` 为准）；**先落文件、再写引用**——Cocos

   执行**）② Graphics 层漏清 ③ 读一个从不被写的字段 ④ 事件回调里直接 `Graphics.fill*`（会被同帧 clear
   抹掉）⑤ ★ **两条规则都能收场 ⇒ 后写的那条永不执行**（V6.79b 缠索：距离 112px 在 0.42s 先触发，

3. Cocos `Graphics` **无 translate/rotate/save/restore** ⇒ 旋转零件手算坐标；**椭圆 Phaser 收直径、Cocos 收
