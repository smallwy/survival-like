## 项目结构（单一真源）

| 目录 | 角色 |
|---|---|
| `shared/` | ★ **引擎无关单一真源**（数值表 + 模拟核心 + 美术 key 表 + 档案逻辑）。改逻辑只改这里 |
| `shared/dive/artKeys.ts` | ★ "游戏需要哪些美术"的唯一说明（两个引擎 + 验证脚本共用） |
| `web/` | Phaser 3.90 + Vite + TS 原型（**可玩参考 + shared 配置层类型检查兜底**，非权威源）。**2026-10-13 晚冻结**，新功能直接写 cocos |
| `cocos/` | Cocos Creator 3.8.8 目标工程（分支 `cocos`） |
| `tools/sync_shared.py` | 真源 → Cocos 副本同步 + 漂移检查（`--check`） |
| `tools/sync_art.py` | **web → cocos** 美术同步（立绘/道具/环境背景）。⚠️ 环境背景真源在 `web/src/assets/env/L*.webp`，只改 cocos 会被下次同步覆盖 |
| `cocos/assets/scripts/shared/` | ⚠️ **自动生成的副本，不要手改** |

`shared/index.ts` 是 `export *` —— 加导出名前**必须先全目录搜同名**，撞名是编译期硬错 `TS2308`。

## 铁规

1. **移植以 `shared/dive` + `cocos` 为准，不凭记忆，也不以 `web/` 为准。** `web/` 是早期 Phaser
   原型（停在 V6.27、无 L2/炮塔/商店），只作**浏览器手感试纸**与 **shared 配置层类型检查兜底**
   （`cd web && npx tsc --noEmit` 退出 0 即 shared 配置合法）。新逻辑落 `shared/dive` 与 `cocos`，
   移植前读 **`cocos/assets/scripts/...` 与 `shared/dive/...` 的当前版本**。
   已踩：曾按旧版 web 多画了 V6.13 早删除的"空座 + 座圈连线"。
2. **顺序：先落文件、再写引用。** Cocos 增量编译**解析失败不登记依赖边**，
   新文件晚到 = importer 永久带着失败 import 躺缓存 = 编辑器全黑而验证全绿。
   判据在 `cocos/temp/.../resolution-detail-map.json` 的 `__unresolved_*`。
3. **验证是"静态可验"的下界，不是"画面对"的证明。** 全绿之后**必须**在 Creator 里
   跑 `Dive.scene` 目视确认。沙箱验不了引擎真实行为与观感。
4. **左右都要过**：改 `shared/` 后跑 `python tools/verify_cocos.py`（应 7/7）**和**
   `cd web && npx tsc --noEmit`（退出码 0）—— 真源是双端共用的。
5. **Cocos `Graphics` 没有 `translate/rotate/save/restore`。** 旋转零件一律手算坐标。
   配套：`Gfx.arc()`（分段折线，引擎 `arc` 在 y 翻转后方向镜像）、`Gfx.roundRect()`（内部翻 y）。
6. **椭圆：Phaser 收直径、Cocos 收半径。** 从 Phaser 实现抄任何 `*Ellipse(w,h)` 的值都要 `÷2`。
7. **"没报错 + 图也在" ≠ "画出来了"。** 层序（后建=上层）、`active` 开关是静默失效高发区。
   任何 `active=false` 的节点，重开点必须**每帧执行**或有明确的回开事件。
8. **UI 分层语义**：`scrim()`（半透明暗幕，弹窗用）≠ `pageFill()`（不透明铺满，页面用）。
   把弹窗底画成 `pageFill` 就是"全屏、太大"。
9. **换底色必须同时换文字色**（`TXT` ↔ `TXT_LIGHT`），只换底 = 白字白底。
10. **命名规范**：中文名目录加数字前缀（按字符编码排序是乱的）；归档改名说清关系，**归档≠删除**。

## 落地形态 = **B 混合**（2026-10-13 晚，已推翻 A 全矢量）

- 原因：用户要"商业化游戏美术级别"，而 `Graphics` 无渐变/无模糊/无笔触 = 硬天花板。
- ① 静态装饰层 → **png 切图**（面板底/按钮/图标/Logo/纹理）② 动态数值层 → **保持矢量**（氧气条填充/冷却环/飘字/脉冲）③ 布局层 → 代码。① ② 是两个渲染批次，互不干扰。
- **风格路线：深海霓虹 + 补质感** —— 题材配色不动（青蓝 `#4fe8ff` + 生物发光色系），只补粗描边/材质纹理/厚度阴影/装饰层。**不转向手绘卡通**。
- **概念图 ≠ 切图**：概念图只定风格锚点；切图必须**单独生成**（纯色底 + 单主体居中 + 正交视角 + 不重叠），否则 `process_item_art.py` 抠不了底。
- "要亮色"**只针对商店/弹窗**；战斗画面与 HUD 维持暗色。背景图/大立绘归插画角色。

## 水域光照与生态（V6.51 立，**推翻了「越深越黑」**）

- **原则 = 光的主权转移**：不是越深越黑，是**每带换一个光的主角**（L1 太阳 → L2 残光+探照灯 → L3 生物荧光 → L4 热泉自身 → L5 探照灯+呼吸点阵）。
  ⚠️ **L4 热泉带要比 L3 亮**（打破单调递减）。**提高对比度 ≠ 提高环境亮度** —— 均值可以低，必须有亮点。
- **env 图硬红线：每张 ≥6% 像素亮于 90**（现状 L3=1.2% / L5=0.4% 不合格）。量化脚本用 PIL 跑 `cocos/assets/resources/env/L*.png`。
- ⚠️ **新增光照层 `gAtmo` 必须插在 `gVeil` 与 `gBack` 之间**（层序 `gBase→bg→gBg→**gVeil→gAtmo→gBack**→fishLayer→gEnt→sub→gPlayer→gFront→hud`）。
  插 gVeil 之下 = 光被自己的压暗层吃掉；插 gBack 之上 = 盖住敌人。
- **能见度靠「雾」不靠「黑」**：雾取当前带 tint（同色），不是黑雾。**「亮的暗」vs「暗的暗」**。
- ⛔ **远景鱼群绝不给 2px 发光核心**（那核心是敌人的定位铁律）⇒ 无核心 + alpha ≤0.35 + ≤敌人 0.6× + 不可瞄准 + 不碰撞。
- **探照灯 = 双向暴露**（最大创新）：光让你看得见，也让你被看见（`attractR = LAMP_R × 2.2`）。v1 只做视觉，机制挂 P1。
- gAtmo 图元硬上限 **130/帧**（最坏 L5 ≈105 = +9.5%）；光柱/荧光/烟柱/点阵**按带互斥**。降级旋钮 `ATMO_QUALITY`（不许降鱼群与探照灯）。
- 规格：`docs/水域光照与生态规格_V6.51.md`（修订 V6.50 §9 落地顺序）。

⇒ **改视角必须连模拟层投影一起改**，只在渲染层做 = 子弹从炮口旁边飞出来。

预览脚本 `tools/preview_hull_side.py` **复刻了同一组常量，改 TS 必须同步改它**。

## 通用手法（矢量 UI 与游戏物件通用）

- **32px 量级可读的体积线索只有四条，缺一条就平**：`⓪投影（右下偏移暗盘）→ ①侧壁（同形下移+变暗）→ ②受光弧（左上粗弧）→ ③暗弧（右下粗弧）`。**光源固定在世界坐标**，不跟被照物旋转。直径 < 32px 的零件加细节只是噪声。
- **立绘/文字三条硬规约**：① 立绘框必须与素材画布同比例（**2:1**，`FILL=0.86` 居中）② `Hud.putArt` 必须用 `sf.originalSize` 定比例，**不能**用 `sf.rect`（trimType:auto 下 rect 是裁剪后的 344×264，而引擎按 originalSize 600×300 定标 ⇒ 非等比拉伸）③ 飘字必须「加粗 + 深色描边」（`max(2, round(size*0.16))`）—— 「字号小」常是表象，真因是没描边。
- ⚠️ **全线禁用 ADD 混合**（Graphics 不支持；Canvas 下画成实心白块）。特效叠加走**普通 alpha**（贴图 alpha 已按亮度导出）。别看到"适合 ADD"就开混合。
- ⚠️ **池化常驻精灵**（鱼池/特效池）退回标题屏必须**显式关**（`hideWorld`+`clearFx`）—— Graphics 层会 clear，池化 Sprite 不会自动清。
- `Title.root` 锚点 (0,0) 在**左下角** ⇒ 屏幕中心是本地 `(W/2, H/2)`。

## 字体（现状 = 没有任何字体资源）

- 项目**无任何 ttf/otf**，`Label` 走 `useSystemFont` 默认字体。所以"换字体"**做不到**，只能做「加粗/描边/放大/字号阶梯」。真换字体须先引入资源并统一双端。

## 设计止损线（计划书 §10）

- **判据**：① 单波爽不爽 ② **氧气有没有"要不要去捡"的犹豫**。**② 2026-10-13 通过**（「氧气现在让我犹豫去捡了」）；**① 2026-10-14 判定 = 未通过**。
- ⚠️ **① 的不通过理由是「体感」不是「数值」**：缺下潜纵深感 / 网雷是软控+被动 / 敌人雷同 / 无收益惊喜。
  ⇒ **骨架不用推翻，要改的是反馈通道**。方案见 `docs/战斗体感四改方案_V6.49.md`。
  关键杠杆：`depthM` **已有且每波在涨**，只是 `tint`/`vis`/`motes` 是 per-layer 常量 ⇒ 改成深度曲线即可。
- 机制在 `tables.ts`：`o2Base=3.0`、`pickupR=31`；收支曲线 **全捡 1.28×→0.98×（净赚）/ 常规 6~7 成拾取 0.83×→0.64×（净亏）**。两条线之差 = 犹豫所在。
- ⛔ **收支曲线是 P0 唯一要守的数，别凭手感改**。调氧感只动三处：`BONE_O2.o2Base` / `O2.pickupR` / 掉落密度 —— **不动 `drain` 结构**。
- **"犹豫"分两种**：A 奖励型（值不值得绕）= 对的要保；B 价值型（回氧太少）= 要修氧收支。

- 图标**只出图形本体，不含槽位底**。**沉淀货币（菱形）留矢量**（静态切图/动态矢量分工的边界示例）。
- ⚠️ **出图硬约束（必须独立成段，混在负面词里会被忽略）**：① **禁止任何底衬**（方/圆底板/卡片底）② **禁止任何文字** ③ 多图标同图**必须写明"各图标外接圆直径相等"**。
- 流程：**3 图标同图打样 → 确认 → 批量**；不合格**改锚点，不是重出单个**。
- **语义深海化已入库**：图鉴=磨砂金属标本罐 / 里程碑=半圆深度计 / 装置坞=压力舱门 / 海域=海图卷轴 / 设置=阀门手轮 / 帮助=探照灯。文件名不变 ⇒ 代码零改动。
  - ⚠️ 写"深海**仪器/仪表**"会把模型带成**线稿示意图**（退成扁平线稿 = 镂空）。修法：把"实心"写成不可绕过的动词「先铺一个填满颜色的实心主体，再做厚度与明暗，任何区域不许只剩轮廓线」＋「像沉甸甸的实心金属铸件」。
