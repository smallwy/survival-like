## 铁规

1. 以 `shared/dive`+`cocos` 当前版本为准；**先落文件再写引用**（解析失败不登记依赖边 ⇒ 编辑器全黑而验证全绿）。改 `shared/` 后 `verify_cocos.py`(7/7) **和** `cd web && npx tsc --noEmit` 都要过；全绿后仍须目视 `Dive.scene`。
2. **"没报错 + 图也在"不等于"画出来了"**。静默失效五类：层序 / `active`（每帧执行）· Graphics 漏清 · 读从不被写的字段 · 回调里直接 `fill*` · 两条规则都能收场 ⇒ 后写的永不执行（阈值/时长成对出现必须回代算谁先命中）。画面没变先查尺寸 / 可见性 / 层序 / 透明度。
3. Cocos `Graphics` 无 translate/rotate/save/restore ⇒ 旋转零件手算坐标；椭圆 Phaser 收直径、Cocos 收半径；禁 ADD 混合、禁径向渐变；镜像翻转旋转方向（`-flip*tilt*180/π`）；侧视"朝向"不等于"速度"；`Gfx` 世界 y=`H-simY` ⇒ 裸 Sprite 自己翻 y。
4. crossfade = 旧图在上淡出（`beginXfade()` 在 `syncBg()` 前）；`hideWorld` 显式关 `bgOld`/池化精灵；速度类每帧现算；回绕双向；`SCROLL_BASE` 恒正，消费者一律 `y -= scrollV*…`（`+=` = 上浮且不报错）；`drawBg`/`drawAtmo` 各记带号。
5. 按行号连做多次删除**从后往前**；加法只做在语义成立的那一个变体上（霰弹喇叭口画进所有枪族 ⇒ 读成"X"）。
6. 比例只有一个口径 `originalSize`（`sf.rect` 是裁剪后的）；位图 `.meta` 必须 `trimType:"none"`（`auto` ⇒ 整体偏移 ⇒ 挂点错位且不报错）；换底色同时换文字色。
7. Read 剥首行缩进 ⇒ Edit 首行常失败（用 Python `assert o in s` 替换）；函数签名不要猜（看 `git show HEAD:<file>` 与调用点）；写文件禁直写 ⇒ 临时文件 + `os.replace`；恢复源 `~/.workbuddy/file-history/`。
