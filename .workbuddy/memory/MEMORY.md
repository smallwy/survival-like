## 铁规

1. **移植以 `shared/dive` + `cocos` 为准，不凭记忆、也不以 `web/` 为准**，移植前读**当前版本**的文件。
   `web/` 只作手感试纸与类型检查兜底（`cd web && npx tsc --noEmit` 退出 0）。
   已踩：按旧版 web 多画了 V6.13 早删除的"空座 + 座圈连线"。
2. **顺序：先落文件、再写引用。** Cocos 增量编译**解析失败不登记依赖边**，新文件晚到 ⇒ importer 永久带
   失败 import 躺缓存 = 编辑器全黑而验证全绿。判据：`cocos/temp/.../resolution-detail-map.json` 的 `__unresolved_*`。
3. **验证是"静态可验"的下界，不是"画面对"的证明。** 全绿之后**必须**在 Creator 里跑 `Dive.scene` 目视。
4. **左右都要过**：改 `shared/` 后跑 `python tools/verify_cocos.py`（应 7/7）**和** `cd web && npx tsc --noEmit`（退出 0）。
5. **Cocos `Graphics` 没有 `translate/rotate/save/restore`**，旋转零件一律手算坐标。配套 `Gfx.arc()`
   （分段折线，引擎 `arc` 在 y 翻转后方向镜像）、`Gfx.roundRect()`（内部翻 y）。
6. **椭圆：Phaser 收直径、Cocos 收半径** ⇒ 从 Phaser 抄 `*Ellipse(w,h)` 要 `÷2`。
7. **"没报错 + 图也在" ≠ "画出来了"。** 静默失效三类：① **层序 / `active`** —— `active=false` 的节点
   重开点必须**每帧执行**；② **Graphics 层漏清** —— 新增任何层**第一件事**是加进 `update()` 的每帧 clear
   名单（漏了只是每帧叠成拖影：V6.55 全屏白横带 = `gAtmo` 漏这行）；③ **读一个从不被写的字段** ——
   用前**先 grep 谁写它**。
8. **UI 分层语义**：`scrim()`（半透明暗幕，弹窗）≠ `pageFill()`（不透明铺满，页面）。混用 = "全屏、太大"。
9. **换底色必须同时换文字色**（`TXT` ↔ `TXT_LIGHT`），只换底 = 白字白底。
10. **命名规范**：中文名目录加数字前缀（编码排序是乱的）；归档改名说清关系，**归档≠删除**。
11. **素材比例只有一个口径：`originalSize`。** `sf.rect` 是**裁剪后**的（meta 默认 `trimType:auto`），而
    `trim=false` 的 Sprite 按 `originalSize` 铺顶点 ⇒ 混用 = 分子分母来自两张不同尺寸的图（透明边多的
    `dash.png` 被拉成方块）。`Hud.putArt` 与 `art.frameAspect` **各踩过一次**。
12. **镜像会翻转旋转方向。** 节点变换是 **T·R·S** ⇒ `scale.x=-1` 时同一个 `angle` 的视觉转向相反。
    基准：`Gfx.ang(a) = -a`、**sim 的 y 向下**、**`node.angle` 正值 = 视觉逆时针**。敌人贴图倾角必须写
    `(-flip * tilt * 180/π)`，漏 `flip` = "朝右游的鱼往下扎"。
13. **侧视下"朝向"和"速度"是两回事。** `Enemy.fx/fy` 存**朝向单位向量**（`updateEnemies` 每帧写，
    dash 覆盖成 `dirX/dirY`），**不要**用位移差或 `vx/vy` 反推。
14. **crossfade 用「旧图在上淡出」**（`bgOld` 压 `bg` 之上 255→0；新图在下**恒满不透明**）。
    合成 = `旧×a + 新×(1-a)`；两层各半透会先暗一档再亮回来（双重曝光）。⚠️ `beginXfade()` 必须在
    **同帧 `syncBg()` 之前**调 —— 挪后 = 拷到新图 = **没有过渡**且不报错。`bgOld` 是**持久 Sprite**，
    `hideWorld` 必须显式关。
15. **速度类表现不逐条存**：颗粒速度 = `MOTE_MUL[带] × scrollV` **每帧现算**，不留 `vy` 字段
    （逐条存 ⇒ 换带时屏幕上已有的那批还按老速度走 = "整片水没一起动"）。**同类量一律现算。**
    配套：回绕必须**双向**（反向颗粒只判 `y<0` 会在屏幕一侧堆成静止亮带）。

## 落地形态 = **B 混合**（2026-10-13 晚，已推翻 A 全矢量）

- 原因：要"商业化游戏美术级别"，而 `Graphics` 无渐变/无模糊/无笔触 = 硬天花板。
- ① 静态装饰层 → **png 切图**（面板底/按钮/图标/Logo/纹理）② 动态数值层 → **保持矢量**（氧气条/冷却环/
  飘字/脉冲）③ 布局层 → 代码。①② 是两个渲染批次，互不干扰。
- **风格路线：深海霓虹 + 补质感** —— 题材配色不动（青蓝 `#4fe8ff` + 生物发光色系），只补粗描边/材质纹理/
  厚度阴影/装饰层。**不转向手绘卡通**。
- **概念图 ≠ 切图**：概念图只定风格锚点；切图必须**单独生成**（纯色底 + 单主体居中 + 正交视角 + 不重叠）。
- "要亮色"**只针对商店/弹窗**；战斗画面与 HUD 维持暗色。背景图/大立绘归插画岗。

## 通用手法（矢量绘制 / UI / 工程）

- **32px 量级可读的体积线索只有四条，缺一条就平**：`⓪投影（右下偏移暗盘）→ ①侧壁（同形下移+变暗）→
  ②受光弧（左上粗弧）→ ③暗弧（右下粗弧）`。**光源固定在世界坐标**，不跟被照物旋转。
  直径 < 32px 的零件加细节只是噪声。
- **56px 量级的金属质感只来自一条集中的镜面亮痕**（V6.57 机体）。⛔ **三个已否掉的方案别再走回头路**：
  贯穿全艇的**竖板缝**（⇒ 铁笼；收细/改暗/跨 62% 后**仍是栅栏**）、舷窗**暗色窗框**（⇒ 一排黑洞）、
  **低频明暗斑**（⇒ 锈渍）。⇒ **窗只做加法：只加光，不加暗**；结构线在 56px 上只可能读作"船被切开"。
- **养成线是纯数值**（`unlocks.ts`/`pool.ts`/`subs.ts`，只改 `o2Bonus/rate/pickup/regen/armor/dodge/luck/`
  `o2Max/hp`）⇒ **外观零变化**。别再去养成表里找外观项。
- **立绘/文字三条硬规约**：① 立绘框与素材画布同比（**2:1**，`FILL=0.86` 居中）② `Hud.putArt` 用
  `sf.originalSize` 定比例，**不能**用 `sf.rect` ③ 飘字必须「加粗 + 深色描边」（`max(2, round(size*0.16))`）
  —— 「字号小」常是表象，真因是没描边。
- ⚠️ **全线禁用 ADD 混合**（Graphics 不支持；Canvas 下画成实心白块）。特效叠加走**普通 alpha**。
- ⚠️ **池化常驻精灵**（鱼池/特效池）退回标题屏必须**显式关**（`hideWorld` + `clearFx`）。
- `Title.root` 锚点 (0,0) 在**左下角** ⇒ 屏幕中心是本地 `(W/2, H/2)`。
- **矢量绘制的两条几何坑**：① **同心圆两种读法不能混** —— 要**空心**（能见度雾）用**环带**（`line()` 粗描边 +
  `strokeCircle()`，每像素只覆盖一次）；要**实心**（探照灯/光晕）用**同 α 由外向内叠**（`fillCircle()`，
  覆盖次数 = 亮度）。抄错 ⇒ 靶环 / 空靶。⛔ 一律禁用径向渐变。② **硬边来自"半径突变的层"，不来自
  alpha**（V6.60 探照灯）：修法是**换半径分布**（`r_i = R(1−i/n)^1.35`，内层更密 ⇒ 中心覆盖次数快升 ⇒
  自然亮斑）。**⛔ 内层分档 alpha = 靶环**，但**最外 2–3 层走淡入梯度不是靶环**（0→1 次覆盖的跳变会在圆边界
  留可见圆周线）。"用不用分档"看**在圆的哪一段**。
- **预览脚本要按"看得见的量"配，不按"函数"配**：`preview_atmo.py`（复刻 drawBg→drawVeil→drawAtmo 的
  **合成结果**）、`preview_hull_side.py`、`preview_dive_cycle.py`、`preview_lights.py`。
  "每个参数都合法、合起来却错"那类问题（V6.55 "背景飘白云"），**只有合成图能提前发现**。
- ⚠️ **速度类常量的符号**：`SCROLL_BASE` 恒为**正数**，消费者**一律 `y -= scrollV × …`** —— sim 的 y 向下，
  只有"减小"才是**向上掠过**（= 下潜感）。写成 `+=` 得到"上浮"，与下潜完全相反，**且不报错**。
  改这类公式时**先去 git 读改动前的原式**。
- ⚠️ **同一帧里两次独立绘制的层，各自记一个"构过的带号"**：`drawBg`（颗粒）与 `drawAtmo`（鱼群/光）
  分开调用、共用一个 `layer` 字段 ⇒ 先跑的改掉带号、后跑的以为建过了 ⇒ **半新半旧**。
- ⚠️ **按行号连做多次删除，必须从后往前**（V6.65 踩）：先删前面区间再用旧行号删后面 ⇒ 删错位置，且编译期
  报的错（`TS1128`）离真因很远。**先把区间收集完，再按 `start` 降序应用。** 配套：判"方法结束"要用
  **花括号计数**，⛔ 不能用"找第一个 `strip() == '}'` 的行"（会停在 for/if 的收尾花括号上）。

## 环境背景图（env）与光照

- ★★ **判"某效果该用矢量还是位图"的唯一判据**（V6.65 立，三轮返工换来）：**不看它"物理上多对"，
  看它"承不承认边缘是模糊的"**。· **承认**（体积光/软阴影/光晕/烟/焦散/任何"软过渡"）⇒ **必须位图或
  着色器** —— `Graphics` 是硬边填充，没有渐变/模糊/软笔触，中间算得再物理，出来也只是「硬边色块」。
  · **不承认**（几何零件/UI 框/硬边提示）⇒ 矢量反而更准。
- ⛔ **丁达尔光柱已从渲染层整体移除**（V6.65）。V6.60→V6.61→V6.64 三轮做的全是"物理化"（透视消失点/
  Beer–Lambert/分波长吸收/散射扩散/乘性起伏包络），**三轮失败根因同一个**（上一条）⇒ **光的表现下放到
  env 位图**。已删 `interface Beam` + `BEAM_*` 常量 + **6 个方法** + 颗粒的「被光柱照亮」；保留
  `ATMO_QUALITY` 与按带互斥预算（`case 0/1` 空分支），原常量位置留**墓志铭**防加回。
- ★★ **判据要匹配"光是怎么分布的"**（V6.66，修正 V6.58 的一刀切）：
  · **面光源**（天光 L1/L2）⇒ 判**全画面亮部占比**（L1 ≥40% / L2 ≥12%）；
  · **局部/点光源**（荧光 L3 / 热泉 L4）⇒ 判 **峰值 + 面积双条件**（`p99 ≥130` **且** 亮部占比 ≥1.5%）。
    ⚠️ V6.68 修正：原写 `p98 ≥110` 把 L3 **误判 FAIL** —— 分散的荧光亮小点会让 p98 被"半亮的荧光线"拉低，
    **面积大但峰值低**被读成"没有亮区"。缺任一条件都不行（否则"一个亮斑"或"一片灰亮"都能骗过单一判据）；
  · **稀疏微光**（深渊雪 L5）⇒ 判**对比与结构**（p50 ≤42 且 p99 ≥55）。
  ⛔ V6.58 的「每张 ≥6% 像素亮于 90」一刀切到五带是**错的** —— 强行提亮暗带的后果是**水体变灰绿浑水、
  暗岩壁被照亮出噪点 ⇒ "午夜带"变成"浑浊白天"，段感全丢**。
- **env 图必须做曝光补偿**（**是工序不是调色**）：渲染层 `drawVeil` **吃掉一半亮度** ⇒ env 要按"被压暗
  之后"配曝光。`tools/brighten_env.py`：`out = 255·(x)^(1/g)` **逐通道**（单调 ⇒ 色相不变；白点保 255 ⇒
  荧光/热泉亮芯不过曝）。实值：L2 `0.80`（压暗）/ L3 `1.62` / L4 `1.40` / L5 `1.35` / V6.68 的 L4 `1.22`·`1.18`。
- ⚠️ **「上下无缝」只对无地形带成立**（V6.68 修正）：判据（首行/末行差 ≤14）是为**纵向滚动**服务的；
  但**有海床的带顶部是水、底部是床，首末行本来就不同色 —— 那是内容不是缺陷** ⇒ `check_art.py` 加
  `SEAM_SKIP={'L3','L4'}`。整图纵向滚动也已改**视差**（背景不动），真要接缝该看**横向**能否平铺。
- ⚠️ **别把"定性判据"写成"精确判据"**（V6.68 第二次踩，此前 `FISH_CX` 已踩过）：阈值一律留 **±2 噪声
  余量**。判据写错比参数调错更贵 —— 它会让你去改**本来是对的**东西。
- **模型出图必带角标水印**：提示词写"无水印"**压不住**后处理角标 ⇒ 「出图 → 本地修水印」是**固定工序**。
  已固化成 `tools/prep_shot.py`（去水印 → webp → 实机 cover 预览 → 打印验收数字）；未修原图留 `*_raw.png`。

### 背景图构图判据（★ 两层，出图前先过）

- **层一：背景图是"擂台"，不是风景照**（V6.67 立）：
  · **中部必须是低对比的空水** —— 那是玩家横向移动、敌人成群飞过、子弹乱窜的地方。⛔ 中部**不许**有强对比
    结构 / 垂直的边 / 密集高频细节。**中段出现一条竖直高对比边 = 废图**（玩家会以为那里有墙）。
  · **地形只放上下边缘或远景**：上 = 水面/岩顶；下 = 海床/礁石/喷口（**地平线压在下 1/3**）；远景 = 一线
    模糊地形。⛔ **两侧不留地形**（左右边缘是玩家的活动边界 = 视觉上筑墙）。
  · **要有纵深分层**（两三层由远及近的鱼群剪影），但⛔ 背景鱼**必须比渲染层动态鱼更小/更淡/更少**。
  · 亮度按「**开阔 > 封闭**」配。⚠️ **"开阔"与"亮"天生矛盾** —— 构图一打开水面积就变大，而水是暗的
    （V6.67 实测：L3 重出后均值 40→24.5）⇒ 亮度**必须靠曝光补偿补回来**，别指望模型。
    顺序永远是「**先定亮度目标 → 再重出 → 再补偿**」。
- **层二：这地方鱼会来吗**（V6.68 立，用户「这种场景还有鱼敢来吗」）。**先问"鱼会不会来"，再问"好不好看"**
  —— 玩家要在这一带打鱼，背景必须先回答鱼为什么要来。三问：① **有食物吗**（热泉：化能合成细菌→管虫→
  虾蟹→鱼）② **温度对生物是危险还是舒适**（喷口极热，但生物活在**烟羽外围的 2°C 冷水**里）
  ③ **画面里有生物吗** —— ★ **这条最直接**：有生物本身就是"这地方能住"，不用跟玩家解释生态。
  ⛔ **"发光"是极强的负向符号**（火 = 危险 + 高温 + 无生命），一次否掉①②③。
- ⛔ **热泉不发光，是矿物**（V6.68，我提示词写错过一次）：真实海底热泉喷的是**热水 + 矿物微粒**，在 2°C
  深海瞬间冷却 ⇒ **浑浊烟羽**（黑烟囱 = 黑色硫化物 / 白烟囱 = 乳白碳酸盐）。照片里的"橙红"是 **ROV 探照灯 +
  岩面铁氧化物沉积**，**不是自发光**。⇒ **只要画面出现"橙红自发光"，玩家只有一个读法：火/岩浆**。
  "热"要靠**间接线索**：岩面一小片不发光锈橙沉积 + 烟羽向上翻涌的形态 + 成排管虫丛。

### 光照层与生态（V6.51 立，**推翻了「越深越黑」**）

- **原则 = 光的主权转移**：不是越深越黑，是**每带换一个光的主角**（L1 太阳 → L2 残光+探照灯 → L3 生物荧光
  → L4 热泉 → L5 探照灯+呼吸点阵）。⚠️ **L4 要比 L3 亮**（打破单调递减）。**提高对比度 ≠ 提高环境亮度**
  —— 均值可以低，必须有亮点。
- **层序**：`gBase→bg→**bgOld**→gBg→**gVeil→gAtmo→gBack**→fishLayer→gEnt→sub→gPlayer→gFront→hud`。
  ⚠️ 新增光照层 `gAtmo` 必须插在 `gVeil` 与 `gBack` 之间 —— 插 gVeil 之下 = 光被自己的压暗层吃掉；
  插 gBack 之上 = 盖住敌人。
- **能见度靠「雾」不靠「黑」**：雾取当前带 tint（同色），不是黑雾。**「亮的暗」vs「暗的暗」**。
- **远景生态（`gAtmo`）**：① 体色按"**比水体偏一点点**"配 —— 浅水取**暗剪影**、深水取**微亮轮廓**、只有
  荧光带给亮色；全给暗会在暗水里**直接消失**。② 鱼群**必须成团**（团心留边距 + 三角分布 + **同团同向同速**）
  —— `x/y` 各自独立随机 = 均匀点阵 = "雪花/星星"。③ ⛔ **远景鱼群绝不给 2px 发光核心**（那核心是敌人的
  定位铁律）⇒ 无核心 + alpha ≤0.35 + ≤敌人 0.6× + 不可瞄准 + 不碰撞。
- **探照灯 = 双向暴露**（最大创新）：光让你看得见，也让你被看见（`attractR = LAMP_R × 2.2`）。v1 只做视觉。
- gAtmo 图元硬上限 **130/帧**（最坏 L5 ≈105）；荧光/烟柱/点阵**按带互斥**。降级旋钮 `ATMO_QUALITY`。
- **带间过渡必须连续，但⛔ 不是全程线性**（`layerBlend`）：`tint`/`vis`/雾半径按 `depthM` 插值，**前 70%
  保持本色、后 30% 才过渡**（`BLEND_FROM = 0.70`）。⚠️ `fogR₀ = 0` 的带（L1 刻意无雾）**不参与插值**。
- ⚠️ **别拿"能见度/亮度"这类表现参数当"是不是深层"的判据**（`vis < 0.5` 判 `darkLayer`）：一改 `vis` 就会把
  深层敌人的可读性兜底**悄悄关掉**。深层是**设计事实**，直接写 `layerIdx`。
- 规格：`docs/水域光照与生态规格_V6.51.md`、`docs/资源重出规格_V6.58.md`；
  闸门 `tools/check_art.py env|fish|items|all`（只读，退出码 0/1）。

### 远景鱼形（V6.64）

## 设计止损线（计划书 §10）

- **判据**：① 单波爽不爽 ② **氧气有没有"要不要去捡"的犹豫**。**② 2026-10-13 通过**；**① 2026-10-14 判定 =
  未通过**。⚠️ **① 的不通过理由是「体感」不是「数值」**：缺下潜纵深感 / 网雷是软控+被动 / 敌人雷同 /
  无收益惊喜 ⇒ **骨架不用推翻，要改的是反馈通道**（`docs/战斗体感四改方案_V6.49.md`）。关键杠杆：`depthM`
  **已有且每波在涨**，只是 `tint`/`vis`/`motes` 是 per-layer 常量 ⇒ 改成深度曲线。
- 机制在 `tables.ts`：`o2Base=3.0`、`pickupR=31`；收支曲线 **全捡 1.28×→0.98×（净赚）/ 常规 6~7 成拾取
  0.83×→0.64×（净亏）**，两条线之差 = 犹豫所在。⛔ **收支曲线是 P0 唯一要守的数，别凭手感改**。
  调氧感只动三处：`BONE_O2.o2Base` / `O2.pickupR` / 掉落密度 —— **不动 `drain` 结构**。
- **"犹豫"分两种**：A 奖励型（值不值得绕）= 对的要保；B 价值型（回氧太少）= 要修氧收支。

## 图标 · 框架元件 · 仓库（细节看对应 docs）

- **图标**：png **512×512**、**高亮冷白单色 + 四档明暗**（受光 100/中间 74/暗面 48/描边投影 24），运行时
  `sprite.color` **乘色**出四态 ⇒ **每图标 1 张**（不是每态 1 张）。⚠️ 乘色**只能压暗** ⇒ 基底明度须 ≥90%；

  不含槽位底；沉淀货币（菱形）留矢量。
