## 项目结构（单一真源）

| 目录 | 角色 |
|---|---|
| `shared/` | ★ **引擎无关单一真源**（数值/模拟核心/美术 key 表/档案逻辑）。改逻辑只改这里 |
| `shared/dive/artKeys.ts` | ★ "游戏需要哪些美术"的唯一说明（双引擎 + 验证脚本共用） |
| `web/` | Phaser 3.90 + Vite 原型。**2026-10-13 晚冻结**：新功能直接写 cocos；仅「已有逻辑搬运」仍以 web 为准 |

| `tools/sync_shared.py` | 真源 → Cocos 副本同步 + 漂移检查（`--check`） |

`shared/index.ts` 是 `export *` —— 加导出名前**必须先全目录搜同名**，撞名是编译期硬错 `TS2308`。

## 铁规

1. **搬运已有逻辑以 `web/` 当前版本为准，不凭记忆**（背景：曾按旧版 web 多画了 V6.13 已删的"空座+座圈连线"）。web 冻结后此条只适用于搬运，新增功能直接写 cocos。
2. **顺序：先落文件、再写引用。** Cocos 增量编译解析失败不登记依赖边 ⇒ 新文件晚到 = importer 永久带失败 import = 编辑器全黑而验证全绿。判据在 `cocos/temp/.../resolution-detail-map.json` 的 `__unresolved_*`。
3. **验证只是"静态可验"的下界。** 全绿之后**必须**在 Creator 里跑 `Dive.scene` 目视确认。
4. **改 `shared/` 后跑 `python tools/verify_cocos.py`（应 7/7）** —— 主门槛。`cd web && npx tsc --noEmit` 不阻塞放行，但顺手别让 web 烂掉。
5. **Cocos `Graphics` 无 `translate/rotate/save/restore`**，旋转零件一律手算坐标。配套 `Gfx.arc()`（分段折线，引擎 `arc` 在 y 翻转后方向镜像）、`Gfx.roundRect()`（内部翻 y）。
6. **椭圆：Phaser 收直径、Cocos 收半径。** 从 `web/src/` 抄 `*Ellipse(w,h)` 一律 `÷2`。
7. **"没报错 + 图也在" ≠ "画出来了"。** 层序（后建=上层）、`active` 开关是静默失效高发区；任何 `active=false` 的节点重开点必须**每帧执行**或有明确回开事件。
8. **UI 分层语义**：`scrim()`（半透明暗幕，弹窗）≠ `pageFill()`（不透明铺满，页面）。弹窗底画成 `pageFill` = "全屏、太大"。
9. **换底色必须同时换文字色**（`TXT` ↔ `TXT_LIGHT`）。
10. **命名**：中文名目录加数字前缀（字符编码排序是乱的）；归档改名说清关系，**归档≠删除**。

## 落地形态 = **B 混合**（2026-10-13 晚，已推翻 A 全矢量）

- 原因：用户要"商业化游戏美术级别"，而 `Graphics` 无渐变/无模糊/无笔触 = 硬天花板。
- ① 静态装饰层 → **png 切图**（面板底/按钮/图标/Logo/纹理）② 动态数值层 → **保持矢量**（氧气条填充/冷却环/飘字/脉冲）③ 布局层 → 代码。① ② 是两个渲染批次，互不干扰。
- **风格路线：深海霓虹 + 补质感** —— 题材配色不动（青蓝 `#4fe8ff` + 生物发光色系），只补粗描边/材质纹理/厚度阴影/装饰层。**不转向手绘卡通**。
- **概念图 ≠ 切图**：概念图只定风格锚点；切图必须**单独生成**（纯色底 + 单主体居中 + 正交视角 + 不重叠），否则 `process_item_art.py` 抠不了底。
- "要亮色"**只针对商店/弹窗**；战斗画面与 HUD 维持暗色。背景图/大立绘归插画角色。

## 皮肤（`shared/theme.ts`）

- `MENU`（暗，菜单/战斗 HUD）：`page < slot < card`，凹槽比卡面**亮**。⛔ 别借 `MENU.slot` 到深海整图上（= 贴黑板）。
- `BRIGHT`（**中调 V8**，商店/弹窗）：`surface(0x3d6b80) > card(0x4a7c91) > slot(0x2b4f61)`，凹槽比卡面**暗**。**谱系别再绕**：V6 近黑「太暗」→ V7 近白「太亮」→ V8 中调 ✅。
- `GLASS`（**只给主界面**）：深青玻璃槽。与黑板的界分 = **顶部受光高光带**（`GLASS.hi`，24 条色带模拟渐隐；锁定态不画高光）。

## 通用手法（矢量 UI 与游戏物件通用）

- **32px 量级可读的体积线索只有四条，缺一条就平**：`⓪投影（右下偏移暗盘）→ ①侧壁（同形下移+变暗）→ ②受光弧（左上粗弧）→ ③暗弧（右下粗弧）`。**光源固定在世界坐标**，不跟被照物旋转。直径 < 32px 的零件加细节只是噪声。
- **立绘/文字三条硬规约**：① 立绘框必须与素材画布同比例（**2:1**，`FILL=0.86` 居中）② `Hud.putArt` 必须用 `sf.originalSize` 定比例，**不能**用 `sf.rect`（trimType:auto 下 rect 是裁剪后的 344×264，而引擎按 originalSize 600×300 定标 ⇒ 非等比拉伸）③ 飘字必须「加粗 + 深色描边」（`max(2, round(size*0.16))`）—— 「字号小」常是表象，真因是没描边。
- ⚠️ **全线禁用 ADD 混合**（Graphics 不支持；Canvas 下画成实心白块）。特效叠加走**普通 alpha**（贴图 alpha 已按亮度导出）。别看到"适合 ADD"就开混合。
- ⚠️ **池化常驻精灵**（鱼池/特效池）退回标题屏必须**显式关**（`hideWorld`+`clearFx`）—— Graphics 层会 clear，池化 Sprite 不会自动清。
- `Title.root` 锚点 (0,0) 在**左下角** ⇒ 屏幕中心是本地 `(W/2, H/2)`。

## 字体（现状 = 没有任何字体资源）

- 项目**无任何 ttf/otf**，`Label` 走 `useSystemFont` 默认字体。所以"换字体"**做不到**，只能做「加粗/描边/放大/字号阶梯」。真换字体须先引入资源并统一双端。

## 设计止损线（计划书 §10）

- **判据**：① 单波爽不爽 ② **氧气有没有"要不要去捡"的犹豫**。**2026-10-13 用户判定「氧气现在让我犹豫去捡了」→ ②通过** ⇒ 「要不要继续投内容」总开关可打勾。
- 机制在 `tables.ts`：`o2Base=3.0`、`pickupR=31`；收支曲线 **全捡 1.28×→0.98×（净赚）/ 常规 6~7 成拾取 0.83×→0.64×（净亏）**。两条线之差 = 犹豫所在。
- ⛔ **收支曲线是 P0 唯一要守的数，别凭手感改**。调氧感只动三处：`BONE_O2.o2Base` / `O2.pickupR` / 掉落密度 —— **不动 `drain` 结构**。
- **"犹豫"分两种**：A 奖励型（值不值得绕）= 对的要保；B 价值型（回氧太少）= 要修氧收支。

## 图标出图锚点（2026-10-13 晚定）

- png **512×512** 源图；**高亮冷白单色 + 四档明暗**（受光 100/中间 74/暗面 48/描边投影 24），运行时 `sprite.color` **乘色**出四态 ⇒ **每图标 1 张**（不是每态 1 张）。
- ⚠️ 乘色**只能压暗不能提亮** ⇒ 基底明度须 ≥90%；**不能真去饱和** ⇒ 锁定态用"暗冷灰乘色"近似。
- ⚠️ 位图**不能靠缩放得小尺寸** ⇒ 48/24 档**单独出图且降级简化**（24 档不画纹理与投影）。
- 图标**只出图形本体，不含槽位底**。**沉淀货币（菱形）留矢量**（静态切图/动态矢量分工的边界示例）。
- ⚠️ **出图硬约束（必须独立成段，混在负面词里会被忽略）**：① **禁止任何底衬**（方/圆底板/卡片底）② **禁止任何文字** ③ 多图标同图**必须写明"各图标外接圆直径相等"**。
- 流程：**3 图标同图打样 → 确认 → 批量**；不合格**改锚点，不是重出单个**。
- **语义深海化已入库**：图鉴=磨砂金属标本罐 / 里程碑=半圆深度计 / 装置坞=压力舱门 / 海域=海图卷轴 / 设置=阀门手轮 / 帮助=探照灯。文件名不变 ⇒ 代码零改动。
  - ⚠️ 写"深海**仪器/仪表**"会把模型带成**线稿示意图**（退成扁平线稿 = 镂空）。修法：把"实心"写成不可绕过的动词「先铺一个填满颜色的实心主体，再做厚度与明暗，任何区域不许只剩轮廓线」＋「像沉甸甸的实心金属铸件」。
  - **母题三要素**：① 圆形仪器倾向 ② 必带机械件（**凸起块不是细线**）③ 必有"浸在水里"痕迹（气泡/水波/锈蚀）。
  - ⚠️ **轮廓必须互不相同**（等宽并排时外轮廓是第一眼信息）。定稿矩阵：**竖长方/半圆/正圆/横长方/近方/近方**。修法是**换载体**，不是"画细一点"。
  - ⚠️ **未修**：`help`（探照灯）光锥向两侧张开 ⇒ 24px 剪影变 A 字形，待重出。
