## 铁规

1. **移植以 `shared/dive` + `cocos` 为准，不凭记忆，也不以 `web/` 为准。** 移植前读**当前版本**的文件。
   `web/` 只作浏览器手感试纸与类型检查兜底（`cd web && npx tsc --noEmit` 退出 0 = shared 配置合法）。
   已踩：按旧版 web 多画了 V6.13 早删除的"空座 + 座圈连线"。
2. **顺序：先落文件、再写引用。** Cocos 增量编译**解析失败不登记依赖边**，新文件晚到 = importer 永久带
   失败 import 躺缓存 = 编辑器全黑而验证全绿。判据：`cocos/temp/.../resolution-detail-map.json` 的 `__unresolved_*`。
3. **验证是"静态可验"的下界，不是"画面对"的证明。** 全绿之后**必须**在 Creator 里跑 `Dive.scene` 目视确认。
4. **左右都要过**：改 `shared/` 后跑 `python tools/verify_cocos.py`（应 7/7）**和** `cd web && npx tsc --noEmit`（退出码 0）。
5. **Cocos `Graphics` 没有 `translate/rotate/save/restore`**，旋转零件一律手算坐标。
   配套 `Gfx.arc()`（分段折线，引擎 `arc` 在 y 翻转后方向镜像）、`Gfx.roundRect()`（内部翻 y）。
6. **椭圆：Phaser 收直径、Cocos 收半径** ⇒ 从 Phaser 抄 `*Ellipse(w,h)` 的值要 `÷2`。
7. **"没报错 + 图也在" ≠ "画出来了"。** 静默失效已踩三类：
   · **层序 / `active` 开关** —— `active=false` 的节点，重开点必须**每帧执行**；
   · **Graphics 层漏清** —— 新增任何层**第一件事**是加进 `update()` 的每帧 clear 名单（漏了不报错，
     只是每帧叠加成拖影：V6.55 "全屏白色横带" = `gAtmo` 漏了这行）；
   · **读一个从不被写的字段** —— 用字段前**先 grep 谁写它**。
8. **UI 分层语义**：`scrim()`（半透明暗幕，弹窗）≠ `pageFill()`（不透明铺满，页面）。混用 = "全屏、太大"。
9. **换底色必须同时换文字色**（`TXT` ↔ `TXT_LIGHT`），只换底 = 白字白底。
10. **命名规范**：中文名目录加数字前缀（编码排序是乱的）；归档改名说清关系，**归档≠删除**。
11. **素材比例只有一个口径：`originalSize`。** `sf.rect` 是**裁剪后**的（meta 默认 `trimType:auto`），
   而 `trim=false` 的 Sprite 按 `originalSize` 铺顶点 ⇒ 混用 = 分子分母来自两张不同尺寸的图
   （透明边多的 `dash.png` 被拉成方块）。`Hud.putArt` 与 `art.frameAspect` **各踩过一次**。
12. **镜像会翻转旋转方向。** 节点变换是 **T·R·S** ⇒ `scale.x=-1` 时同一个 `angle` 的视觉转向相反。
   基准：`Gfx.ang(a) = -a`、**sim 的 y 向下**、**`node.angle` 正值 = 视觉逆时针**。
   敌人贴图倾角必须写 `(-flip * tilt * 180/π)`，漏 `flip` = "朝右游的鱼往下扎"。
13. **侧视下"朝向"和"速度"是两回事。** `Enemy.fx/fy` 存**朝向单位向量**（`updateEnemies` 每帧写，
   dash 冲刺覆盖成 `dirX/dirY`），**不要**用位移差或 `vx/vy` 反推。
14. **crossfade 用「旧图在上淡出」**（`bgOld` 压 `bg` 之上、255→0；新图在下**恒满不透明**）。
   合成 = `旧×a + 新×(1-a)`；两层各半透会先暗一档再亮回来（双重曝光）。
   ⚠️ `beginXfade()` 必须在**同帧 `syncBg()` 之前**调 —— 挪后 = 拷到新图 = **没有过渡**且不报错。
   `bgOld` 是**持久 Sprite**，`hideWorld` 必须显式关。
15. **速度类表现不逐条存**：颗粒速度 = `MOTE_MUL[带] × scrollV` **每帧现算**，不留 `vy` 字段
   （逐条存 ⇒ 换带时屏幕上已有的那批还按老速度走 = "整片水没一起动"）。**同类量一律现算。**
   配套：回绕必须**双向**（反向颗粒只判 `y<0` 会在屏幕一侧堆成静止亮带）。

## 落地形态 = **B 混合**（2026-10-13 晚，已推翻 A 全矢量）

- 原因：要"商业化游戏美术级别"，而 `Graphics` 无渐变/无模糊/无笔触 = 硬天花板。
- ① 静态装饰层 → **png 切图**（面板底/按钮/图标/Logo/纹理）② 动态数值层 → **保持矢量**（氧气条填充/冷却环/
  飘字/脉冲）③ 布局层 → 代码。①② 是两个渲染批次，互不干扰。
- **风格路线：深海霓虹 + 补质感** —— 题材配色不动（青蓝 `#4fe8ff` + 生物发光色系），只补粗描边/材质纹理/
  厚度阴影/装饰层。**不转向手绘卡通**。
- **概念图 ≠ 切图**：概念图只定风格锚点；切图必须**单独生成**（纯色底 + 单主体居中 + 正交视角 + 不重叠）。
- "要亮色"**只针对商店/弹窗**；战斗画面与 HUD 维持暗色。背景图/大立绘归插画岗。

## 水域光照与生态（V6.51 立，**推翻了「越深越黑」**）

- **原则 = 光的主权转移**：不是越深越黑，是**每带换一个光的主角**（L1 太阳 → L2 残光+探照灯 → L3 生物荧光
  → L4 热泉自身 → L5 探照灯+呼吸点阵）。⚠️ **L4 要比 L3 亮**（打破单调递减）。
  **提高对比度 ≠ 提高环境亮度** —— 均值可以低，必须有亮点。
- **env 图硬红线：每张 ≥6% 像素亮于 90**。⚠️ **2026-10-14 实测 4/5 FAIL**：
  `L1 38.6% OK / L2 5.5% / L3 1.4% / L4 2.6% / L5 0.4%`。
  ⇒ 「太黑」的根因在**资源层**，改渲染层 tint 治不了；**规格写了 ≠ 资源达标**。
  重出规格 `docs/资源重出规格_V6.58.md`（env **1536×1180** + 上下无缝 + 单张 **≤0.8MB**；**L1/L2 去掉海床**）。
  验收闸门 `tools/check_art.py env|fish|items|all`（只读，退出码 0/1）。
- **层序**：`gBase→bg→**bgOld**→gBg→**gVeil→gAtmo→gBack**→fishLayer→gEnt→sub→gPlayer→gFront→hud`。
  ⚠️ 新增光照层 `gAtmo` 必须插在 `gVeil` 与 `gBack` 之间 —— 插 gVeil 之下 = 光被自己的压暗层吃掉；
  插 gBack 之上 = 盖住敌人。
- **能见度靠「雾」不靠「黑」**：雾取当前带 tint（同色），不是黑雾。**「亮的暗」vs「暗的暗」**。
- ⛔ **远景鱼群绝不给 2px 发光核心**（那核心是敌人的定位铁律）⇒ 无核心 + alpha ≤0.35 + ≤敌人 0.6× +
  不可瞄准 + 不碰撞。
- **探照灯 = 双向暴露**（最大创新）：光让你看得见，也让你被看见（`attractR = LAMP_R × 2.2`）。v1 只做视觉。
- gAtmo 图元硬上限 **130/帧**（最坏 L5 ≈105 = +9.5%）；光柱/荧光/烟柱/点阵**按带互斥**。降级旋钮 `ATMO_QUALITY`。

## 通用手法（矢量 UI 与游戏物件通用）

- **32px 量级可读的体积线索只有四条，缺一条就平**：`⓪投影（右下偏移暗盘）→ ①侧壁（同形下移+变暗）→
  ②受光弧（左上粗弧）→ ③暗弧（右下粗弧）`。**光源固定在世界坐标**，不跟被照物旋转。
  直径 < 32px 的零件加细节只是噪声。
- **56px 量级的"金属质感"只来自一条集中的镜面亮痕**（V6.57 机体）。三个被预览图否掉的方案，
  ⛔ **别再走回头路**：三条贯穿全艇的**竖板缝**（⇒ 读作**铁笼**；收细/改暗调/跨度收到 62% 之后**仍然是栅栏**）、
  舷窗**暗色窗框**（⇒ 一排窗 = **一排黑洞**）、**低频明暗斑**（⇒ **锈渍**）。
  ⇒ **窗只做加法：只加光，不加暗。** 结构线在 56px 量级上只可能读作"船被切开"。
  矢量到此为止 —— 再往上要**位图化**，但 ⚠️ **受光层不能烘焙进图**（镜像会把"左上受光"翻成右上，
  违背光源世界固定铁律）⇒ 位图只出**中性层**，明暗层继续矢量叠。
- **养成线是纯数值**（`unlocks.ts` / `pool.ts` / `subs.ts`，只改 `o2Bonus/rate/pickup/regen/armor/dodge/luck/o2Max/hp`）
  ⇒ **外观零变化**。别再去养成表里找外观项。
- **立绘/文字三条硬规约**：① 立绘框必须与素材画布同比例（**2:1**，`FILL=0.86` 居中）② `Hud.putArt` 必须用
  `sf.originalSize` 定比例，**不能**用 `sf.rect` ③ 飘字必须「加粗 + 深色描边」（`max(2, round(size*0.16))`）
  —— 「字号小」常是表象，真因是没描边。
- ⚠️ **全线禁用 ADD 混合**（Graphics 不支持；Canvas 下画成实心白块）。特效叠加走**普通 alpha**。
- ⚠️ **池化常驻精灵**（鱼池/特效池）退回标题屏必须**显式关**（`hideWorld`+`clearFx`）。
- `Title.root` 锚点 (0,0) 在**左下角** ⇒ 屏幕中心是本地 `(W/2, H/2)`。
- **远景生态（`gAtmo`）**：① 体色按"**比水体偏一点点**"配 —— 浅水取**暗剪影**、深水取**微亮轮廓**、
  只有荧光带给亮色；全给暗会在暗水里**直接消失**（v1 配色栽在这）。② 鱼群**必须成团**（团心留边距 +
  三角分布 + **同团同向同速**）—— `x/y` 各自独立随机 = 均匀点阵 = "雪花/星星"。
- **预览脚本要按"看得见的量"配，不按"函数"配**：`preview_atmo.py`（复刻 drawBg→drawVeil→drawAtmo 的
  **合成结果**）、`preview_hull_side.py`、`preview_dive_cycle.py`、`preview_lights.py`、`preview_v664.py`。
  "每个参数都合法、合起来却错"那类问题（V6.55 "背景飘白云"），**只有合成图能提前发现**。
- ⚠️ **速度类常量的符号**：`SCROLL_BASE` 恒为**正数**，消费者**一律 `y -= scrollV × …`** —— sim 的 y 向下，
  只有"减小"才是**向上掠过**（= 下潜感）。写成 `+=` 得到"上浮"，与下潜完全相反，**且不报错**。
  改这类公式时**先去 git 读改动前的原式**。
- **同心圆两种读法，不能混**：要**空心**（能见度雾）用**环带**（`line()` 粗描边 + `strokeCircle()`，
  每像素只覆盖一次）；要**实心**（探照灯/光晕）用**同 α 由外向内叠**（`fillCircle()`，覆盖次数 = 亮度）。
  抄错 ⇒ 靶环 / 空靶。⛔ 一律禁用径向渐变。
- ⚠️ **硬边来自"半径突变的层"，不来自 alpha**（V6.60 探照灯）：修法是**换半径分布**
  （`r_i = R(1−i/n)^1.35`，内层更密 ⇒ 覆盖次数在中心快升 ⇒ 自然亮斑）。
  补充边界：**⛔ 内层分档 alpha = 靶环**，但**最外 2–3 层走淡入梯度不是靶环**（0→1 次覆盖的跳变会在
  圆边界留一条可见圆周线）。"用不用分档"看**在圆的哪一段**。
- ⚠️ **同一帧里两次独立绘制的层，各自记一个"构过的带号"**：`drawBg`（颗粒）与 `drawAtmo`（鱼群/光）
  分开调用、共用一个 `layer` 字段 ⇒ 先跑的改掉带号、后跑的以为建过了 ⇒ **半新半旧**。
- ⚠️ **别拿"能见度/亮度"这类表现参数当"是不是深层"的判据**（`vis < 0.5` 判 `darkLayer`）：一改 `vis` 就会
  把深层敌人的可读性兜底**悄悄关掉**。深层是**设计事实**，直接写 `layerIdx`。
- **"太黑"要先分层归因，再动手**：V6.59 实测压暗层能吃掉**一半**（L4 40.5→20.1），另一半在 **env 图本体**。
  **点状光源拉不动均值**（48 个 2px 点覆盖不了 6% 像素）⇒ 靠渲染层"造光"解决"黑"是徒劳的，必须重出图。
- **带间过渡必须连续，但⛔ 不是全程线性**（`layerBlend`）：`tint`/`vis`/雾半径按 `depthM` 插值，
  **前 70% 保持本色、后 30% 才过渡**（`BLEND_FROM = 0.70`）。⚠️ `fogR₀ = 0` 的带（L1 刻意无雾）**不参与插值**。
- **"几道" vs "一片"的分界是宽度，不是亮度**（V6.60 光柱）。**V6.61/V6.64 光柱三定律**（详见 §光柱）：
  ① 平行光因透视必汇聚到消失点（画不出真平行）；② 太阳在无穷远 ⇒ 水面无遮挡时**光是一整片**，
  波纹调制的是**强度**不是"有光/无光"；③ **⛔ 起伏绝不靠"再叠一层半透明形状"** —— 那样叠出来是加法，
  必然留下 N 道竖亮带。正确做法是**只画一片，它的 alpha 剖面 = 基底 × 包络**。

### 光柱（V6.61 → V6.64，三次修正链）

| 版本 | 做法 | 结果 |
|---|---|---|
| V6.60 | 4 条等距平行直条 | 用户：「视觉上能看到平行的柱子吗」+ 不物理（无衰减无扩散），两头不靠 |

  留一条横向色阶带）/ `BEAM_ABSORB=1.75` / `BEAM_DIFFUSE=0.8`。

  `beamSheetStrip()` 逐段首尾相接画（**留缝 = 一片竖条纹**）。

### 远景鱼形（V6.64）

- 从"椭圆 + 三角尾"改成**单个多边形完整轮廓**（`FISH_OUTLINE`，15 点）。额外收益：**1 图元/条**

## 设计止损线（计划书 §10）

- **判据**：① 单波爽不爽 ② **氧气有没有"要不要去捡"的犹豫**。**② 2026-10-13 通过**；
  **① 2026-10-14 判定 = 未通过**。
- ⚠️ **① 的不通过理由是「体感」不是「数值」**：缺下潜纵深感 / 网雷是软控+被动 / 敌人雷同 / 无收益惊喜。
  ⇒ **骨架不用推翻，要改的是反馈通道**。方案见 `docs/战斗体感四改方案_V6.49.md`。
  关键杠杆：`depthM` **已有且每波在涨** —— 只是 `tint`/`vis`/`motes` 是 per-layer 常量 ⇒ 改成深度曲线。
- 机制在 `tables.ts`：`o2Base=3.0`、`pickupR=31`；收支曲线 **全捡 1.28×→0.98×（净赚）/
  常规 6~7 成拾取 0.83×→0.64×（净亏）**。两条线之差 = 犹豫所在。
- ⛔ **收支曲线是 P0 唯一要守的数，别凭手感改**。调氧感只动三处：`BONE_O2.o2Base` / `O2.pickupR` /
  掉落密度 —— **不动 `drain` 结构**。
- **"犹豫"分两种**：A 奖励型（值不值得绕）= 对的要保；B 价值型（回氧太少）= 要修氧收支。

## 图标出图锚点（2026-10-13 晚定）

- png **512×512** 源图；**高亮冷白单色 + 四档明暗**（受光 100/中间 74/暗面 48/描边投影 24），
  运行时 `sprite.color` **乘色**出四态 ⇒ **每图标 1 张**（不是每态 1 张）。
- ⚠️ 乘色**只能压暗不能提亮** ⇒ 基底明度须 ≥90%；**不能真去饱和** ⇒ 锁定态用"暗冷灰乘色"近似。
- ⚠️ 位图**不能靠缩放得小尺寸** ⇒ 48/24 档**单独出图且降级简化**（24 档不画纹理与投影）。
- 图标**只出图形本体，不含槽位底**。**沉淀货币（菱形）留矢量**。
- ⚠️ **出图硬约束（必须独立成段，混在负面词里会被忽略）**：① **禁止任何底衬**（方/圆底板/卡片底）
  ② **禁止任何文字** ③ 多图标同图**必须写明"各图标外接圆直径相等"**。
- 流程：**3 图标同图打样 → 确认 → 批量**；不合格**改锚点，不是重出单个**。
- **语义深海化已入库**：图鉴=磨砂金属标本罐 / 里程碑=半圆深度计 / 装置坞=压力舱门 / 海域=海图卷轴 /
  设置=阀门手轮 / 帮助=探照灯。文件名不变 ⇒ 代码零改动。
  - ⚠️ 写"深海**仪器/仪表**"会把模型带成**线稿示意图**（退成扁平线稿 = 镂空）。修法：把"实心"写成
    不可绕过的动词「先铺一个填满颜色的实心主体，再做厚度与明暗，任何区域不许只剩轮廓线」＋
    「像沉甸甸的实心金属铸件」。
  - **母题三要素**：① 圆形仪器倾向 ② 必带机械件（**凸起块不是细线**）③ 必有"浸在水里"痕迹。
  - ⚠️ **轮廓必须互不相同**。定稿矩阵：**竖长方/半圆/正圆/横长方/近方/近方**。修法是**换载体**。
  - ⚠️ **未修**：`help`（探照灯）光锥向两侧张开 ⇒ 24px 剪影变 A 字形，待重出。
