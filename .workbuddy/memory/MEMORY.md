## 铁规

1. **移植以 `shared/dive` + `cocos` 为准，不凭记忆，也不以 `web/` 为准。** `web/` 是早期 Phaser
   原型（停在 V6.27、无 L2/炮塔/商店），只作**浏览器手感试纸**与 **shared 配置层类型检查兜底**
   （`cd web && npx tsc --noEmit` 退出 0 即 shared 配置合法）。新逻辑落 `shared/dive` 与 `cocos`，
   移植前读 **`cocos/assets/scripts/...` 与 `shared/dive/...` 的当前版本**。
   已踩：曾按旧版 web 多画了 V6.13 早删除的"空座 + 座圈连线"。
2. **顺序：先落文件、再写引用。** Cocos 增量编译**解析失败不登记依赖边**，
   新文件晚到 = importer 永久带着失败 import 躺缓存 = 编辑器全黑而验证全绿。
   判据在 `cocos/temp/.../resolution-detail-map.json` 的 `__unresolved_*`。
3. **验证是"静态可验"的下界，不是"画面对"的证明。** 全绿之后**必须**在 Creator 里
   跑 `Dive.scene` 目视确认。沙箱验不了引擎真实行为与观感。
4. **左右都要过**：改 `shared/` 后跑 `python tools/verify_cocos.py`（应 7/7）**和**
   `cd web && npx tsc --noEmit`（退出码 0）—— 真源是双端共用的。
5. **Cocos `Graphics` 没有 `translate/rotate/save/restore`。** 旋转零件一律手算坐标。
   配套：`Gfx.arc()`（分段折线，引擎 `arc` 在 y 翻转后方向镜像）、`Gfx.roundRect()`（内部翻 y）。
6. **椭圆：Phaser 收直径、Cocos 收半径。** 从 Phaser 实现抄任何 `*Ellipse(w,h)` 的值都要 `÷2`。
7. **"没报错 + 图也在" ≠ "画出来了"。** 静默失效高发区，已踩三类：
   · **层序 / `active` 开关** —— 任何 `active=false` 的节点，重开点必须**每帧执行**；
   · **Graphics 层漏清** —— 新增任何层，**第一件事是加进 `update()` 的那行每帧 clear 名单**。
     漏了不报错，只是每帧叠加成拖影（V6.55 的"全屏白色横带"= `gAtmo` 漏了这行）；
   · **读了一个从不被写的字段** —— 渲染层曾用 `e.vx/e.vy` 算朝向，而敌人在 `world.ts` 里是
     直接改坐标（`e.x += nx*speed*dt`），`vx/vy` 自 `mkEnemy` 归零后**再没人写过** ⇒ 恒 0
     ⇒ 全场鱼水平朝左。**用字段前先 grep 谁写它。**
8. **UI 分层语义**：`scrim()`（半透明暗幕，弹窗用）≠ `pageFill()`（不透明铺满，页面用）。
   把弹窗底画成 `pageFill` 就是"全屏、太大"。
9. **换底色必须同时换文字色**（`TXT` ↔ `TXT_LIGHT`），只换底 = 白字白底。
10. **命名规范**：中文名目录加数字前缀（按字符编码排序是乱的）；归档改名说清关系，**归档≠删除**。
11. **素材比例只有一个口径：`originalSize`。** `sf.rect` 是**裁剪后**的（meta 默认 `trimType:auto`），
   而 `trim=false` 的 Sprite 按 `originalSize` 铺顶点 —— 混用 = 分子分母来自两张不同尺寸的图
   （透明边多的 `dash.png` 被拉成方块）。`Hud.putArt` 与 `art.frameAspect` **各踩过一次**。
12. **镜像会翻转旋转方向。** 节点变换是 **T·R·S**（先缩放后旋转）⇒ `scale.x=-1` 时同一个
   `angle` 的视觉转向正好相反。基准：`Gfx.ang(a) = -a`、**sim 的 y 是向下**、**`node.angle`
   正值 = 视觉逆时针**。敌人贴图倾角必须写 `(-flip * tilt * 180/π)`，漏 `flip` 会"朝右游的鱼往下扎"。
13. **侧视下"朝向"和"速度"是两回事。** `Enemy.fx/fy` 存**朝向单位向量**（`updateEnemies` 每帧写，
   dash 冲刺阶段覆盖成 `dirX/dirY`），**不要**用位移差或 `vx/vy` 反推 —— 蓄力/冲刺时位移会归零或突变。
14. **crossfade 用「旧图在上淡出」**（`bgOld` 压 `bg` 之上、255→0；新图在下**恒满不透明**）。
   合成恰为 `旧×a + 新×(1-a)` = 干净交叉淡入；两层各半透会先暗一档再亮回来（双重曝光）。
   ⚠️ `beginXfade()` 必须在**同帧 `syncBg()` 之前**调（`handleEvent` 天然满足）—— 挪后 = 拷到新图
   = **没有过渡**，且不报错。`bgOld` 是**持久 Sprite**，`hideWorld` 必须显式关。
15. **速度类表现不逐条存**（V6.56）：颗粒速度 = `MOTE_MUL[带] × scrollV` **每帧现算**，不留 `vy` 字段。
   逐条存速度的话，换带爆冲只能推快新生成的，屏幕上已有的那批还在按老速度走
   ⇒ "换带时整片水没一起动"。**同类量（方向也在变，如 L4 反向）一律现算。**
   配套：回绕必须**双向**（反向走的颗粒只判 `y<0` 会在屏幕一侧堆成静止亮带）。

## 落地形态 = **B 混合**（2026-10-13 晚，已推翻 A 全矢量）

- 原因：用户要"商业化游戏美术级别"，而 `Graphics` 无渐变/无模糊/无笔触 = 硬天花板。
- ① 静态装饰层 → **png 切图**（面板底/按钮/图标/Logo/纹理）② 动态数值层 → **保持矢量**（氧气条填充/冷却环/飘字/脉冲）③ 布局层 → 代码。① ② 是两个渲染批次，互不干扰。
- **风格路线：深海霓虹 + 补质感** —— 题材配色不动（青蓝 `#4fe8ff` + 生物发光色系），只补粗描边/材质纹理/厚度阴影/装饰层。**不转向手绘卡通**。
- **概念图 ≠ 切图**：概念图只定风格锚点；切图必须**单独生成**（纯色底 + 单主体居中 + 正交视角 + 不重叠），否则 `process_item_art.py` 抠不了底。
- "要亮色"**只针对商店/弹窗**；战斗画面与 HUD 维持暗色。背景图/大立绘归插画角色。

## 水域光照与生态（V6.51 立，**推翻了「越深越黑」**）

- **原则 = 光的主权转移**：不是越深越黑，是**每带换一个光的主角**（L1 太阳 → L2 残光+探照灯 → L3 生物荧光 → L4 热泉自身 → L5 探照灯+呼吸点阵）。
  ⚠️ **L4 热泉带要比 L3 亮**（打破单调递减）。**提高对比度 ≠ 提高环境亮度** —— 均值可以低，必须有亮点。
- **env 图硬红线：每张 ≥6% 像素亮于 90**。⚠️ **2026-10-14 实测仍未达标**：
  `L1 38.6% OK / L2 5.5% / L3 1.4% / L4 2.6% / L5 0.4%` —— **4/5 FAIL**。
  ⇒ 「太黑了」的根因在**资源层**，改渲染层 tint 治不了；**规格写了 ≠ 资源达标**。
  重出规格 `docs/资源重出规格_V6.58.md`（env **1536×1180** + 上下无缝 + 单张 **≤0.8MB**，
  L1 现 2.58MB；**L1/L2 必须去掉海床**）。
  ⚠️ **沙箱 Python 没有 numpy** —— 统计用**纯 PIL**：亮度 `histogram()[91:]` 求和比例；
  重心 `getchannel('A').resize((w,1), Image.BOX)` 算逐列权重（敌人贴图"头朝左"的基线
  = **重心 x 落在 42~47%**，现有 swarm/dash/drift 均符合）。
- ⚠️ **新增光照层 `gAtmo` 必须插在 `gVeil` 与 `gBack` 之间**（层序 `gBase→bg→**bgOld**→gBg→**gVeil→gAtmo→gBack**→fishLayer→gEnt→sub→gPlayer→gFront→hud`；`bgOld` = V6.56 的 crossfade 旧背景）。
  插 gVeil 之下 = 光被自己的压暗层吃掉；插 gBack 之上 = 盖住敌人。
- **能见度靠「雾」不靠「黑」**：雾取当前带 tint（同色），不是黑雾。**「亮的暗」vs「暗的暗」**。
- ⛔ **远景鱼群绝不给 2px 发光核心**（那核心是敌人的定位铁律）⇒ 无核心 + alpha ≤0.35 + ≤敌人 0.6× + 不可瞄准 + 不碰撞。
- **探照灯 = 双向暴露**（最大创新）：光让你看得见，也让你被看见（`attractR = LAMP_R × 2.2`）。v1 只做视觉，机制挂 P1。
- gAtmo 图元硬上限 **130/帧**（最坏 L5 ≈105 = +9.5%）；光柱/荧光/烟柱/点阵**按带互斥**。降级旋钮 `ATMO_QUALITY`（不许降鱼群与探照灯）。
- 规格：`docs/水域光照与生态规格_V6.51.md`（修订 V6.50 §9 落地顺序）。

## 通用手法（矢量 UI 与游戏物件通用）

- **32px 量级可读的体积线索只有四条，缺一条就平**：`⓪投影（右下偏移暗盘）→ ①侧壁（同形下移+变暗）→ ②受光弧（左上粗弧）→ ③暗弧（右下粗弧）`。**光源固定在世界坐标**，不跟被照物旋转。直径 < 32px 的零件加细节只是噪声。
- **56px 量级的"金属质感"只来自一条集中的镜面亮痕**（V6.57 机体）。三个被预览图否掉的
  方案，⛔ **别再走回头路**：三条贯穿全艇的**竖板缝**（⇒ 读作**铁笼**；收细/改暗调/跨度收到
  62% 之后**仍然是栅栏**）、舷窗**暗色窗框**（⇒ 一排窗 = **一排黑洞**）、**低频明暗斑**（⇒ **锈渍**）。
  ⇒ **窗只做加法：只加光，不加暗。** 结构线在 56px 量级上只可能读作"船被切开"。
  矢量到此为止 —— 再往上要**位图化**，但 ⚠️ **受光层不能烘焙进图**（镜像会把"左上受光"翻成
  右上，违背光源世界固定铁律）⇒ 位图只出**中性层**，明暗层继续矢量叠。
- **养成线是纯数值**（`unlocks.ts` 永久强化 / `pool.ts` 商店卡 / `subs.ts` 潜航器固有，
  只改 `o2Bonus/rate/pickup/regen/armor/dodge/luck/o2Max/hp`）⇒ **外观零变化**。
  "机体没质感"不可能是养成线补的，只能靠渲染层 —— 别再去养成表里找外观项。
- ⚠️ **`HULL_OUTLINE` 是 14 点轮廓（y 到 ±1.00），不是 12 点**。任何"贴轮廓"的新数值
  （板缝/铆钉/高光带）都必须先读 TS 里的**现值**再插值，凭记忆写必错（V6.57 第一版就栽了）。
- **立绘/文字三条硬规约**：① 立绘框必须与素材画布同比例（**2:1**，`FILL=0.86` 居中）② `Hud.putArt` 必须用 `sf.originalSize` 定比例，**不能**用 `sf.rect`（trimType:auto 下 rect 是裁剪后的 344×264，而引擎按 originalSize 600×300 定标 ⇒ 非等比拉伸）③ 飘字必须「加粗 + 深色描边」（`max(2, round(size*0.16))`）—— 「字号小」常是表象，真因是没描边。
- ⚠️ **全线禁用 ADD 混合**（Graphics 不支持；Canvas 下画成实心白块）。特效叠加走**普通 alpha**（贴图 alpha 已按亮度导出）。别看到"适合 ADD"就开混合。
- ⚠️ **池化常驻精灵**（鱼池/特效池）退回标题屏必须**显式关**（`hideWorld`+`clearFx`）—— Graphics 层会 clear，池化 Sprite 不会自动清。
- `Title.root` 锚点 (0,0) 在**左下角** ⇒ 屏幕中心是本地 `(W/2, H/2)`。
- **远景生态（`gAtmo`，V6.53/V6.55）**：① 体色按"**比水体偏一点点**"配 —— 浅水取**暗剪影**、
  深水取**微亮轮廓**、只有荧光带给亮色；全给暗会在暗水里**直接消失**（"没有鱼"也是失败，
  V6.55 第一版配色就栽在这）。② 鱼群**必须成团**（团心留边距 + 三角分布 + **同团同向同速**）
  —— `x/y` 各自独立随机 = 均匀点阵 = "雪花/星星"，不是鱼群。⛔ 远景鱼群**绝不给 2px 发光核**。
- **预览脚本要按"看得见的量"配，不按"函数"配**：`preview_atmo.py`（复刻 drawBg→drawVeil→drawAtmo
  的**合成结果**）、`preview_hull_side.py`、`preview_dive_cycle.py`、`preview_lights.py`（光照合成）。
  "每个参数都合法、合起来却错"的那类问题（V6.55 的"背景飘白云"），**只有合成图能提前发现**。
- ⚠️ **速度类常量的符号（V6.59 挖出的真 bug）**：`SCROLL_BASE` 恒为**正数**，消费者**一律
  `y -= scrollV × …`** —— sim 的 y 向下，只有"减小"才是**向上掠过**（= 下潜感）。写成 `+=` 得到的是
  "上浮"，与下潜完全相反，**且不报错**。V6.56 提速时把 `vy = -6~-20` 写成 `+46` 且注释丢了负号 ⇒
  潜伏了一整轮。**改这类公式时，先去 git 读改动前的原式**。
- **同心圆两种读法，不能混（V6.59）**：要**空心**（能见度雾）用**环带**（`line()` 粗描边 +
  `strokeCircle()`，每像素只覆盖一次）；要**实心**（探照灯/光晕）用**同 α 由外向内叠**
  （`fillCircle()`，覆盖次数 = 亮度）。抄错 ⇒ 靶环 / 空靶（预览图实测）。⛔ 一律禁用径向渐变。
- **"太黑"要先分层归因，再动手**：V6.59 实测"改前(source)→合成后"亮度差 —— 压暗层能吃掉
  **一半**（L4 40.5→20.1），另一半在 **env 图本体**（亮于 90 的像素仅 0.0–2.2%）。

## 设计止损线（计划书 §10）

- **判据**：① 单波爽不爽 ② **氧气有没有"要不要去捡"的犹豫**。**② 2026-10-13 通过**（「氧气现在让我犹豫去捡了」）；**① 2026-10-14 判定 = 未通过**。
- ⚠️ **① 的不通过理由是「体感」不是「数值」**：缺下潜纵深感 / 网雷是软控+被动 / 敌人雷同 / 无收益惊喜。
  ⇒ **骨架不用推翻，要改的是反馈通道**。方案见 `docs/战斗体感四改方案_V6.49.md`。
  关键杠杆：`depthM` **已有且每波在涨**，只是 `tint`/`vis`/`motes` 是 per-layer 常量 ⇒ 改成深度曲线即可。
- 机制在 `tables.ts`：`o2Base=3.0`、`pickupR=31`；收支曲线 **全捡 1.28×→0.98×（净赚）/ 常规 6~7 成拾取 0.83×→0.64×（净亏）**。两条线之差 = 犹豫所在。
- ⛔ **收支曲线是 P0 唯一要守的数，别凭手感改**。调氧感只动三处：`BONE_O2.o2Base` / `O2.pickupR` / 掉落密度 —— **不动 `drain` 结构**。
- **"犹豫"分两种**：A 奖励型（值不值得绕）= 对的要保；B 价值型（回氧太少）= 要修氧收支。
