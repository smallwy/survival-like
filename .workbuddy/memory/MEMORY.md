## 铁规

1. **以 `shared/dive` + `cocos` 当前版本为准**（不凭记忆、不以 `web/` 为准）；**先落文件、再写引用**——Cocos
   解析失败**不登记依赖边** ⇒ 编辑器全黑而验证全绿。**验证是下界** ⇒ 全绿后仍须目视 `Dive.scene`；改
   `shared/` 后 `verify_cocos.py`(7/7) **和** `cd web && npx tsc --noEmit` 都要过。
2. **"没报错 + 图也在" ≠ "画出来了"**。静默失效**五**类：① 层序/`active`（`active=false` 的重开点必须**每帧
   执行**）② Graphics 层漏清 ③ 读一个从不被写的字段 ④ 事件回调里直接 `Graphics.fill*`（会被同帧 clear
   抹掉）⑤ ★ **两条规则都能收场 ⇒ 后写的那条永不执行**（V6.79b 缠索：距离 112px 在 0.42s 先触发，
   "往外游 0.7s"成了死代码）⇒ **凡阈值/时长成对出现，必须回代算谁先命中**。
   ⚠️「画面毫无改变」先查**尺寸/可见性/层序/透明度**，别急着改内容。
3. Cocos `Graphics` **无 translate/rotate/save/restore** ⇒ 旋转零件手算坐标；**椭圆 Phaser 收直径、Cocos 收
   半径**；⛔ 禁 ADD 混合、禁径向渐变。**镜像翻转旋转方向**（敌人倾角 `(-flip*tilt*180/π)`）。**侧视"朝向"
   ≠ "速度"**（`Enemy.fx/fy` 存朝向）。⚠️ **`Gfx` 世界 y = `H−simY`** ⇒ 裸 Sprite 自己翻 y。
4. **crossfade = 旧图在上淡出**（`beginXfade()` 要在同帧 `syncBg()` **之前**）；`hideWorld` 必须显式关
   `bgOld`/池化常驻精灵。**速度类表现每帧现算**；回绕**双向**；`SCROLL_BASE` 恒正，消费者一律
   `y -= scrollV×…`（写 `+=` = "上浮"**且不报错**）；`drawBg`/`drawAtmo` **各记一个"构过的带号"**。
