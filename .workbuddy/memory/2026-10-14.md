### 四条关键结论（可复用）

1. **"沉底淡出"是补丁，不是设计**。它当初就是用来遮 V6.42 的越界（艇半挂在柱外 78px）。
   删掉补丁让动作全程可见 ⇒ 那个真问题立刻暴露。**用"看不见"藏问题，代价是下次必然返工。**
2. **"动力感"的主开关是速度差，不是气泡数量**。排气口跟着艇走，气泡若只比艇快
   0–28px/s（旧值 38–75 vs 艇峰值 47）⇒ 气泡**粘在艇上**，读作"一团气泡陪着它漂"。
   必须提到相对速度 48–103px/s，气泡才能冲过艇身继续往上。
3. **排气口位置要同时过三关**：① 出壳（√(dx²+dy²) > 90，否则气泡一出生就被艇压住，
   因为 `tBubble` 层在舱体之下）② 不越柱底（556+72=628 < 652）③ 上升途中不被艇挡。
   取 (76, 72) 斜下 —— 正下方 (0, 96) 会让 ② 失败。
4. **抽帧预览看不出连续动画的问题**，但**位移/速度/间距这类"时间上"的问题只有抽帧预览能看到**
   （静态预览 `preview_diver.py` 完全看不到）。→ 新写 `tools/preview_dive_cycle.py`。

## V6.46 机制型武器实装（3 把 + 6 条进化）+ 特效按来源分化

用户原话：「1 内讧 2 伤害砍 39% 3 可以 4 确认
5 目前有些技能施法 打击 击杀特效还是不够 继续未完成的」
（决策 1 **从"真友军"改回"内讧"** —— 见下）

### 落地内容

`mine` 气泡雷族 / `net` 网族 / `lure` 诱饵族，各 1 基础 + 2 进化 = **9 个 WeaponId**。
水流推进器**故意不加进 `WeaponId`**（一加，`Record<WeaponId,…>` 的 `WEAPON_DEF` 就必须同步补全 = 等于提前实装）。

### 五个可复用的判断

1. **`enemyAim(e)` 一个函数收下三个机制**：驯化网 / 诱饵 / 光墙本质都是"改写敌人寻路目标"。
   分散在各自的 update 里迟早互相打架。优先级写死 **内讧 > 诱饵 > 玩家**。
2. **`mkEnemy()` 工厂是被 TS 报错逼出来的**：给 `Enemy` 加三个控制字段时，
   手写两处对象字面量（`spawnEnemy` / `spawnBoss`）**只改了一处**，报 "not assignable"。
   抽工厂后新增字段物理上不可能只改一半。
3. **发现了两个重复真源**：
   - `WEAPON_NAME` / `WEAPON_FAMILIES` 在 `codex.ts` 与 `unlocks.ts` **各有一份**，
     加三族时只改一份 ⇒ TS 报 "missing properties"。**重复定义的真实代价是"每个新增项都要记得改两处"**。
   - `SimEvent` 里有两个 `muzzle` 定义（加字段时没删旧的）⇒ 联合类型把 `fam`/`power` 变成可选，读取时报"属性不存在"。
4. **"施法感"的解法不是"开火时多画点"，是"让开火有预告"**：
   新增**前摇蓄力环**（`ivLast ≥ 1.4` 的武器，开火前 28% 窗口画 36→9 向内收拢的双环）。
   进度**直接读 `weapon.timer / ivLast`** —— 模拟层不需要维护第二份"正在蓄力"状态。
   ⚠️ 不能走 `pushShock` 池（每帧 push 会挤爆 `SHOCK_CAP`，症状是打击特效**整体消失**且不报错）。
5. **特效分化要分"形状语汇"而不是"图元数量"**：每条新分支与原来**持平或更省**。
   靠加粒子做区分会在满屏 100+ 敌人时糊成一团 —— 那正是"特效不够"的另一种表现。

### 三把武器的关键常量（都带"为什么不是别的值"）

| 武器 | 红线常量 | 不做会怎样 |
|---|---|---|
| 气泡雷 | `MINE_ARM = 0.40s` 布防 | 一布雷就自己踩炸，武器直接废掉 |
| 气泡雷 | `MINE_CAP = 6` | 稳态 21 枚 = 地毯轰炸，不用走位也能赢 |
| 连锁雷 | `MINE_CHAIN_R = 90 > MINE_R = 88` | 相邻两枚不互引 = 连锁雷名不副实 |
| 氧气雷 | 三条锁（−39% 伤害 / 单爆封顶 +10 / 每敌只计一次） | 缺一条 = 站雷堆里无限回血，**氧气机制作废** |
| 网 | `NET_R` 张开的两个入口共用 `openNet()` | 分开写迟早只有一处生效，且不会报错 |
| 驯化网 | **Boss 免疫策反**（减速仍生效） | "网住 Boss 帮你打小怪"摧毁关卡设计 |
| 诱饵 | 投放点 = `densestSpot()` 密度最高处 | 投在最近敌人身上没用，它本来就在朝你来 |
