### 重大纠正（务必记住）
- **`DiveScene` 才是当前正式玩法**：`web/src/main.ts` 的 `scene:[TitleScene,DiveScene,ExploreScene,GameScene]`，

  gameData 那套（护甲相克/计谋/六阵型）是上一代设计。
- web/src 共 **16206 行**；大头 `DiveScene.ts` 6530 行 + `GameScene.ts` 5900 行，逻辑与 Phaser Graphics 高度交织。

### 引擎选型复核（用户问：Godot 还是 Cocos 成本小）
- 本机事实：**Cocos Creator 3.8.8 已装**（`C:/ProgramData/cocos/editors/Creator/3.8.8/CocosCreator.exe`，Dashboard 2.2.2）；Godot 全盘未装。

### 关键结论
- **验证边界（必须对用户说清）**：`verify_cocos.py` 全绿 ≠ 能跑。它证明的是
  "模拟核心行为正确 + 视图层没用错模拟层 API + 无漂移"；**引擎 API 真实行为与画面正确性
  只能由用户在 Creator 里目视确认**。沙箱跑不起 GUI 编辑器，这是硬限制。
- 无头冒烟 21/21：120s 圆形走位跑通 4 波→3 商店→1 决策→上浮；同 seed 世界线完全一致（确定性成立）。
- 自查发现并修掉的**自己的 bug**：`sync_shared.py` 的 `strip_banner()` 原本"吃掉开头所有 // 行"，
  把正文自身的注释头也吞了 → `shared/index.ts`、`shared/dive/index.ts`、`shared/gameData.ts`
  三个文件**永远误报漂移**（假红），真漂移反而被淹没。改为按横幅固定行数切，并让失败输出指出第几行不同。
- 删除 `cocos/src/logic/`（assets/ 之外 Cocos 不编译，且已和真源漂移：内联 0x4fe8ff vs 真源 UI.cyan）。
  内容留在 commit a86f5f0。
- 自查发现并修掉的 Creator 注入坑（写进 cocos/README 的"已知坑"）：
  ① 运行时 `new Node()` layer=DEFAULT，UI 相机只渲染 UI_2D → 必须显式继承父 layer（统一走 mkNode/mk）；
  ② Label 锚点要跟着对齐方式走，否则右对齐数字右边缘随位数漂移（原 Phaser 侧是 setOrigin 干的）；
  ③ 全屏底色/背景不能写死 (0,0,W,H)，设计分辨率宽高比不同会露清屏色 → 按 Canvas 实际尺寸外扩；
  ④ `cocos/tsconfig.json` extends `./temp/tsconfig.cocos.json`（编辑器生成），**不能用于 CI**，
     离线检查走 `tools/cocos_check.tsconfig.json`。
