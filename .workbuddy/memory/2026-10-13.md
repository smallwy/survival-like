### 真发现（本轮最值钱的几条）
- **`Camera` 没有 `zoom`**：Cocos 3.8 只有 `orthoHeight`，而它由 `Canvas` 组件托管。
  换成真 `cc.d.ts` 检查后立刻报 `TS2339: Property 'zoom' does not exist on type 'Camera'` ——
  之前手写桩里我自己写了 `Camera.zoom`，**检查通过的是我的假设而不是引擎**。
  改法：缩放 `WorldRoot` 节点（`setScale`）+ `setPosition(-z*camX, z*(camY-H))`，等价、不抢引擎状态。
  同步删掉 `Dive.scene` 与 `gen_cocos_scene.py` 里的 `cam` 序列化字段。
- **`node.angle` 逆时针为正**（引擎实现是 `Quat.fromAngleZ`），而 sim 角度是 y 向下顺时针为正
  → 必须写 `node.angle = -(aim*180/PI)`。符号搞反 = 潜航器朝反方向。
- **`col()` 被局部变量遮蔽**：`drawEnemies` 里写了 `const col = ...`，遮蔽了从 `Gfx` 导入的
  颜色构造函数 `col()`，报 `TS2349: Type 'Number' has no call signatures`。改名 `body`。
- **暗幕必须画在世界坐标**（web 铁律）：暗幕只压暗地形，敌人/气泡/玩家画在它之上，
  否则深渊层（可见度 10%）会把 gameplay 信息一起吃掉。用**18 环同心环带**
  `pow(1-i/18, 2.4)*strength`，每像素只画一次（径向渐变会反复叠加成死黑）。
- **`.webp` 的取舍**：`macro.SUPPORT_TEXTURE_FORMATS` 含 `.webp` 但那是**引擎运行时**格式，
  不等于**编辑器导入器**支持（沙箱无法验证）→ 统一转 PNG（0.37 MB → 3.6 MB，换零风险）。
- **web 版本本来就没有音效**：全仓无音频文件、无 `AudioContext` —— 音效不是移植缺口，是**新功能**。
  （更正了之前"未移植：音效"的错误记录。）

### 修掉的自己的坑：`cocos/.gitignore` 行内注释
上次写的 `/library/        # 资源数据库缓存……` **整行被当成一条规则**（**.gitignore 不支持行内
注释**），于是 `/library/`、`/temp/`、`/profiles/`、`/local/`、`/build/`、`/native/` 六条**全部失效**。
编辑器一打开工程，`library/`（36 MB）、`temp/`（3.6 MB）就成片进 `git status`。
（上一节写的"已 gitignore"是错的，此行纠正。）已改成注释独占行并逐条用
`git check-ignore -v --no-index` 验证命中。
**踩坑提示**：`git check-ignore -v <路径>/`（带尾斜杠）会返回 exit 0 且打印
`<file>:<空行号>:` —— 看似"已忽略"，实为空模式误报；**必须用 `git ls-files --others --exclude-standard`
或对不带斜杠的文件路径判定**。
