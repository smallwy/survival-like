### 关键发现（都是翻本机编辑器安装目录得到的，不是猜的）
编辑器在 `C:/ProgramData/cocos/editors/Creator/3.8.8/`，**模板就在本地**：
`resources/templates/{empty,empty-2d,empty-quality,hello-3d-world}`。
- `empty-2d` 的 `package.json` 只有 `{"name":"empty"}` → **Dashboard 不要求额外字段**；
  它带 `settings/v2/packages/engine.json`（2D 模块集）、`.creator/default-meta.json`、`profiles/v2/packages/scene.json`。
- **3.8.8 的默认设计分辨率是 1280×720、fitWidth=true**；配置键是
  `general.designResolution.{width,height,fitWidth,fitHeight}`，存在 `settings/v2/packages/project.json`。
  `project` 扩展自身版本 = **1.0.6**（→ 文件里的 `__version__` 写 1.0.6 才不触发迁移）。
  来源：`app.asar` 里 `"name":"project","version":"1.0.6"` 的贡献声明。
- **`empty-2d` 模板连场景文件都没有** → Cocos 3.8 新建 2D 工程确实是空 assets。
- **金矿**：编辑器自带 2D 场景模板
  `resources/resources/3d/engine/editor/assets/default_file_content/scene/scene-2d.scene`
  → 手写场景时**逐字段照抄它**（`cc.SceneGlobals` 那 6 个子对象凭记忆写必错）。
- 资源 meta 的真实格式（别照抄 `default_file_content/typescript/ts.meta`，那是占位符 `importer:"*"`）：
  真实 `.ts.meta` 是 `{"ver":"4.0.24","importer":"typescript","imported":true,"uuid":...,"files":[],"subMetas":{},"userData":{}}`
  （取自 `default_renderpipeline/*.ts.meta`）；`.scene.meta` 是 `ver:"1.1.50", importer:"scene", files:[".json"]`；
  目录 meta 是 `ver:"1.2.0", importer:"directory"`。
- **Cocos 压缩 uuid 算法**（场景引用用户脚本用的是它，不是完整 uuid）：
  `Base64KeyChars = "A-Za-z0-9+/"`（标准表）＋保留前 5 个 hex，其余每 3 hex → 2 base64 → **23 字符**。
  逐字实现抄自编辑器（`compressHex` / `decompressNormalUuid`）。已在 20000 组随机 uuid 上验证互为逆运算。
  **算错 = 编辑器显示 Missing Script**（画面能跑但组件不生效）。落在 `tools/cocos_uuid.py`。
