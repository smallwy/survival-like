## 二、三条根因型发现（值得记进长期记忆）

### ① 船体那两个品红圆环 = 回声炮的「前摇蓄力环」

- 不是新画的什么东西 —— **V6.46 就在**，只是一直没人把它和"船体上莫名圆环"对上。
- 两罪并罚：**闭合亮环**（铁规 14「闭合/半闭合亮色轮廓 = UI 框语汇」，这是**第三次**复发）
  + **借了敌人的颜色语汇**（`theme.ts` ① 把 `magenta` 划给"稀有 / 危险生物"）。
- 正解 = 画在**炮口自己身上**的充能柔光（同心圆、无轮廓，同 `drawLamp` 的手法）。
- ★★ **新判据：凡 `WEAPON_DEF.color` 落在玩家自己身上，先问这个色是不是"生物语汇"。**

### ② 出弹口恒偏 6.3px

- sim 出弹点从**座心**沿 aim 外推；视图炮管却是从**转座心**外推 → 两条轴差一整个法向量。
- 新增共享常量 `tables.TURRET_OUT = MOUNT_RING_R × 0.90`，`world.ts` 六处 + `drawTurret.rOut` 同源。
- 顺带揪出：**后坐力被算了两次**（`rx,ry` 与 `drawEmitter` 内部各加一次 `fore`）。
- ★★ **新判据：同一个位移在两处各加一次 = 实机"对不上"且不报错。**

### ③ 背景图去鱼 V6.81「减了跟没减」

- 三条叠加：补洞 σ=8 的窗口里**仍全是鱼**（成片、间距 ~20px）+ 判定带只到 72% 而 **L1 的鱼铺到 84%**
  + 8 邻域腐蚀把 2~3px 的鱼身**吃光**。
- 新口径 = **大半径归一化补洞**（σ=**18** / 膨胀 **5** / 只从未遮盖区取色）+ 判定带**按层给**
  + 去噪靠**连通域特征**不靠形态学 + 统计**向量化**。
- ★★ **新判据：遮罩覆盖率与检出条数全"正常"时，问题往往在补洞半径，不在检出。**
