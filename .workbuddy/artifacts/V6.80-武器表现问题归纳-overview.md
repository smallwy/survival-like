## 关键结论

### ① 施法速度评估（用户点名"评估下"）—— 太快，病根是「射速复利」

4 个乘数全乘在 `iv` 的**同一轴**上：

```
ivLast = 基础 iv ÷ [ (1+(等级-1)×0.12) × seatBoost × (1+高压供能) ] × 过载核心
```

| 场景 | 有效间隔 | 发/秒 |
|---|---|---|
| `gun` 1 级裸装 | 0.110 s | 9.1 |
| `gun` 3 级 + 高压 ×2 | 0.071 s | 14.1 |
| `gun_gl` 5 级 + 高压 ×4 + 双联 + 过载 | 0.013 s | **≈74** |

⇒ 成型后是一门 **70+ 发/秒** 的炮，屏幕上不是"在射击"而是一条**不间断光带**。
口径 = **抬基础 + 等比补 dmg**。★ 硬约束：**DPS 逐条不变**（DPS 一动 P0 收支曲线就动）；
只动 `iv < 1.0` 的族（**网 / 诱饵 / 鱼雷未动**）。

| 5 | 精英黄圈突兀 | 闭合环 → **体表三层辉光 + 绕游光点** |

### ③ 举一反三（第 7 条）落成一条通则

> **凡是"状态 / 身份"，都必须画在物体自己身上，⛔ 不能围一圈线。**
> 围一圈线 = 画了个框 = 读作 UI 覆盖层。

精英黄圈 / 定身青环 / swarm 蓄力环 **三处同根因**；正解 = **体表辉光 / 缠绕物 / 收势弧**。
