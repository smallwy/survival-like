## 一、✅ 潜航器游行时有了各自的动力特效

三台各一套"动力语汇"，靠机身主题色上色 + 粒子形态区分：

| 台 | 尾流形态 |
|---|---|
| **灯艇**（青白） | 细密**气泡**——多、小、散得快（明亮·轻盈） |
| **刺鳐**（玉绿） | 两三道**长条速度流线**——少、快、拖尾长（尖锐·高速） |
| **深潜者**（暗紫） | **大颗低沉的脉冲气泡**——少、大、慢（厚重·军械） |

细节：尾流从**艉部**喷、方向 = **移动方向的反向**（推进反作用力）。⚠️ 角度取**移动方向**而不是机体朝向——朝向是离散翻面的（还有 0.35 秒迟滞），喷口跟着它跳会读成"尾流在抽搐"。

## 二、✅ 「炮座飘不飘」现在**看得见**了

新工具把判据直接画在机体上 → `docs/shots/sub_mounts_ab.png`：

- **红折线** = `HULL_OUTLINE`（挂点基准）· **黄圈** = 6 个挂点 · **青框** = 位图里挖的发射槽
- 逐座检查"这一座下面有没有艇身像素"，没有就画成**品红**并列出编号

**实测结论：三台的 6 座全部落在艇身上（无品红）** ⇒ 从几何看**炮座并不飘**。

⚠️ **但图里能看见另一件事**：红轮廓线在**灯艇左上 / 刺鳐上缘跑到了机体之外**——那是渲染层沿 `HULL_OUTLINE` 画的**霓虹兜底轮廓**。**这更像是你在实机里看到的"飘"**：一条浮在机体外的亮线，不是炮座。⇒ 记成待办：兜底轮廓应沿**位图自己的边缘**画，不该照抄那条固定折线。

## 三、⏸ 「发射基座均匀分散」——先停下问你

查实的硬约束：

| 项 | 现状 |
|---|---|
| 背排为什么从 `u=0.12` 起 | **指挥塔占了背脊前段**（`TOWER = u∈[0.30, 0.72]`）——塔与背脊炮位争同一条中轴线，这是 V6.71 就记下的老账 |
| 现在的间距 | 背 `0.12 / -0.28 / -0.68`、腹 `0.06 / -0.34 / -0.74`（交错 0.06）。间距 0.40 ≈ 全长的 40%，**已覆盖约 80% 的可用长度** |
| 改它的代价 | 这张表是**挂点唯一真源** ⇒ 要**重挖三张图的发射槽** + 同步 `prep_sub_art.py` / `preview_hull_side.py` / 文档，并且会**改变炮在艇上的位置** |

**两个方向（选一个我再动）：**

- **A · 小幅拉匀（低风险）**：把两排的 `u` 均匀铺满可用长度（背 `0.12 / -0.37 / -0.86`、腹 `0.06 / -0.43 / -0.92`）。视觉上更整齐、机体中段更"空"，但仍受塔的限制。**要重挖三张槽。**
- **B · 改成"绕轮廓分布"（高收益高风险）**：不再"背 3 腹 3"，6 座沿机体轮廓均匀铺开（如上 2 + 下 2 + 侧 2）。机体的**造型自由度最大**（这正是你要的），但 `v` 要逐座重贴轮廓、炮的朝向分布会变 ⇒ 手感要一起复测。

我倾向 **B**——你说"均匀分散那么潜航器的创作会很好点"，那要的就是**挣脱"两排平行"这个框**，A 只是把它拉长一点、还是两排。但 B 改完必须重新目视一次挂点。
