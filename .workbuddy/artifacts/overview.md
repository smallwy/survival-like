# 主界面中央区 V6.42 —— 下潜中的潜航器（立体版）

## 做了什么

按你的三条指令重写了主界面中央区：**真下潜** + **有体积的实物** + **不留探照锥**。

| 你的要求 | 落地 |
|---|---|
| 真的下潜 | 舱体在竖向水体柱里匀速沉 **220px**（8.2s），沉到底**一边继续下沉一边淡出**，循环 10s |
| 立体感的实物 | 按项目既定的**四条体积线索**逐条落，另加三条 preview 迭代出来的新线索（见下） |
| 探照锥不要 | 删了。方向线索改由受光弧 / 暗弧 / 投影 / 球面明暗承担 —— 全场只剩**一个**光源说法 |

同时删掉了闸门、机械臂、鱼群（"没意义"的根源是**每条动画都没有来源**）。

## 立体感具体怎么做的

| 线索 | 取值 |
|---|---|
| ⓪ 投影 | 右下偏移 (9, 8)，近黑 α .40 |
| ① 侧壁（厚度） | 主盘下移 **14px** 的同形暗盘 |
| ② 受光弧 | 左上 80°–190°，r 86，粗 6 |
| ③ 暗弧 | 右下 258°–372°，r 86，粗 6 |
| ★ 球面明暗 | 左上受光椭圆（α .26）+ 右下背光椭圆（α .50），**铺满整个圆** |
| ★ 外缘硬边 | 整圈 r 90 |
| ★ 稳定鳍 | 左右各一片梯形，根部 r58 → 尖端 r132 |

★ 的三条是**新加的**，理由在下面。

## 两个只看代码发现不了的问题（新工具抓出来的）

这轮新加了 `tools/preview_diver.py` —— 用 PIL 复刻同一套几何**直接出静态图**，
改一个半径常量不用开 Creator。它当场抓出两个问题：

1. **投影偏移 18/14 太大** ⇒ 读作"后面还叠着另一个圆"，不是"浮着"。改到 9/8。
2. **只在壳面做明暗 = 读作"边缘一圈装饰"** ⇒ 必须把明暗**铺满整个圆**（含立绘与装甲环），
   才读作"一块金属被光从左上照到"。这是立体感成不成的主开关。

顺带一条：**纯圆 + 同心环 = 一块表盘**。加了两片稳定鳍，第一眼才读作"一台机械"。

对比图 `docs/shots/diver_layers.png` 从左到右能看出体积是一层层建起来的。

## 三个会静默失效的坑（已规避）

1. **`UIOpacity` 不向下传播** —— 只给父节点挂一个，淡入淡出会失效且不报错。
   ⇒ 每个零件各挂一个，节点结构拍平成"一个节点 = 一个 Graphics"。
2. **舱体内部坐标与顶层相反**（局部 y 向上）⇒ 内部的 `Gfx.arc()` 会多翻一次 y，
   "受光弧在左上"会翻到右下。⇒ 内部统一走 `.g` + 自带的 `larc()`。
3. **半径层级要排成表** —— 上一版外环带 r 84–92 比外壳（90）还大（悬空在壳外）、
   推进器口 r 66 正好压在立绘边缘。单个常量看不出来，排成表一眼就露。

## 验证

- `tools/verify_cocos.py` **7/7**
- `web npx tsc --noEmit` 退出码 0
- `tools/sync_shared.py` 零写入（纯视图层改动，`shared/` 一行没动）

⚠️ **静态全绿只是下界**。必须在 Creator 3.8.8 里跑 `Dive.scene` 目视，
重点是**球面明暗压在真实立绘上的观感** —— 预览里用的是占位圆，
真实立绘自带明暗且受光方向未知，有可能显得"双重打光"。**这是本方案最大的风险点。**
