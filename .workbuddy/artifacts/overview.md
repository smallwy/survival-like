# 主界面版式重做 · V6.38 —— 交付概览

## 本次要解决的问题

你看过 V6.37 的标题屏对照图后指出：**「这样的布局肯定是不行的，不应该有个游戏主界面的 UI 吗？然后游戏中有功能的 ICON……至少有个主界面吧，然后不同的系统再分类」**，并给了土豆兄弟主菜单做结构参照。

结论：**你说得对。** 原来那版是 **splash 启动页**（居中标题 + 三张并排卡 + 两个文字按钮），不是 **hub 主界面**。

## 诊断：5 条症状

| # | 症状 | 造成的结果 |
|---|---|---|
| 1 | 没有常驻框架（无顶栏、无分区） | 看不出这是个有多个系统的游戏 |
| 2 | 货币藏在右上角小字里 | 局外核心资源不显眼 |
| 3 | 入口是 180×48 **文字按钮**，不是图标 | 无图标、无分类、无层级 |
| 4 | 主形象是"三张并排卡"，不是"一个角色" | 没有视觉焦点，像商店货架 |
| 5 | 所有系统混在一处 | 玩家无法枚举"这游戏有哪些系统" |

## 新版式：五分区

```
顶栏（常驻记账：档案 · 沉淀货币 · 设置/帮助）
左栏·收藏（图鉴 / 里程碑）      右栏·成长（装置坞 / 海域·锁定）
中央（标题 + 单张大立绘 + 左右箭头 + 指示点 + 主按钮）
底栏（快捷键提示 · 版本号）
```

**核心变化**：三张卡 → **一张大立绘（Brotato 式）**；两个文字按钮 → **左右两栏 6 个功能图标**。

## 最有价值的一条：fitWidth 的高度安全带

`fitWidth=true` 下 **可见高 = 1304 ÷ 屏幕长宽比**，以 y=374.5 对称裁切：

| 比例 | 可见高 | 可见 y 区间 | 顶栏(0–72) |
|---|---|---|---|
| 16:9 | 733 | [8, 741] | ✅ |
| 19.5:9 | 602 | [74, 676] | ⚠️ 裁 2px |
| 21:9 | 559 | [95, 654] | ❌ 裁 23px |

→ **主目标 16:9 桌面**（键盘操作 + `.bat` 启动，本就是桌面定位）。
→ 若日后上手机横屏：顶栏下移到 y96 起、底栏上移到 y660 前，**中央三块完全不用动**（已在 21:9 可见带内）。
