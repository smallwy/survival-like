## 核心改动

### 1. 玩家机体 = 炮塔总成（`view/DiveGame.ts`）
每台**实际装配**的武器 = 一座塔：底盘受光面 → 环带上下弧 → 内凹槽 → 外缘亮环 →
**装填进度环** → 中心毂 → 扩容座卡榫 → 按武器 id 的发射器造型。
删掉了已废弃的"空座 + 座圈连线"（需要看"还有几个空位"的时机是**商店**，不是战斗）。

- 新增 `rot()` **手算旋转** —— Cocos `Graphics` 没有 `translate/rotate`（读引擎源码确认）。
- 鱼雷管身改**本色半透明** —— 原先的近黑填充就是"击杀后黑方块"的真凶。

### 2. 商店亮色居中面板 V7（`view/Hud.ts` + `shared/theme.ts`）
- 新增 **`BRIGHT` 皮肤**，明度阶梯与暗色**反向**：暗色是"凹槽比卡面亮"，
  亮色必须"**凹槽比卡面暗**"，否则立绘跳不出来。对比靠**实底 + 硬边**，不靠发光。
- `scrim()`（半透明暗幕）取代 `pageFill()`（不透明铺满）—— 后者正是"全屏太大"的成因。
- 面板宽 **700 = 3×204 + 2×18 + 2×26**（设计分辨率 1304×749，正好整除）。
- **四类卡立绘缺失时全走代码图形兜底**：器械/武器→武器形状签名、挂载→座圈俯视示意图、
  属性→11 种 glyph + 进度条、遗物→遗物图标。
- 按钮新增皮肤系统 `BtnStyle`，**缺省行为与原暗色完全一致**（老调用点零改动）。
