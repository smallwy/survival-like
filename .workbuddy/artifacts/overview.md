## V6.51a 你的追问 → 三个答案

> 「我要的是往下游的感觉 / **这个不是要做视频么** / 还是怎么设计 / 还可以看到向下的海洋生物、周围的鱼群 / **这是一个俯视的角度**」

### ① 不做视频（四条理由，任一成立即否决）

| 维度 | 视频 | 引擎内程序化（本方案） |
|---|---|---|
| 深度连续性 | 锁死在片子里 | 跟 `depthM` 实时变 —— 玩家在哪一米，画面就是哪一米 |
| 可被玩法驱动 | 不能（探照灯/节拍/换带全动不了） | 全都能改 |
| 循环 | 首尾必须无缝 | 无需循环，颗粒是无限流 |
| 体积/分辨率 | 10s 1080p ≈ 8–15MB，分辨率固定 | **零新增资源** |

**核心**：深度是**玩家行为决定的连续量**。用视频＝放弃全部玩法耦合。

### ② 俯视看不到"下"，"下"由四个通道翻译过来

| # | 通道 | 屏幕里长什么样 | 权重 |
|---|---|---|---|
| ① | **相对运动** | 悬浮物**向上掠过**（= 开车时路边景物向后跑） | ★★★ |
| ② | 换带 | 颜色/亮度/生物群整体换一次 | ★★ |
| ③ | 生物群变化 | 鱼群种类、大小、密度随深度换 | ★★ |
| ④ | HUD 深度计 | 左侧竖条游标下移 | ★ |

**现状缺的就是 ①** —— 海雪 `vy = -6~-20 px/s` 方向对但**慢一个数量级**、只有一层、**无视差**。
主修：`SCROLL_BASE` → **46 px/s**、换波峰值 **220（4.8×）**、**三层视差**（视差本身就是深度线索）。

### ③「向下的生物 + 周围的鱼群」= 生态两层

俯视里**唯一能表达深度的是大小 + 明暗**（近大亮 / 远小暗）：

| 层 | 内容 | 大小 | 明暗 | 可交互 |
|---|---|---|---|---|
| **远景剪影层**（深，你点名的"向下的生物"） | 小鱼群横游 / 深渊巨影 | ≤ 敌人 0.6× | alpha ≤0.35，**无发光核** | ⛔ 不可瞄准 / 不碰撞 |
| **同层实体层**（浅） | 现有敌人 | 基准 | 带 2px 发光核心 | ✅ 战斗目标 |

⚠️ 远景鱼群**绝不能带那枚 2px 发光核** —— 敌人定位铁律，破了它玩家会朝打不到的鱼开火。

> 「水域带有游戏色彩吧 / 至少能产生鱼群吧 / 太黑了 应该要有光吧 / 能够看见生物 水体物质 / 类似潜水 / 也不是完全漆黑 / 发挥下想象」

| L1 阳光带 | 86.8 | 0% | 39.9% |
| L2 弱光带 | 63.5 | 0% | 10.6% |

## 核心原则：光的主权转移

> **不做「越深越黑」。做「每一带换一个光的主角」。**

| 带 | 光的主角 | 玩家的心理 |
|---|---|---|
| L1 | 太阳（丁达尔光柱 + 水面焦散） | 安全、熟悉 |
| L2 | 残光 + **探照灯登场** | 「我得靠自己看了」 |
| L3 | **生物荧光**（链状浮游 / 水母群） | 陌生、美丽、危险 |
| L4 | **热泉本身**（橙红烟柱） | 灼热、狂暴 |
| L5 | **探照灯 + 深渊呼吸点阵** | 孤独、压迫 |

**两处关键反转**：
- **L4 热泉带比 L3 亮** —— 打破单调递减的节奏疲劳（物理上也成立：热泉有热辐射 + 化能生物群）。
- **提高对比度 ≠ 提高环境亮度** —— 均值可以低，但**必须有亮点**。这才是「黑暗中有光」和「一团黑」的分界。

**可验收红线（本轮唯一硬指标）**：每张图 **≥6% 像素亮于 90**。现状 L3=1.2% / L5=0.4% 都不合格。

## 四个创新点

1. **探照灯 = 双向暴露** ★ 最大创新。光让你看得见，也让你被看见：`LAMP_R` 越大 → 看得越远，但趋光生物生成概率越高。**把一个纯表现参数变成了一次真实取舍。**
2. **光的颜色 = 情报语言**（零学习成本）：青绿=鱼骨 / 紫青链=生物荧光 / 橙絮=热泉 / 冷白=你自己 / 白点阵=深渊。
3. **深渊的呼吸**：L5 点阵全场同步明灭 3.2s —— 极低成本制造「底下有个巨大的东西」。
4. **温跃层扫带**：换带时一条波纹带从下往上扫过 0.6s。**只 3 图元，性价比最高。**
