## 二、为什么你选的这档可行（关键论证）

你之前否掉过"侧视"，理由是「敌人只能左右来，360° 包围感掉一大截」。
**这个理由不成立** —— 敌人本来就是从四条边刷的：

```
pickSpawnSide(): rng.int(0, 3)     // 左 / 右 / 上 / 下
spawnBoss():     y = -90           // Boss 从上方进
```

侧视下换个解释就还是 360°（左/右 = 前后，上 = 水面方向，下 = 更深处）。
⇒ **贵的不是配平，是渲染层 + 资源。模拟层一行不用改。**

## 三、六条改动

| # | 改动 | 关键点 |
|---|---|---|
| 1 | 敌人朝向：整圈旋转 → **镜像 + ±35° 限幅倾角** | 现状 `DiveGame.ts:1944,1955` 用 `atan2` 朝玩家全 360° 旋转 = **俯视写法**。侧视的鱼不该翻滚 —— 从正上方游下来的鱼被转 90°，屏幕上就是"一条竖着的鱼" |
| 2 | 潜航器：60° 俯角球核 → **侧视剖面** | 复用 `Title.ts` 中央区已有的侧视轮廓。⚠️ **炮塔座位是最大风险点** |
| 3 | **水域滚动** `SCROLL_BASE 46px/s` + 换带 burst 220（4.8×） | ⚠️ **水色不滚、只地形与颗粒滚** —— 滚纯色没有视觉信息 |
| 4 | **换带三段式**：起势 0.8s → 温跃层扫带 0.6s → crossfade 2.0s → 落定 0.9s | 你说的"坐电梯"**不是过渡不够长，是速度曲线是台阶** |
| 5 | 浅层去底 + 环境图/敌人贴图重出 | ⚠️ **敌人贴图是俯视素材，不换等于白改** |
| 6 | HUD：左侧深度计 + 右上**鱼情雷达**（你要的） | ⚠️ 深度区间非线性，**必须按视觉等分** |

### 两个最容易漏的坑

1. **敌人贴图**：改朝向只改一行，贴图不换 = 白改。**出图必须与第 1 步同时排。**
2. **深度计必须视觉等分**：五带区间 0-200 / 200-1000 / 1000-4000 / 4000-6000 / 6000-11000，
   L1 只占真实比例的 **1.8%**，等比例画等于看不见。
