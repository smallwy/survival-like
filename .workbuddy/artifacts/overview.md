# V6.56 · 下潜滚动与换带过渡

> 分支 `cocos` ｜ 对应 V6.52 §3.1 §3.2 §3.3 §3.4 ｜ 落地顺序第 3+4 步

## 一句话

之前把**朝向**改成了侧视，但**运动**没跟上 —— 水是**冻住的**、换带是**一帧硬切**。
本轮把运动补上：世界开始**真的在滚**，换带变成一次**有速度的穿越**。

## 四件事

| # | 内容 | 关键数 |
|---|---|---|
| ① | 下潜滚动速度 `scrollV`：换带爆冲 + 指数衰减 | 稳态 **46 px/s**（16.3s 扫过一屏）；爆冲 **220**（4.8×）；τ **0.9s** |
| ② | 颗粒 / 远景鱼群接进速度场，近 1.00× / 中 0.35× | **L4 热泉带整组反向**（-0.62 / -0.22）＝ `ventPush` 的视觉证据 |
| ③ | 温跃层扫带：波纹带从屏幕底扫到顶 | **0.6s**，26 段正弦，头线/过渡带/余晖 3 层 |
| ④ | 双图 crossfade + 水压环 | 淡入 **2.0s**（< `descDur` 2.1s）；水压环 **0.9s** 3 圈 |

⛔ **模拟层一行未改** —— 弹道 / 碰撞 / 氧气收支 / 敌人生成全部不动。

## 三个"看着对其实错"的点

1. **`beginXfade()` 必须在 `syncBg()` 之前调**（同一帧内）。挪后 = 拷到新图 = 没有过渡，
   而且是**不报错的静默失效**。已在代码里就地标注。
2. **旧图压在上面淡出**，不是两层各淡一半 —— 两层半透会先暗一档再亮回来（双重曝光）。
   节点顺序 `bg`(新,在下,满不透明) → `bgOld`(旧,在上,255→0) 本身就是设计。
3. **`Mote.vy` 删掉了** —— 速度改为每帧由 `MOTE_MUL[带] × scrollV` 现算。
   逐条存速度的话，换带爆冲只能推快新颗粒，"换带时整片水没一起动"。

## 未做（明确标注）

- **背景图的地形滚动** ⛔ **做不了**：现有 env 图是 1536×984 的一整张定死全景，
  cover 后纵向只剩 86px 余量，**结构上无法自身滚动**。必须等 §4.3 的
  1536×1180 + 边缘无缝新图（**插画岗**）。速度机制已就位，新图落地后接 `scrollY` 偏移即可。
- **浅层去底 / 带名标签升级 / 探照灯 / 雾 / 荧光群** —— 见规格 §3。
