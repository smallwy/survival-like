## 三、★★ 三条新通则（值得记进长期记忆）

### ① 颜色是「语义槽」，不是「调色板」

`theme.ts` 七支色各有归属：`jade` 常见生物 / `magenta` 稀有危险 / `amber` 资源 /
`violet` 深渊 Boss / `steel` 甲壳金属 / `lime` 软体 / `danger` 致命预警。
⇒ **新生物按语义归族取色，不新开槽；种类区分靠剪影 + 行为，不靠换色。**

### ② 凡"按权重抽一个"，必须归一化，⛔ 不用顺序阈值 `if/else`

- 旧口径深层 `Σ其他 > 1` 时**尾部恒定饿死** ⇒ **L5 全程 `armor`/`orbit`/`swarm` 出现率 0**
  （深渊带退化成纯 dash 走廊）—— 而**表里写的权重看着都对**。这正是 V6.79 记下的旧坑。
- 新 `tables.spawnWeights()`：`Σ ≤ 1` 逐位一致、`Σ > 1` 按比例 + `SWARM_MIN = 0.20` 保底。
- ⚠️ **改了它 = 深层实际配比变了 ⇒ 手感有异第一个怀疑它**（不是新生物的锅）。

### ③ 占比写在表里 ≠ 玩家看得见 —— 加完生物**必须跑整局刷怪普查**

新建 `tools/census_enemies.js`。⚠️ 首跑 12 局**全只到 L1、新生物全 0** —— 不是配比的锅，
是**脚本没推进 `shop`/`decide` 相位**（卡在 4 波后空跑）。
修好后才跑出真数据，并揪出 **`herder` 平均每局仅 0.2 只 ≈ 玩家根本看不到**
（V6.79「都没看到新的生物」**同坑复发**）⇒ `brood` 下放 L2、`herder` 下放 L3，
**每种生物至少落在一个到达率 ≥40% 的层**，修完 **0.2 → 2.0**。

## 四、★ 普查出的真结论：短板从「内容量」换成「到达率」

```
L1  ██████████████████████████████ 100%
L2  █████████████████████████▌      85%
L3  ████████████                    40%
L4  █▌                               5%
L5  ▏                                0%
```

**后 40% 的内容，玩家在正常一局里根本看不到** —— 这比"内容不够"更该优先处理。
（本轮 5 种新生物每局出现：splitter 11.4 / kamikaze 9.9 / brood 7.8 / bulwark 2.7 / herder 2.0；
幼体峰值同屏 30 只。）

**跑偏判定：方向 ✅ 没跑偏 · 深度 ✅ 已脱离危险区 · 新风险 🔴 可发现性。**
