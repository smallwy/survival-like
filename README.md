# 深海回响 · 工程说明

一款**深海 · 生物发光题材的幸存者类（Survivors-like / Bullet Heaven）**游戏：**Phaser 3 + TypeScript + Vite** 前端，**Go** 后端（云存档/排行榜/meta 解锁）。参考《土豆兄弟》（Brotato）的波次-商店循环，题材与核心玩法全部重做。

> 立项决策、排期、各阶段复盘见 **[docs/项目计划书.md](docs/项目计划书.md)**（唯一正本，决策性内容只进这里）。
> 美术资产的生产规则见 **[docs/美术资源计划.md](docs/美术资源计划.md)**。
> 怎么启动、怎么玩、故障排查见 **[启动说明.md](启动说明.md)**。
> 一句话：**深海天然有"黑暗中的一束光"，光既是视野也是资源。**

## 核心差异：光资源系统（P2a 已落地）

黑暗不是氛围贴图，是**资源约束**——光量 = 光照半径，没有第二条数值：

| 规则 | 数值 | 玩法含义 |
|---|---|---|
| 开火消耗光量 | 0.9 / 点伤害 | 高伤武器视野收得快，无脑按住会把自己按瞎 |
| 自然回光 | 7 / 秒 | 停火几秒视野重新铺开 |
| 击杀回光 | 小怪 +5 · Boss +30 | 清怪就是续航，缩圈逼你主动进攻 |
| 两段半径 | 战术 420px ／ 头灯 150px | 光量 45% 为分界，跌破后只剩头灯一圈 |
| 光量告警 | 低于 45% 光量条闪烁品红 | 该换位置或交计谋了 |

## 四根差异化支柱

| 支柱 | 落地位置 | 说明 |
|---|---|---|
| **光**（你怎么看） | `gameData.ts` 的 `LIGHT` + `GameScene.tickLight()` | 见上表。黑暗遮罩实时挖洞，玩家带轮廓光保持可见。 |
| **剪影族**（谁在打你） | `tools/deepsea_assets.py` 的 `FOES` 表 + `ENEMIES` | 6 个深海剪影族（钟形水母 bell / 塔状管虫 tower / 海蛇 serpent / 鱼群 school / 贝壳 shell / 利维坦 leviathan），8 种小怪 + 5 个 Boss 分占 5 族。剪影两两可分由 `tools/silhouette_check.py` 用 IoU 实测把关（同屏敌对均值 0.584，人形玩家 vs 敌族 0.547 vs 0.801）。 |
| **护甲相克**（怎么打疼） | `EnemyDef.armor` + `WEAPONS[].vs` | 4 条相克链：凝胶 gel / 鳞甲 scale / 钙壳 cal / 骨质 bone。护甲决定伤害倍率，选武器就是选切哪类怪。 |
| **计谋**（你的主动牌） | `STRATAGEMS` + `castStratagem()` | 6 计局内 `Q`/`E` 一键释放，冷却 20~28s：共鸣脉冲 / 诱光潮 / 声呐冲击 / 环形回旋 / 捕光陷阱 / 过载脉冲。**这是玩家唯一的主动操作**。 |

## 可操控角色：4 名潜行者

| 角色 | 定位 | 起始武器 | 生命 | 移速 | 被动 |
|---|---|---|---|---|---|
| 深潜者 | 声呐 · 均衡 | 声呐枪 | 100 | 220 | 光量上限 +15% |
| 拾光者 | 诱饵 · 机动 | 探照灯束 | 120 | 195 | 每次击杀回复 3 生命 |
| 铸壳者 | 钙壳 · 减伤 | 电弧泡幕 | 150 | 185 | 受击减伤 20% |
| 电鳗使 | 电弧 · 爆发 | 骨刺长枪 | 90 | 265 | 攻速 +25%；受击伤害 +10% |

## 同屏密度与性能

反雪崩节流：同屏敌人上限 `30 + 等级 × 8`，封顶 130；终局目标同屏 80~150。
实测（P2a 后）：存活 34~37s 区间同屏 33~43 只，无平衡回归。
视野适配已做 6 档分辨率回归（4:3 → 32:9，短边对齐、长边封黑），见 `tools/view_check.py`。

## 启动与验证

```bat
REM 一键：双击项目根目录 start-game.bat（后端 :8099 + 前端 :5173 自动开浏览器）
REM 手动：
cd server && go build && set APP_PORT=8099 && survivors-server.exe
cd web && npm install && npm run dev -- --open
```

一条命令全量验证（静态守卫 → 类型检查 → 逻辑断言 → 真机截图）：`python tools/verify_all.py`。

## 目录结构

```
web/                 前端（Phaser 3 + TS + Vite）
  src/config/gameData.ts    全部数值与内容表（策划改这里，不动逻辑）
  src/scenes/GameScene.ts   战斗主场景（光系统/伤害入口/深度层）
  src/assets/pixel/         程序化生成的 PNG 资产
server/              Go 后端（存档/解锁/排行榜，:8099）
tools/               美术生成与验证脚本（Python）
  deepsea_assets.py         6 深海剪影族生成器
  silhouette_check.py       剪影可分性自检（IoU）
  view_check.py             6 分辨率视野回归
  verify_all.py             全量验证入口
docs/                项目计划书（正本）· 美术资源计划
```

- **美术是程序化像素**：仓库只存 PNG，改美术走 `tools/deepsea_assets.py`，别手画 sprite sheet。
- **`start-game.bat` 必须保持 CRLF + 纯 ASCII**（GBK 代码页下非 ASCII 会被误读），中文说明一律放 `启动说明.md`。
- **决策性内容只进 `docs/项目计划书.md`**，不另开文档。
